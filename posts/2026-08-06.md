## 编辑按语

今天的四篇论文覆盖通信复杂性、机制设计、动态数据结构和随机采样四个不同方向，没有直接技术联系。前两篇分别刻画 global-error 批量通信的渐近单价，并为 subadditive valuation 给出首个多项式时间常数近似。

另外两篇推进长期开放问题：Greedy BST 首次取得 $o(\log n)$ 竞争比；log-concave sampling 用 path-space rejection sampling 将两种光滑性设定下的维数依赖降至 $d^{1/3}$ 与 $d^{1/5}$。

## Zero-error information equals amortized communication complexity [arXiv:2608.04141](https://arxiv.org/abs/2608.04141)

这篇论文研究 randomized communication complexity 的 direct-sum 问题：Alice 拿到 $x=(x_1,\ldots,x_n)$，Bob 拿到 $y=(y_1,\ldots,y_n)$，两人要一次性输出 $f(x_1,y_1),\ldots,f(x_n,y_n)$；协议允许以至多 $\varepsilon$ 的概率把整个答案向量算错。Daiki Suruga 证明，对任意有限输入上的函数乃至 relation（同一输入可以有多个合法答案），若以 $\overline R_\varepsilon(f^n)$ 表示最坏输入上的**期望**通信量，则

$$
\lim_{n\to\infty}\frac{\overline R_\varepsilon(f^n)}{n}
=(1-\varepsilon)\mathrm{IC}_0(f).
$$

这里 $\mathrm{IC}_0(f)$ 是 zero-error information complexity：不是协议实际发送了多少 bit，而是在完全不出错的前提下，transcript 至少向双方泄露多少关于对方输入的新信息。对通常按所有随机选择取最大值的 worst-case 通信量 $R_\varepsilon$，论文还证明

$$
(1-\varepsilon)\mathrm{IC}_0(f)
\leq \liminf_{n\to\infty}\frac{R_\varepsilon(f^n)}{n}
\leq \limsup_{n\to\infty}\frac{R_\varepsilon(f^n)}{n}
\leq \mathrm{IC}_0(f).
$$

因此 expected cost 的常数被精确确定；worst-case cost 对任意固定 $\varepsilon<1$ 则在常数因子内精确。论文还给出 $\mathrm{OR}_n\circ f$ 在 one-sided error 下的精确极限，并由此确定 Set-Disjointness 相应 one-sided 版本的渐近通信率，否定 Dagan–Filmus–Hatami–Li 关于标准 two-sided randomized complexity 的猜想。One-sided error 指两类错误中有一类被完全禁止——例如绝不把负例报成正例，只允许漏掉少量正例；two-sided error 则允许两边都以小概率出错。

通信复杂性研究的是“数据分开放置时，信息交换本身要付出多少代价”。最基本的 two-party 模型里，Alice 只知道 $x$，Bob 只知道 $y$；本地计算免费，唯一计费的是两人交换的 bit 数。例如两家机构各持有一份用户集合，要判断是否存在共同用户，本地把集合排序、建哈希表都不收费，但不允许把整份数据库偷偷搬到同一台机器上。一个低通信协议说明任务真正需要交换的信息很少；反过来的下界则说明，不管本地算法多快、交互轮数怎样安排，这么多信息总得跨过边界。

这个抽象既能给 streaming、distributed computation 和 data structure 下界，也通过 Karchmer–Wigderson correspondence 接到 circuit depth。[Karchmer、Raz 和 Wigderson (1995)](https://www.math.ias.edu/~avi/PUBLICATIONS/KarchmerRaWi1995.pdf) 曾指出，一类 relation composition 的 direct-sum 性质会带来超对数 circuit-depth 下界；这也是为什么“同时做 $n$ 份任务能否省通信”远不只是批处理里的常数优化。不过本文解决的是 randomized communication 中独立坐标输出、global error 的渐近问题，并没有解决 KRW composition conjecture。这里的“$n$ 份”也不是把一个长输入随意切成 $n$ 段，而是 $n$ 对彼此独立定义的输入坐标，每一对都要给出一个合法答案。

乍看 direct sum 应当成立：单独做一份 $f$ 要 $C$ bit，做 $n$ 份似乎就要 $nC$ bit。问题是协议 transcript 可能携带大量冗余。一个长对话实际发送了 $C$ bit，并不等于它让 Alice 和 Bob 学到了 $C$ bit 新信息；把许多独立执行放在一起，冗余部分可能被压缩掉。[Feder、Kushilevitz、Naor 和 Nisan (1995)](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/amortized_abs.html) 已经用 Equality 型例子说明，单份 private-coin（双方各用自己的随机数、没有共享随机串）randomized cost 可以是 $\Theta(\log m)$，而 amortized cost 降到 $O(1)$。所以正确问题不是“通信量是否机械相加”，而是“批量压缩后还有什么不可消除的量”。

Information complexity 正是为回答这个问题而生。设输入 $(X,Y)$ 服从分布 $\mu$，协议的随机 transcript 为 $\Pi$。Bob 本来知道 $Y$，所以 $I(X;\Pi\mid Y)$ 衡量 transcript 让他额外知道了多少 Alice 的输入；对称项 $I(Y;\Pi\mid X)$ 衡量 Alice 的所得，两者之和

$$
\mathrm{IC}_\mu(\Pi)
=I(X;\Pi\mid Y)+I(Y;\Pi\mid X)
$$

叫 internal information cost。它至多等于期望通信量，却可能小得多。

一个简单的极端能说明“发送”和“揭示”并不相同：如果 Bob 凭自己的 $Y$ 已经能预测 Alice 将发的长消息，那么 transcript 虽长，条件互信息仍可能很小。Interactive compression 的目标就是利用这种可预测性，让双方只交流用于消除各自不确定性的部分；单次协议中，为了让双方同步到同一 transcript 所需的额外协调可能很贵，但把很多份协议放在一起后，这些协调成本可以摊薄。因而 information complexity 不是人为另造的下界量，而是批量运行时通信中不可压缩的净含量。

[Chakrabarti、Shi、Wirth 和 Yao (2001)](https://www.cs.dartmouth.edu/~ac/Pubs/focs01-infocomplex.pdf) 首先用这个观点处理 simultaneous-message direct sum；[Barak、Braverman、Chen 和 Rao (2009)](https://eccc.weizmann.ac.il/report/2009/044/) 建立 interactive protocol compression，并得到一般 randomized communication 的 $\widetilde\Omega(\sqrt n)$ 型 direct-sum 下界。决定性一步是 Braverman 和 Rao (2011) 的 [Information Equals Amortized Communication](https://arxiv.org/abs/1106.3595)：固定输入分布、固定每个坐标的容错要求时，information cost 精确等于 amortized distributional communication。[Braverman (2017)](https://epubs.siam.org/doi/10.1137/17M1139254) 随后把它推进到 prior-free randomized complexity：若每个坐标各自允许 error $\varepsilon$，则

$$
\lim_{n\to\infty}\frac{R([f,\varepsilon]^n)}{n}=\mathrm{IC}_\varepsilon(f).
$$

这里 $[f,\varepsilon]^n$ 的要求是每个坐标的边际错误率不超过 $\varepsilon$，并不要求整条输出向量同时正确。[Ganor、Kol 和 Raz (2014, 2016)](https://www.ias.edu/sites/default/files/math/csdm/14-15/GanorKolRaz.pdf) 又构造出 information complexity 仅 $O(k)$、单份 randomized communication 却为 $2^{\Omega(k)}$ 的 relation，后来还推广到 partial Boolean function。这表明即使每坐标版本的 amortized rate 被 information complexity 精确描述，也不能倒推出 $R(f^n)=\Omega(nR(f))$；是否存在同样分离的 **total function** 至今仍然开放。

到本文之前，图景因此很不对称：按坐标分别计错时，amortized rate 已由 $\mathrm{IC}_\varepsilon(f)$ 描述；把整条输出向量一次判成成功或失败时，已有 compression 工具却没有给出极限，更不清楚正确的单份量应是带误差的 $\mathrm{IC}_\varepsilon(f)$，还是完全正确的 $\mathrm{IC}_0(f)$。已有分离说明用单份通信量 $R_\varepsilon(f)$ 做 strong direct sum 不会普遍成立，却没有回答 global-error 批量问题究竟收敛到什么。

:::aside[本文使用的 prior-free 定义]
对分布 $\mu$，记 $\mathrm{IC}^\mu_0(f)$ 为所有在 $\mu$ 上 zero-error 的协议中 information cost 的下确界。本文的 prior-free 量要求一个协议面对所有输入分布：
$$
\mathrm{IC}_0(f)
=\inf_{\Pi:\,\mathrm{err}=0}\max_\mu \mathrm{IC}_\mu(\Pi).
$$
有限输入情形下的 minimax identity 给出 $\mathrm{IC}_0(f)=\max_\mu\mathrm{IC}^\mu_0(f)$，因而可以选取一个最难分布 $\mu^*$ 做下界。Relation 的输出可以是合法答案集合；zero-error 意味着协议在每个输入、每个随机分支上都输出集合中的元素。
:::

本文填上的缺口来自另一种误差要求。标准的 $R_\varepsilon(f^n)$ 只允许

$$
\Pr[\Pi(X^n,Y^n)\neq f^n(X^n,Y^n)]\leq\varepsilon,
$$

也就是以至少 $1-\varepsilon$ 的概率把 **全部 $n$ 个坐标**同时算对。它比“每一坐标各有 $\varepsilon$ 错误率”强得多：后者容许错误散落在不同坐标，前者一处错误就算整次失败。假如 $n$ 个坐标各自独立地以 $0.01$ 概率出错，那么每个坐标都满足 $1\%$ 的误差保证，整条向量全对的概率却是 $0.99^n$，随 $n$ 指数下降。Global error 要求排除了这种做法，却仍允许协议把全部失败集中到同一个概率为 $\varepsilon$ 的随机分支。直觉上，其余成功分支必须像 zero-error protocol 一样可靠；主定理中的 $(1-\varepsilon)\mathrm{IC}_0(f)$ 正是这一直觉的精确形式。这里也能看出标题为什么强调 zero-error information，而不是更熟悉的 $\mathrm{IC}_\varepsilon(f)$。

下界最巧的一步，是把“整条向量错了”转化成一个 single-instance 协议能够识别的局部事件。固定最难分布 $\mu^*$，从一个计算 $f^n$、global error 至多 $\varepsilon$ 的协议 $\Pi_n$ 出发。公共随机性均匀选坐标 $I\in[n]$，并公开抽取 $X_{<I}$ 与 $Y_{>I}$；Alice 私下补出 $X_{>I}$，Bob 私下补出 $Y_{<I}$，再把真正待算的 $(A,B)$ 塞到第 $I$ 个坐标。这样拼出的整个输入仍服从 $(\mu^*)^n$，双方可以模拟 $\Pi_n$。

困难在于：只看第 $I$ 个输出，其错误率未必是 $\varepsilon/n$。一次坏运行可能同时错很多坐标，普通随机坐标 embedding 无法把 global error 均匀摊开。Suruga 的修正是让 Bob 检查 $I$ 之前的所有坐标是否都输出正确——他知道公开的 $X_{<I}$ 和自己抽取的 $Y_{<I}$，因此能做这个验证。若 prefix 已经出错就 abort；只有 prefix 完全正确时，协议才输出第 $I$ 项。若以 $E_i$ 表示第 $i$ 项出错，那么

$$
\Pr\!\left[\bigcup_{i=1}^n E_i\right]
=\sum_{i=1}^n\Pr[E_i\cap \neg E_1\cap\cdots\cap\neg E_{i-1}].
$$

右边按 first failure 把全局错误事件不重不漏地分解。于是 abort 概率至多 $\varepsilon$，而“不 abort 且第 $I$ 项出错”恰好把每次坏运行收费给它的第一个错误坐标，平均后至多 $\varepsilon/n$。这比 union bound 的方向更精细：union bound 能从局部错误推出全局错误，这里却需要从已知的全局错误上界反向抽出一个几乎无错的局部协议。

这一步若为每个 $I$ 分别附上一段验证记录，information overhead 可能毁掉精确常数。论文观察到，表示“长度 $i-1$ 的 prefix 是否全对”的变量 $P_i$ 不会任意变化：整串 $(P_1,\ldots,P_n)$ 必为若干个 $1$ 后接若干个 $0$，只有 $n+1$ 种可能，所以总熵只有 $\log(n+1)$。把坐标随机化后，单份嵌入协议的额外 information cost 是 $O(\log n/n)=o(1)$。我认为这是全文最关键的结构观察：prefix verification 不只是把错误定位到 first failure，还把所有验证结果压成了一个“首错位置”。

现在得到的是一个 error $\varepsilon/n$、abort probability $\varepsilon$ 的单份协议。Abort lemma 再把每次 abort 接上一份最优 zero-error protocol；接续发生的概率至多 $\varepsilon$，所以 information cost 最多增加 $\varepsilon\mathrm{IC}_0(f)$。令 $n\to\infty$，非 abort 分支的 error 消失，并用 zero-error information complexity 对 error 的连续性，便得到

$$
\liminf_{n\to\infty}\frac{\overline R_\varepsilon(f^n)}{n}
\geq (1-\varepsilon)\mathrm{IC}_0(f).
$$

匹配上界在概念上反而很短。先取一份 prior-free information cost 接近 $\mathrm{IC}_0(f)$ 的 zero-error protocol，独立运行许多份，再用 Braverman–Rao 一系的 interactive compression 把 transcript 压到每坐标 $\mathrm{IC}_0(f)+o(1)$。论文补出的 prior-free amortized simulation 命题很重要：它不是只对某个输入分布平均成立，而是对每个输入点都保证输出分布的 total-variation 误差——即任何事件在两种输出分布下的概率最多相差一个小量——并给出线性的 worst-case 长度界。证明先对任意输入分布压缩，再以 minimax 把这些 distribution-dependent simulators 混合成一个对所有输入统一有效的 simulator；直观地说，它把“对每个分布另选一个好协议”换成“先固定一个协议混合，再扛住最坏输入”。最后把很多中等大小的 block 独立运行，用 concentration 和 truncation 把期望长度变成严格的 worst-case 上界。立方大小的分组只是为了让模拟误差与超长 transcript 的概率同时变成低阶项，并不改变每坐标极限。

随后掷一枚公共硬币：以接近 $1-\varepsilon$ 的概率运行压缩协议，否则零通信并输出默认答案。后一个分支承担几乎全部 global error，前一个分支近乎精确，于是期望通信恰好多出系数 $1-\varepsilon$。同一招不能把 worst-case 长度也乘上 $1-\varepsilon$——只要硬币落在“运行”分支，仍需支付完整 transcript——这正解释了第二个定理为何只有 $[(1-\varepsilon)\mathrm{IC}_0(f),\mathrm{IC}_0(f)]$ 的夹逼。

Set-Disjointness 的应用需要另一层结构。它是 communication complexity 最常用的硬问题之一：Alice 和 Bob 各持有 $n$ bit 的集合指示向量，要判断是否存在某个坐标同时为 $1$。它的线性 randomized lower bound会经 reduction 传给 streaming、sketching 和 data structure 问题，因此不只需要知道 $\Theta(n)$，误差 $\varepsilon$ 改变线性项常数的方式也值得追问。把“两个集合存在交集”写成

$$
\mathrm{NDISJ}_n(x,y)
=\bigvee_{i=1}^n (x_i\wedge y_i)
=\mathrm{OR}_n\circ\mathrm{AND}(x,y);
$$

取反就是通常输出“是否不相交”的 $\mathrm{DISJ}_n$，只会交换 false positive 与 false negative 的名字。对任意 Boolean $f$，令 $U_0$ 是所有仅支撑在 $f^{-1}(0)$ 上的输入分布，并定义

$$
\mathrm{IC}^{U_0}_{\mathrm{FP}=0,\,\mathrm{FN}\leq\varepsilon}(f)
=\inf_{\Pi:\,\mathrm{FP}=0,\,\mathrm{FN}\leq\varepsilon}
\max_{\mu\in U_0}\mathrm{IC}_\mu(\Pi).
$$

它只在 0-input distributions 上计算 information cost，却要求协议对所有输入都绝不 false-positive、且 false-negative 至多 $\varepsilon$。论文证明精确的 composition limit

$$
\lim_{n\to\infty}
\frac{R_{\mathrm{FP}=0,\,\mathrm{FN}\leq\varepsilon}
(\mathrm{OR}_n\circ f)}{n}
=\mathrm{IC}^{U_0}_{\mathrm{FP}=0,\,\mathrm{FN}\leq\varepsilon}(f).
$$

为什么右边只看 0-input？上界协议先随机抽 $n^{2/3}$ 个坐标并逐个 exact evaluation；找到正坐标就带着 witness 停机。若样本中没有正坐标，那么看完 filtering transcript 后，对剩余坐标形成的平均条件分布在 $f^{-1}(1)$ 上只有 $O(n^{-1/3})$ 质量：正坐标若很多，随机样本几乎不可能全部避开它们。Information cost 对输入分布连续且凹；前者保证移除这点小质量只造成 $o(1)$ 改变，后者允许先把许多坐标的条件分布取平均再统一控制。因此可以近似成某个 $U_0$ 中的分布，再在其余坐标上运行达到上述 asymmetric information cost 的单份协议。这个 filtering 论证对坐标高度相关的输入分布也成立，而不依赖独立性。

Compression 会以小概率扰动输出，似乎会破坏“false positive 必须严格为零”。作者为每个输出 1 的 block 同时保留一个正坐标 witness，压缩后再由一方发送该坐标上的输入、让另一方验证；假 witness 被确定性删掉，true positive 的额外损失只受 total variation distance 控制。这里的 witness verification 与前半篇的 prefix verification 形成了很整齐的对应：前者定位“第一个全局错误”以做下界，后者定位“一个真实正坐标”以保住 one-sided upper bound。

Dagan、Filmus、Hatami 和 Li (2018) 在 [Trading Information Complexity for Error](https://arxiv.org/abs/1611.06650) 中已经证明

$$
R_\varepsilon(\mathrm{DISJ}_n)
=n\bigl(C_{\mathrm{DISJ}}-\Theta(h(\varepsilon))\bigr),
$$

其中 $h$ 是 binary entropy；但这个式子只精确到 $\Theta(h(\varepsilon))$ 的改变量。他们还把标准 two-sided rate 夹在 $\mathrm{IC}_\varepsilon(\mathrm{AND})$ 与上述 one-sided $U_0$ information measure 之间，并猜想上界就是 $R_\varepsilon(\mathrm{DISJ}_n)/n$ 的精确常数。本文证明的是：这个 information measure 精确对应 **one-sided** Set-Disjointness，而不是标准 two-sided complexity，因此旧猜想不能成立。最直接的边界检查是 $\varepsilon=1/2$：two-sided 协议可以零通信随机猜测，one-sided information measure 却仍为正。

所以这篇论文并不是把强 direct sum 重新证明回来，而是确定了 global-error 批处理真正按什么“单价”结算：批量 compression 能消掉 transcript 的冗余，却消不掉成功分支上为保证整条答案向量正确而必须揭示的 zero-error information。Direct-sum 问题在这里最终没有以 $R_\varepsilon(f)$ 为基本单位闭合，而是以 $\mathrm{IC}_0(f)$ 闭合。

## From Compensation Design to Budget-Feasible Mechanisms: A Constant Approximation for Subadditive Valuations [arXiv:2608.04337](https://arxiv.org/abs/2608.04337)

这篇论文研究 budget-feasible mechanism design：有 $n$ 个卖方，每人完成任务要承担只有自己知道的成本 $c_i$；一个买方有总预算 $B$，从中选择集合 $S$ 后获得价值 $v(S)$，目标是在如实激励卖方报价且总支付不超过 $B$ 的前提下，让 $v(S)$ 尽量接近知道所有真实成本时的最优值
$$
\mathrm{OPT}=\max\left\{v(S):S\subseteq N,\ \sum_{i\in S}c_i\le B\right\}.
$$
作者处理的是一般的 subadditive valuation，即任意两组贡献者合并后的价值至多是两组价值之和。精确地说，Theorem 5.1 先假设 $v$ normalized、monotone 且 subadditive：normalized 表示 $v(\varnothing)=0$，monotone 表示加入更多卖方不会降低价值。对任意固定 $\varepsilon>0$，存在 universally truthful、individually rational、budget-feasible 的随机机制，使用 $\mathrm{poly}(n)$ 次 demand query、在多项式时间内达到 $C+\varepsilon$ 近似，其中
$$
C=1+2e\rho_0<86.399,
\qquad
\rho_0\approx 15.7083.
$$
这是 subadditive 情形第一个 polynomial-query constant approximation，把此前的 $O(\log\log n)$ 变成与 $n$ 无关的常数，解决了延续十五年的开放问题。对 nonmonotone 函数，论文采用标准的 monotone closure $\widehat v(S)=\max_{T\subseteq S}v(T)$ 运行机制，再在入选集合中输出实现该最大值的子集，因此结论也延伸到 nonmonotone subadditive valuation。

论文同时给出一个不计计算代价、但常数强得多的统一机制：monotone submodular、XOS、subadditive valuation 的近似比分别为 $3$、$e+1\approx3.718$、$2e+1\approx6.436$；后两项分别把此前的 $28$ 和 $33$ 大幅压低。在 large market——每个卖方的成本只占预算的 $o(1)$——XOS 与 subadditive 的机制还可确定性地做到 $e+o(1)$ 与 $2e+o(1)$。因此这里要区分两个层次：$2e+1$ 是信息论层面的 subadditive 界；真正回答 oracle-efficient 开放问题的是常数较大的 $86.399$。

为什么需要为“花钱买一组人的贡献”单独发展机制理论？如果每项服务的成本公开，这只是一个带 knapsack 约束的集合优化问题。但卖方会报价：支付太少，人不参加；直接按报价支付，又会鼓励虚报。Truthfulness 要求对每个卖方，无论其他人报什么，报出真实成本都是最优策略。Individual rationality 要求入选者的支付至少覆盖真实成本，而 budget feasibility 要求机制支付的是钱，不只是入选者成本之和，仍必须始终不超过 $B$。最后一点破坏了熟悉的 VCG 路线：VCG 可以用 externality payment 实现 truthful 与 welfare-optimal，却不能保证这些支付装得进事先给定的预算。数据采购、federated learning 中招募训练节点、内容平台奖励创作者，都是这种“贡献互相影响、成本私人、现金预算刚性”的场景。

:::aside[三项机制约束的形式化版本]
确定性机制由 allocation $S(b)$ 和支付 $p_i(b)$ 构成。卖方 $i$ 的效用为 $p_i(b)-c_i$（若入选）或 $0$（若未入选）。Dominant-strategy truthfulness 要求对所有 $b_{-i}$ 与谎报 $b_i$，真实报价 $c_i$ 的效用不更低；budget feasibility 要求对所有报价向量 $b$ 都有 $\sum_{i\in S(b)}p_i(b)\le B$。Universally truthful 随机机制是 truthful 确定性机制的分布，因而每次随机实现本身都满足 truthfulness 与预算约束，而不只是期望满足。
:::

这里的另一个难点是价值不再逐项相加。Additive valuation 满足 $v(S)=\sum_{i\in S}v_i$；submodular valuation 允许交互，但要求边际收益递减；XOS valuation 是若干 additive clause 的最大值；subadditive 只保留
$$
v(S\cup T)\le v(S)+v(T).
$$
直觉上，subadditive 排除了“两个单独无用、合在一起突然产生巨额价值”的强 complementarity，却仍允许远比 submodular 更不规则的替代关系。四类函数形成严格包含链
$$
\mathrm{additive}\subsetneq\mathrm{submodular}\subsetneq\mathrm{XOS}\subsetneq\mathrm{subadditive}.
$$
函数有 $2^n$ 个可能输入，当然不能显式给出。论文使用 demand oracle：给定一组非负“价格” $q_i$，oracle 返回
$$
D_v(q)\in\arg\max_{S\subseteq N}\left\{v(S)-\sum_{i\in S}q_i\right\}.
$$
它比只询问某个集合值的 value oracle 更强，能把一次带线性惩罚的组合优化封装为查询；所谓 polynomial-query，就是机制只调用它多项式次。本文突破的正是这一 oracle model 下的障碍，而非仅仅证明某个指数搜索存在好解。

这条线从 Singer (2010) 引入模型开始；他证明预算使 truthful optimum 不可能，并为 additive 与 monotone submodular 给出首批常数近似 [arXiv:1002.2334](https://arxiv.org/abs/1002.2334)。Chen、Gravin 和 Lu (2011) 随后证明，即便价值 additive，随机机制也不能优于 $2$，确定性机制不能优于 $1+\sqrt2$ [arXiv:1007.3801](https://arxiv.org/abs/1007.3801)；随机 additive 的 $2$ 上界直到 Gravin et al. (2020) 才匹配。

Subadditive 一侧长期困难得多。Dobzinski、Papadimitriou 和 Singer (2011) 给出随机 $O(\log^2 n)$、确定性 $O(\log^3 n)$ 近似，并猜测常数近似需要指数多个 demand queries。Bei et al. (2012) 把 polynomial-query 界改进到 $O(\log n/\log\log n)$ [arXiv:1203.4455](https://arxiv.org/abs/1203.4455)；他们在 2017 年的 Bayesian-analysis 路线还证明了不计计算时常数机制的存在，但没有显式构造。Neogi、Pashkovich 和 Swamy (2024) 给出显式 $33$ 近似，却需要指数查询；同一组作者 (2025) 才把多项式时间界推进到 $O(\log\log n)$ [arXiv:2506.04665](https://arxiv.org/abs/2506.04665)。所以本文之前的局面很清楚：constant 与 polynomial-query 各自都能做到，但从未在同一个机制里同时做到。

论文的入口来自作者团队三周前提出的 compensation design [arXiv:2607.14438](https://arxiv.org/abs/2607.14438)。它不是让卖方报告成本的 direct mechanism，而是先公布一个不依赖成本的支付规则；每个卖方看到自己参加后能拿多少钱，再自行 opt in 或 opt out，最终参与集合是一个 Nash equilibrium。设 $F$ 是买方价值的某个 proxy，marginal-contribution rule 在参与集合 $S$ 上支付
$$
p_i^F(S)=B\,\frac{F(S)-F(S\setminus\{i\})}{F(S)}
$$
给每个 $i\in S$。分子是“去掉 $i$ 会损失多少价值”，所以预算按最终边际贡献的相对大小分配。

要让这些份额之和不超预算，恰好需要 $F$ 是 self-bounding：它单调，且对每个 $S$ 都满足
$$
\sum_{i\in S}\bigl(F(S)-F(S\setminus\{i\})\bigr)\le F(S).
$$
这个概念原本来自 concentration inequalities；在这里，它直接变成支付可行性的证书。XOS 函数都是 self-bounding，但一般 subadditive 函数不是：若 $v(\varnothing)=0$，每个非空真子集价值为 $1$，全集价值为 $2$，那么全集上每个元素的最终边际都是 $1$，边际之和可达 $n$，远大于 $v(N)=2$。

Marginal-contribution game 有一个关键 potential：
$$
\Phi_c^F(S)=F(S)\prod_{i\in S}\left(1-\frac{c_i}{B}\right)_+.
$$
它把集合价值与参与成本的乘法折扣放在一起。若 $S$ 是全局最大化者，那么删去任意已参与者都不会增大 $\Phi$，整理不等式正好得到 $p_i^F(S)\ge c_i$；加入任意未参与者也不会增大 $\Phi$，等价于其加入后的支付不超过成本。因此全局 maximizer 是 pure Nash equilibrium，也就是在其他人参与决定固定时，没有任何单个卖方能靠独自加入或退出提高效用。这里论文刻意分析 price of stability，也就是“最佳 equilibrium 离 $\mathrm{OPT}$ 多远”，而不是最坏 equilibrium 的 price of anarchy：对 XOS，后者甚至可以是 $\Omega(n^{1/5})$，但前者仍是常数。之后的 direct mechanism 会主动选中这个 potential maximizer，因而 best-equilibrium 分析就足够。

对 subadditive valuation，整篇论文最有独立价值的一步是把原函数平滑成
$$
\widetilde v(S)=\int_0^1\mathbb E\bigl[v(R_q(S))\bigr],dq,
$$
其中 $R_q(S)$ 独立地以概率 $q$ 保留 $S$ 中每个元素。也可以把它理解成：先从 $\{0,1,\ldots,|S|\}$ 均匀选一个大小，再在 $S$ 中均匀选这么多个元素，然后取价值期望。平滑没有抹掉 subadditivity，而且只损失 factor $2$：单调性立即给出 $\widetilde v(S)\le v(S)$；另一方面，对每次抽样都有
$$
v(S)\le v(R_q(S))+v(S\setminus R_q(S)),
$$
而补集与 $R_{1-q}(S)$ 同分布，对 $q\in[0,1]$ 积分便得到
$$
\frac12v(S)\le \widetilde v(S)\le v(S).
$$

更巧的是，平滑后的所有最终边际满足一个精确恒等式：
$$
\sum_{i\in S}\left(\widetilde v(S)-\widetilde v(S\setminus\{i\})\right)
=v(S)-\widetilde v(S)
\le \widetilde v(S).
$$
最后一个不等式正是上面的 factor-$2$ 结论，于是 $\widetilde v$ 自动 self-bounding。这里最让我意外的是，作者没有把 subadditive 近似成更熟悉的 XOS——那条经典路线必然损失 $\Theta(\log n)$——而是只修复支付分析真正需要的一个不等式。平滑不是为了让函数“更简单”，而是精确地把总边际压回函数值之内；factor $2$ 还是一般情形下最优的。

这个 proxy 怎样给出 $2e+1$？设 $S^*$ 是最优预算可行集合，$M$ 是可负担单个卖方的最大价值，从 $S^*$ 中删去成本最大的 $i^*$。Subadditivity 给出 $v(S^*\setminus\{i^*\})\ge\mathrm{OPT}-M$，而 $\sum_{i\in S^*}c_i/B\le1$ 蕴含
$$
\prod_{i\in S^*\setminus\{i^*\}}\left(1-\frac{c_i}{B}\right)\ge e^{-1}.
$$
若 proxy 满足 $\eta v\le F\le v$，potential maximizer 的价值因而至少是 $\eta(\mathrm{OPT}-M)/e$。XOS 可取 $F=v$、$\eta=1$；subadditive 则取 $F=\widetilde v$、$\eta=1/2$。再以概率 $1/(2e+1)$ 运行 singleton branch——选择价值最大的可负担单人并支付整个 $B$——以其余概率运行 marginal-contribution branch，恰好把 $M$ 与 $\mathrm{OPT}-M$ 两部分配平，得到 $\mathrm{OPT}/(2e+1)$。

从 indirect equilibrium 变回 dominant-strategy truthful direct mechanism 的桥也很简洁。给定报价 $b$，机制选择 $\Phi_b^F$ 的全局 maximizer。某个已入选者降低报价时，所有包含他的集合的 potential 都乘上同一个因子，其他集合不变，所以在固定 tie-breaking 下整个入选集合不变；这比“他仍然入选”的 monotonicity 更强，称为 nonbossiness。单参数机制的 Myerson characterization 于是允许给每个入选者支付其 threshold bid。若 $i$ 抬价到 $b_i'$ 后仍入选，nonbossiness 保证集合仍为 $S$，同时 $S$ 仍是新报价下的 Nash equilibrium，因此
$$
b_i'\le B\,\frac{F(S)-F(S\setminus\{i\})}{F(S)}.
$$
所以 threshold payment 被 marginal-contribution payment 逐项控制，再由 self-bounding 求和即可证明总支付不超过 $B$。这一步把“equilibrium 存在性”转成了“truthful payment 的预算证书”，也是 compensation design 不只是动机包装的原因。

剩下的开放问题是计算：全局最大化 $\widetilde v(S)\prod_i(1-b_i/B)$ 看起来仍需指数搜索，而且对大集合精确计算 $\widetilde v(S)$ 本身要查询 $v$ 共 $2^{|S|}$ 次。Polynomial-time 版本 PolyRMC 先取略缩小的内部预算 $B'\le B$，令 $x_i=\min\{b_i/B',1\}$，再把最优 potential 集合 $S^*$ 分成 cost 最高的 $\ell$ 个元素组成的 core $C^*$ 与剩余 tail $T^*$。Tail 中每个元素都有 $x_i\le1/(\ell+1)$，而 subadditivity 给出
$$
\widetilde\Phi_b^{B'}(S^*)
\le \widetilde\Phi_b^{B'}(C^*)+\widetilde\Phi_b^{B'}(T^*).
$$
固定精度时 $\ell$ 是常数，因此 core 可以枚举所有 $O(n^\ell)$ 个小集合；每次精确算 $\widetilde v$ 只需 $2^\ell$ 个 value queries。

Tail 才是 demand oracle 发挥作用的地方。对 light agents，论文建立 sandwich inequality
$$
\frac{v(S)}{2}\exp\!\left(-\sum_{i\in S}\frac{x_i}{1-x_i}\right)
\le \widetilde\Phi_b^{B'}(S)
\le \frac{v(S)}{1+\sum_{i\in S}\frac{x_i}{1-x_i}}.
$$
右侧的最优值记为 $H_b(U)$。测试 $H_b(U)\ge z$ 等价于测试
$$
\max_{S\subseteq U}\left\{v(S)-z\sum_{i\in S}\frac{x_i}{1-x_i}\right\}\ge z,
$$
这正是一次 demand query；在一个与报价无关的标量 grid 上搜索 $z$，便能近似 $H_b(U)$。作者随机把卖方分成两半，用较小一侧的估计值 $\nu$ 给较大一侧定“市场价格”。这样一个入选者降价只会让自己所在市场更有吸引力，决定 $\nu$ 的另一侧不变，于是 allocation 保持 nonbossy。

Demand query 返回集合 $D$ 后还不能直接输出，因为 $D$ 的总归一化成本可能很大，乘积 potential 会指数衰减。论文以
$$
q=\frac{\nu}{v(D)}
$$
独立保留 $D$ 中每个元素，做 uniform thinning。当 $D$ 太“贵”时，$v(D)/\nu$ 也相应较大，较小的保留概率恰好把成本指数项拉回常数区间；最终 tail 的期望 potential 至少为 $\ell\nu/(2e(\ell+1))$。把 core 与 tail 以优化过的概率混合，得到 nonbossy 的 potential allocator，并满足
$$
\mathbb E\!\left[\widetilde\Phi_b^{B'}(A_{\mathrm{pot}}^{B'}(b))\right]
\ge \frac{1}{\rho_0+\varepsilon}
\max_{S\subseteq N}\widetilde\Phi_b^{B'}(S),
$$
其中
$$
u_0=\frac{\sqrt{1+16e}-1}{8e},
\qquad
\rho_0=1+\frac{1}{u_0^2}\approx15.7083.
$$

还有一个容易被“constant approximation”标题遮住的机制设计障碍：近似 maximizer 不再必然是 Nash equilibrium，前面用于控制 threshold payment 的证明会断掉。作者的修复是 filtering。先用随机排列加一个 marker 来采样 $\widetilde v$：marker 前面的元素与平滑定义中的随机子集同分布；取多次样本平均得到可多项式查询的 $\widehat v_m$，它以高概率同时近似所有集合上的 $\widetilde v$。然后从 potential allocator 的输出开始，按固定顺序反复删除任何一个“删掉后经验 potential 严格上升”的卖方。删除不会降低目标值，固定顺序又保住 nonbossiness；在终止集合 $S$ 上，每个 threshold 都满足
$$
\tau_i\le B'\,
\frac{\widehat v_m(S)-\widehat v_m(S\setminus\{i\})}{\widehat v_m(S)}.
$$
经验 proxy 只是近似 self-bounding，所以机制把内部预算略微缩小，并显式检查右侧之和不超过真实预算 $B$。论文证明高概率的好采样事件下检查一定通过、filtering 对真实 potential 只造成 $1+o(1)$ 损失，而且所有 threshold 都能用多项式次 demand queries 精确求出。

最终 marginal branch 对 $\mathrm{OPT}-M$ 的近似损失是 $2e\rho_0+\varepsilon$：$2$ 来自 smoothing，$e$ 来自预算产品项，$\rho_0$ 来自 core-tail allocator。再与 singleton branch 配平便得到
$$
\mathbb E[v(\mathrm{PolyRMC})]
\ge \frac{\mathrm{OPT}}{1+2e\rho_0+\varepsilon},
$$
即 $C+\varepsilon<86.399+\varepsilon$。这个常数没有被优化，算法对固定 $\varepsilon$ 虽是 polynomial time，$n^\ell$ 与采样规模也显然离实用很远；但 2011 年的指数查询猜想之所以失效，原因已经非常具体：机制从不试图用 demand oracle 直接最大化难算的 smoothed potential，而是让 smoothing 负责结构与支付，让 demand query 只解原函数 $v$ 的一参数线性惩罚问题，再用 thinning 和 filtering 把解带回 truthful、budget-feasible 的世界。绕开指数障碍的不是更强的 oracle，而是把同一个 proxy 在“分析”“分配”“支付”三个位置承担的工作拆开了。

## The Greedy Binary Search Tree is Non-trivially Competitive [arXiv:2608.04410](https://arxiv.org/abs/2608.04410)

这篇论文研究 dynamic binary search tree 的竞争性：固定 $n$ 个有序键，在线算法依次处理访问序列 $\sigma=(\sigma(1),\ldots,\sigma(m))$，每次可以用 rotation 改变树形；目标是让整段执行的代价接近预先知道全部序列的最优离线 BST。Guo、Pettie、Wan 和 Skora 证明，经典 Greedy BST 对任意初始树都满足

$$
\mathrm{Cost}_{\mathrm{Greedy}}(\sigma)
\le 2^{O(\sqrt{\log\log n})}
\bigl(\mathrm{OPT}(\sigma)+n\bigr).
$$

因此当 $m\ge n$ 时，Greedy 是 $2^{O(\sqrt{\log\log n})}$-competitive；附录把指数中的常数细化为

$$
2^{(2\sqrt 2+o(1))\sqrt{\log\log n}}.
$$

此前对 Greedy 的一般保证只有平凡的 $O(\log n)$ competitive ratio。这是第一次证明它在所有访问序列上都达到 $o(\log n)$，而不是只在某一类有局部性或避开特定 permutation pattern 的序列上表现良好。

先从为什么要研究这种基准说起。平衡 BST 保证每次查询 $O(\log n)$，但这会把访问序列中可利用的结构全部抹平：如果少数键反复出现，它们应该逐渐靠近根；如果访问按 $1,2,\ldots,n$ 扫描，下一次查询总在刚才的位置旁边，仍付 $\Theta(\log n)$ 也不合理。动态 BST 的一次访问会沿根到目标键的路径搜索，并允许用局部 rotation 重排树；代价可以等价地记为这次被触及的节点数。离线最优 $\mathrm{OPT}(\sigma)$ 也不能免费把树变成想要的形状，它做搜索和 rotation 同样要付费，只是提前知道未来。Dynamic optimality conjecture 要求存在一个不知道未来的在线 BST，在每条序列上的总成本都只比这个离线最优多常数倍。

这里的 rotation 是保持中序键序不变的局部父子交换，因此重排后的结构仍是一棵合法搜索树；模型不允许另存任意指针或跳过搜索路径。也就是说，算法既要为“找到键”付费，也要为“把树调整得对以后有利”付费。单棵平衡树对长度 $m$ 的序列只给出 $O(m\log n)$，而 $\mathrm{OPT}\ge m$，两式相除就是那个不需要理解序列结构的平凡 $O(\log n)$ competitive ratio。要证明 $o(\log n)$，必须说明 Greedy 的大量触碰恰好对应序列本身不可避免的困难，而不能只调用树高上界。

:::aside[竞争比中的初始化项]
初始树可能任意，而把一棵树改造成另一棵树本来就可能需要 $\Theta(n)$ 次局部操作，所以严谨陈述通常允许加性 $O(n)$。又因为每次访问至少花常数代价，$\mathrm{OPT}(\sigma)\ge \Omega(m)$；在论文采用的 $m\ge n$ 约定下，$n$ 可被最优成本吸收，得到纯乘法竞争比。
:::

这条研究线从 Sleator 和 Tarjan (1985) 提出 splay tree 与 dynamic optimality conjecture 开始。Splay 和 Greedy 后来成为两个最主要的“自然候选”：它们的更新规则本来就是为了自调整而提出，并非为了拟合某个已知 lower bound 人工搭建。Lucas (1988) 提出 Greedy Future，Munro (2000) 重新发现了它；Sleator–Tarjan 的 splay 则在每次访问后用 zig、zig-zig、zig-zag 把目标旋到根。两者都满足 working-set bound 和 dynamic-finger bound：若键 $x$ 自上次出现后只有 $w$ 个不同键被访问，前者给出约 $O(\log(w+1))$ 的摊还成本；后者按相邻访问键的秩距离 $|x_t-x_{t-1}|$ 收取对数成本。顺序扫描也都只需线性总时间。但这些性质各自覆盖某类“容易”序列，不能推出它们与任意序列的离线最优都接近。关于问题的经典脉络，可参见 Iacono (2013) 的综述 [arXiv:1306.0207](https://arxiv.org/abs/1306.0207)。

需要区分“为竞争比专门设计一棵树”和“证明已有自然算法确实好”。Demaine、Harmon、Iacono 和 Pătraşcu (2004/2007) 的 [Tango tree](https://erikdemaine.org/papers/Tango_SICOMP/) 已达到 $O(\log\log n)$-competitive，Multi-Splay 与 Chain-Splay 随后也达到同一量级。Chalermsook et al. (2024) 又构造出不同于 Greedy 的 GGreedy，竞争比为 $O(\sqrt{\log n})$ [arXiv:2312.15426](https://arxiv.org/abs/2312.15426)；其 group access bound 允许在参考树的每层先把相邻键合成组，再按被访问的组而非单键记账。上述算法都围绕可证明的下界或费用函数设计。这些结果回答“某个在线 BST 能否非平凡地逼近最优”，却没有回答 Lucas 的 Greedy 是否做到。Greedy 此前最强的证据主要来自特殊序列，例如 Chalermsook et al. (2023) 对 pattern-avoiding sequences——访问键的相对次序不含某个固定排列模式——的分析 [arXiv:2211.04112](https://arxiv.org/abs/2211.04112)。反方向上，Sadeh 和 Kaplan (2023) 已证明 Greedy 的竞争比不可能小于 $2$，并构造出它比最优多 $\Omega(m\log\log n)$ 的序列，从而否定“只差加性 $O(m)$”这个更强猜想 [arXiv:2301.03084](https://arxiv.org/abs/2301.03084)。

就在本文之前，Chmel et al. (2026) 证明

$$
\mathrm{Cost}_{\mathrm{Splay}}(\sigma)
=O\!\left((\mathrm{OPT}(\sigma)+n)
\log\log n\,(\log\log\log n)^2\right),
$$

给出了 splay 的首个 $o(\log n)$ competitive ratio；我们在 [2026-07-22 日报](#2026-07-22) 详细讲过那套证明，[论文见 arXiv:2607.18498](https://arxiv.org/abs/2607.18498)。数值上，本文的 $2^{O(\sqrt{\log\log n})}$ 比 splay 的 polylog-log 界弱，也比 Tango 的 $O(\log\log n)$ 弱；它的分量在于终于跨过了 Greedy 自身四十年来的 $\log n$ 障碍。两篇 2026 年结果的证明路线也几乎相反：splay 工作直接耦合一棵正规化的近最优动态树，本文则完全不追踪最优树，而把 Greedy 的几何执行逐级缩放，最后接到 Wilber 的序列下界上。

Greedy 为什么适合几何分析，需要先把 BST execution 换一种画法。把第 $t$ 次访问键 $\sigma(t)$ 画成平面点 $(\sigma(t),t)$：横轴是键的有序位置，纵轴是时间。一次 BST 操作触及键 $x$，就在对应行再放一点 $(x,t)$。一个点集称为 arboreally satisfied，若任意两个既不同行也不同列的点所张成的闭矩形里，还含有第三个点。Demaine et al. (2009) 证明，合法 BST execution 与这种点集等价，执行代价就是点数；于是 $\mathrm{OPT}$ 等于包含所有访问点的最小 arboreally satisfied superset 的大小。

在这个视图里，Greedy 只有一行定义：从下向上扫描时间；处理 $(\sigma(t),t)$ 时，对每个过去的点 $(x,t')$，如果它与当前访问点张成的矩形还是空的，就在当前行补点 $(x,t)$。这些补点恰好是本次被触及的键。Lucas 的原始描述像是“按照未来访问重排当前搜索路径”，看起来是离线算法；几何 line sweep 却只使用已经出现的点。Demaine et al. 证明其触点模式可以由在线 BST 以常数因子模拟，因此本文分析几何 Greedy 就足以得到在线结果。

证明要接入的 lower bound 是 Wilber (1989) 的 interleave bound。固定一棵叶子为 $[n]$ 的参考树 $R$；每个内部节点把“其子树里最近一次访问落入的那个孩子”标为 preferred child。新访问到来时，从根到该叶子的路径上有些内部节点会改变 preferred child，记切换数为 $\Lambda(\sigma,R,t)$，再定义

$$
\mathrm{IB}(\sigma,R)=\sum_{t=1}^m \Lambda(\sigma,R,t).
$$

在二叉参考树里，这就是对每个节点统计访问在左、右子树之间交替了多少次。任何动态 BST 都必须为这些跨区间切换付费，所以

$$
\mathrm{OPT}(\sigma)\ge
\Omega\!\left(\mathrm{IB}(\sigma,R)+m\right).
$$

例如参考树根把键分成较小的一半和较大的一半；若访问在两半间反复跳转，根的 preferred child 每次都翻转。BST 可以用 rotation 改变真实树形，却不能让这种跨有序区间的交替完全免费。把同样的计数递归放到参考树每个内部节点，便得到整条序列在多个空间尺度上的强制切换总数。Wilber 定理的关键正是：无论在线还是离线执行，至多常数个这样的切换可以由一次付费操作解释。

Interleave bound 本身并不 tight。另一种 Wilber lower bound 叫 funnel bound：对每个访问点向过去看，按时间倒序记录从左侧和右侧可见的点，并统计左右交替；Lecomte 和 Weinstein (2020) 证明它总不弱于 interleave bound，并且有时强 $\Theta(\log\log n)$ [arXiv:1912.02858](https://arxiv.org/abs/1912.02858)。本文没有换用更强下界，反而说明只要在多个尺度之间正确记账，这个较弱的经典下界已经足以打破 Greedy 的 $\log n$ 界。

Scaling 的设置是全文的中心。为简化记号，先 padding 到 $n=2^{2^k}$，于是 $k=\log\log n$。作者构造 $R_0,R_1,\ldots,R_k$：$R_0$ 是深度 $2^k$ 的满二叉参考树，每向上一个尺度就把相邻两层压成一层，因此 $R_i$ 的深度为 $2^{k-i}$、分支数为 $2^{2^i}$，而 $R_k$ 只剩一个根和 $n$ 个叶子的 star。它们描述同一个有序键集，只是分辨率从“一次区分左右”逐渐粗化到“一次区分每个键”。

对第 $t$ 次访问 $x=\sigma(t)$，看 $x$ 在 $R_i$ 中的所有祖先。每个祖先的 sibling subtrees 都对应键轴上的连续区间，而且这些区间把 $[n]\setminus\{x\}$ 分割开。作者定义两种费用：$\mathrm{ICost}_i(t)$ 逐个统计其中有多少 sibling interval 被 Greedy 触及；$\mathrm{GCost}_i(t)$ 则在每个祖先处，把 $x$ 左侧所有 siblings 合成一组、右侧所有 siblings 合成一组，只问这两个大区间是否被触及。它们满足

$$
\mathrm{GCost}_k\le\cdots\le \mathrm{GCost}_0
=\mathrm{ICost}_0\le\cdots\le\mathrm{ICost}_k,
$$

并且

$$
\mathrm{Cost}_{\mathrm{Greedy}}(\sigma)=\mathrm{ICost}_k+m,
\qquad \mathrm{GCost}_k\le 2m.
$$

两端为何如此容易理解：$R_0$ 是二叉树，每个祖先只有一个 sibling，individual 与 group 没有区别；$R_k$ 是 star，individual cost 会逐个数本次触及的其他键，正是真实成本减去必触及的查询键，而 group cost 只看查询键左、右两侧，单次至多为 $2$。问题于是变成：怎样从右端几乎免费的 $\mathrm{GCost}_k$，经过多尺度关系，走到真实成本 $\mathrm{ICost}_k$？

两个 scaling lemma 的势能都建立在 visible intervals 上。对一个按键序排列的区间划分 $I_1,\ldots,I_r$，令 $h_t(I_j)$ 是其中最近一次被触及的时间。若 $h_t(I_j)$ 严格高于它左边所有区间，或严格高于它右边所有区间，就把 $I_j$ 称为 visible；也就是从左或从右看过去时出现的 record high。这个定义恰好捕捉 Greedy 的 empty-rectangle 条件：当访问点位于整个区间外面时，只有朝向它一侧的 visible intervals 可能被触及；若一次触及 $q$ 个，除了两端，居中的至少 $q-2$ 个会因同一行出现了更高点而失去 visibility。若访问发生在区间内部，新变 visible 的区间又至多两个。于是“大量触碰”会造成势能下降，只有改变观察区间的 preferred-child switch 才能大幅重建势能，而后者正由 $\mathrm{IB}$ 计数。

这里可以把 visibility 理解成一条随时间升降的 skyline：区间的高度就是其中最高点的时间坐标，从左、右能看见的轮廓才可能与外部新点围出空矩形。一次 Greedy 访问把所有被触及区间的最高点抬到同一高度，中间轮廓随即被两端挡住。普通的“每碰一次势能减一”当然不成立，但“同一次碰很多区间时，除两个边界例外几乎都让势能下降”成立；两条 lemma 中反复出现的系数 $2$，正是这两个无法由 visibility 支付的边界例外。

形式化后得到两条核心不等式。对任意 $0\le i<j\le k$，

$$
\mathrm{GCost}_i
\le 2\,\mathrm{GCost}_j
+2^{j-i}\bigl(2\,\mathrm{IB}(\sigma,R_j)+4n\bigr),
$$

以及

$$
\mathrm{ICost}_j
\le 2\,\mathrm{ICost}_i
+2^{j-i}\bigl(2\,\mathrm{IB}(\sigma,R_i)+2n
+2\,\mathrm{GCost}_j\bigr).
$$

第一条沿一段 $R_j$ preferred path 展开它在更细 $R_i$ 中的左右 sibling intervals，并把 visible 数量作为势能。一次粗尺度 preferred child 改变，最多重置 $O(2^{j-i})$ 个细区间，收费给 $\mathrm{IB}(\sigma,R_j)$；若 preferred child 不变，细尺度触及很多 group 就会消耗 visibility，恰好支付 $\mathrm{GCost}_i-2\mathrm{GCost}_j$。第二条把势能放在相邻两个 $R_j$ 层之间的 $R_i$ 节点上，观察其粗尺度 descendant intervals；此时细分后多出来的 individual touches 要么消耗势能，要么对应 coarse group 已被触及，或对应一次 preferred switch。它因而把 $\mathrm{ICost}_j$ 拉回较细尺度的 $\mathrm{ICost}_i$，但多出 $\mathrm{GCost}_j$ 这一校正项。

这里最巧的不是某个势函数本身，而是作者没有试图一步从 $i=0$ 跳到 $j=k$。那样 $2^{j-i}=2^k=\log n$，立刻退回平凡界；逐层跳又要把不等式前面的系数 $2$ 累乘 $k$ 次，同样得到 $2^k=\log n$。令 $k=p^2$、$p=\sqrt{k}$，只看尺度

$$
0,p,2p,\ldots,p^2=k,
$$

则每次跨尺度的局部损失为 $2^p$，而递推只迭代 $p$ 次。先反复应用第一条不等式，从 $\mathrm{GCost}_k\le2m$ 推回

$$
\mathrm{GCost}_0=\mathrm{ICost}_0
\le O(2^{2p})\bigl(\mathrm{IB}(\sigma,R_0)+n+m\bigr);
$$

再用第二条从 $\mathrm{ICost}_0$ 推到真实的 $\mathrm{ICost}_k$，得到

$$
\mathrm{ICost}_k
\le O(2^{4p})\bigl(\mathrm{IB}(\sigma,R_0)+n+m\bigr)
=2^{O(\sqrt{\log\log n})}
\bigl(\mathrm{IB}(\sigma,R_0)+n+m\bigr).
$$

更抽象地看，若每次跨 $d$ 层，代价来自“单步分辨率损失” $2^{O(d)}$ 与“递推次数”造成的 $2^{O(k/d)}$；指数 $d+k/d$ 在 $d\asymp\sqrt{k}$ 时最小。附录让两趟递推分别走方向相反的 triangular scales，而不是都用等长 block，由此把粗略证明指数里的常数 $4$ 降到 $2\sqrt2+o(1)$。

这个结果也自动转移给 SmoothHeap——一种不维护显式平衡条件、只靠局部链接自调整的 priority queue。Kozma 和 Saranurak (2020) 证明，SmoothHeap 排序 permutation $\sigma$ 时的触碰模式，等同于 Greedy 排序逆 permutation $\sigma^{-1}$；最优 BST 成本又在交换时间轴与键轴时保持不变。所以同一个 $2^{O(\sqrt{\log\log n})}$ 界也控制 SmoothHeap sorting。

与一个月前的 splay 突破放在一起看，差别很清楚。Splay 的证明试图解释每个局部 rotation 如何跟随一棵运动的近最优树；Greedy 的证明则没有更精细地猜测 OPT 在做什么，而是发现同一份几何执行在不同分辨率下有两种可互换的费用。论文最后指出，当前指数并非来自 Greedy 的坏例子，而是两条 scaling lemma 前面的系数都是 $2$：若两处都能降到 $1$，同一套推导会立即给出 $\mathrm{poly}(\log\log n)$ competitive ratio。四十年的 $O(1)$ 猜想还在远处，但下一道门槛已经被具体地压缩成这两个系数。

## Exact simulation of diffusions and improved algorithms for log-concave sampling [arXiv:2608.05022](https://arxiv.org/abs/2608.05022)

这篇论文研究的是 high-dimensional log-concave sampling：给定一个只能通过导数 oracle 访问的势函数 $V:\mathbb R^d\to\mathbb R$，目标是从
$$
\pi(x)=\frac{e^{-V(x)}}{\int_{\mathbb R^d}e^{-V(y)}\,dy}
$$
中生成近似样本。Chen、Chewi、Rakhlin 和 Zhang 考虑 $\alpha I\preceq \nabla^2V(x)\preceq \beta I$ 的 strongly log-concave、smooth 情形，记条件数 $\kappa=\beta/\alpha$。对固定 Rényi 阶数 $q\ge 2$，他们证明只用 gradient queries 就能输出分布 $\nu$，使 $R_q(\nu\Vert\pi)\leq\varepsilon$，期望查询复杂度为
$$
O_q\!\left(\kappa^{2/3}d^{1/3}\,\mathrm{polylog}(1/\varepsilon)\right).
$$
若进一步假设 Hessian 在 Frobenius norm 下以 $\beta_H$ 为 Lipschitz 常数，并令 $\kappa_H=\beta_H^{2/3}/\alpha$，则使用返回 $\nabla V(x)$ 与 Hessian-vector product $\nabla^2V(x)v$ 的 generalized first-order oracle，复杂度改进为
$$
O_q\!\left(\left[\kappa^{1/2}+\kappa_H^{3/5}d^{1/5}
+\kappa^{1/3}\!\left(\kappa_H+\kappa_H^{3/11}\right)d^{2/11}\right]
\mathrm{polylog}(1/\varepsilon)\right).
$$
特别地，$\kappa_H=O(1)$ 时主导的维数依赖是 $d^{1/5}$；Gaussian target 有 $\kappa_H=0$，维数项全部消失，只剩近乎最优的 $\widetilde O_q(\sqrt\kappa)$。

这里报告的是 oracle complexity：Gaussian 随机数生成和显式线性变换不按 gradient query 计费。FORS 可能因 rejection 而重启，所以主结果写期望查询数；论文同时证明以至少 $1-p$ 的概率，总查询数只比 transition 数多一个 $O(\log(1/p))$ 项。

为什么要把“从 $e^{-V}$ 采样”单独做成一套复杂度理论？在 Bayesian inference 里，$V$ 可以是 negative log-posterior；在统计物理里，它是能量。归一化常数通常正是算不出来的那部分，因为它要求对整个高维空间积分，但采样仍能用来估计期望、置信区间和边缘概率。optimization 只需找到 $V$ 的低点，sampling 却必须按整片空间的相对质量分配随机性：一个很窄的深谷和一个稍浅但体积巨大的区域，哪边拿到更多概率质量，不能只看极小值。因此这里的基本资源不是 arithmetic operations，而是算法向 oracle 询问多少次 $\nabla V(x)$；我们希望把查询数写成维数 $d$、条件数 $\kappa$ 和误差 $\varepsilon$ 的函数。

$\alpha$-strong convexity 表示 $V$ 在每个方向都至少有二次函数那么弯，$\beta$-smoothness 表示它又不会弯得过快。于是 $\pi\propto e^{-V}$ 只有一个集中的“盆地”，而 $\kappa=\beta/\alpha$ 衡量这个盆地有多狭长。误差采用 Rényi divergence：它比较算法输出密度与目标密度之比的高阶矩；小 Rényi divergence 会推出小 KL divergence 和 total variation distance，因而是比“多数集合上的概率差不多”更强的 high-accuracy 保证。这里 high-accuracy 的关键不是 $\varepsilon$ 很小本身，而是复杂度只按 $\mathrm{polylog}(1/\varepsilon)$ 增长，而非 $1/\varepsilon$ 的某个幂。

这个 benchmark 刻意把几何条件固定得很规整，因为连这里的最优答案都还不知道。只追求对 $\kappa$ 的对数依赖，可以调用 cutting-plane 一类方法，但维数代价会变成较大的多项式；只追求 $\sqrt\kappa$，又可能付出很差的 $d$ 依赖。这个方向所谓 acceleration，准确目标是同时得到接近 $\sqrt\kappa$ 的条件数依赖和次线性的维数依赖。Chewi et al. (2023) 已经为 Gaussian sampling 建立 query lower bounds，说明 $\sqrt\kappa$ 这一尺度不是分析幻觉；但在一般 strongly log-concave target 上，$\kappa$ 与 $d$ 能否同时做到什么指数仍然开放。与本文同期，Lu 和 Luo (2026, [arXiv:2607.28413](https://arxiv.org/abs/2607.28413)) 对 bouncy particle sampler 做到 $\widetilde O(\kappa^{1/2}d^2)$：它把 $\kappa$ 完全加速，却牺牲维数。本文的 $\kappa^{2/3}d^{1/3}$ 正位于这张 tradeoff 图上，而不是宣布 sampling 已经获得与 Nesterov optimization 完全相同的复杂度。

最基础的连续时间 sampler 是 overdamped Langevin diffusion，直觉上是“沿 $-\nabla V$ 下坡，同时加 Brownian noise 防止只掉进 mode”。本文用的是带动量的 underdamped Langevin diffusion（ULD）：
$$
\begin{aligned}
dX_t &= P_t\,dt,\\
dP_t &= -\gamma P_t\,dt-\nabla V(X_t)\,dt+\sqrt{2\gamma}\,dB_t.
\end{aligned}
$$
$X_t$ 是位置，$P_t$ 是动量，$\gamma$ 是摩擦，$B_t$ 是 Brownian motion，即在不相交时间段上产生独立 Gaussian 增量的连续随机运动。这个过程在 phase space 上的平稳分布是
$$
\Pi(x,p)\propto \exp\!\left(-V(x)-\frac{\lVert p\rVert^2}{2}\right),
$$
所以丢掉动量后，$X$ 的 marginal 正是目标 $\pi$。加入动量的意义与 Nesterov acceleration 相似：overdamped 轨迹在狭长盆地里不断扩散、回撤，underdamped 轨迹能沿已有方向“滑行”。Cao、Lu 和 Wang (2023) 首先证明了 ULD 在 $L^2$ 意义下的 sharp accelerated decay；Lu (2026, [arXiv:2605.01933](https://arxiv.org/abs/2605.01933)) 又把它推进到 relative entropy，Li 和 Lu (2026, [arXiv:2605.25083](https://arxiv.org/abs/2605.25083)) 给出本文调用的 Rényi decay。取 $\gamma\asymp\sqrt\alpha$ 后，连续过程大约在 $\widetilde O(1/\sqrt\alpha)$ 时间内混合；这就是 sampling 版本的 $\sqrt\kappa$ acceleration 来源。

这些收敛定理背后的桥梁是 log-Sobolev inequality（LSI）：它说一个分布下函数值的 entropy 可以由局部梯度能量控制，因此动力学不断耗散局部梯度时，全局 density ratio 也会收缩。$\alpha$-strongly log-concave 分布自动满足常数为 $1/\alpha$ 的 LSI；这使上面的连续时间结论能够从一个有界 Rényi warmness 的初始分布开始，以指数速度忘掉初始化。比 LSI 弱的 Poincaré inequality 只控制 variance，足够给 $L^2$ contraction，却不自动给最适合 high-accuracy composition 的 entropy contraction。这也解释了为什么 Cao--Lu--Wang 的 $L^2$ acceleration 已经很强，仍需等到后来的 entropy/Rényi 版本才能顺畅地进入算法复杂度。

困难是，知道一条 SDE 混得快，不等于数字计算机能无偏地跑它。直接 discretization 每隔 $h$ 时间冻结一次 drift，会得到可模拟的 Markov chain，但它的平稳分布一般不再恰好是 $\pi$。为了把 asymptotic bias 压到 $\varepsilon$，$h$ 往往也得随 $\varepsilon$ 缩小，于是出现 $\mathrm{poly}(1/\varepsilon)$ 查询数。Altschuler、Chewi 和 Zhang (2026) 把 ULD 的连续 acceleration 与 shifted-composition 分析结合，做到 $\widetilde O(\kappa^{5/6}d^{1/3}/\varepsilon^{2/3})$：$\kappa$ 已经是次线性的，精度依赖却仍属于 low-accuracy regime。

经典补救是 Metropolis--Hastings：先走一个离散 proposal，再用目标密度比决定接受还是留在原地，以此消除 stationary bias。Euler--Maruyama proposal 加这一层过滤就是 MALA。Chewi et al. (2021, [arXiv:2012.12810](https://arxiv.org/abs/2012.12810)) 和 Wu et al. (2022) 的分析，加上 Altschuler--Chewi 的 algorithmic warm start，给出
$$
O\!\left(\kappa d^{1/2}\,\mathrm{polylog}(1/\varepsilon)\right)
$$
的 prior-best high-accuracy 复杂度。这里 warm start 指初始分布不会把过多概率质量塞到目标分布极少出现的区域；它是 mixing theorem 的输入条件，而不是一句“从一个好点开始”。在更强的三阶导数假设下，Metropolized HMC 由 Chen、Gatmiry 和 Jiang (2026, [arXiv:2304.04724](https://arxiv.org/abs/2304.04724)) 的 mixing bound 与 Zhang、Altschuler 和 Chewi (2026, [arXiv:2603.22741](https://arxiv.org/abs/2603.22741)) 的 warm-start construction 合起来达到
$$
O\!\left((\kappa+\kappa_H)d^{1/4}\,\mathrm{polylog}(1/\varepsilon)\right);
$$
后一个 warm-start 结果也曾在 [2026-03-25 日报](#2026-03-25) 中出现。本文在只有 Hessian 两侧界时同时把 $\kappa$ 的 $1$ 次幂降到 $2/3$、把 $d^{1/2}$ 降到 $d^{1/3}$；有三阶控制时再把 $d^{1/4}$ 降到 $d^{1/5}$。这不是同一条 MCMC mixing proof 上的常数优化，而是换掉了 correction 所作用的对象。

作者不再对一个离散 endpoint 做 Metropolis correction，而是对整条 continuous path 的 probability law 做 rejection sampling。设 $Q$ 是容易模拟的 proposal path measure，$P$ 是真正 ULD 的 path measure。Girsanov theorem 的作用可以这样理解：两条扩散若 noise 相同、只有 drift 不同，那么它给出一条完整轨迹在 $P$ 与 $Q$ 下的 density ratio。若把 drift 差标准化为 $\mu_t$，就有
$$
\frac{dP}{dQ}(Z)
=\exp\!\left(-\int_0^T\langle\mu_t,dB_t\rangle
-\frac12\int_0^T\lVert\mu_t\rVert^2dt\right).
$$
形式上，用这个比值做 rejection sampling 就能精确纠正 proposal；障碍是右边依赖不可数多个时刻的整条轨迹，直接求它与“可实现算法”相距很远。

用 Girsanov ratio 做 exact diffusion simulation 并非从本文开始。Wagner (1988) 已提出一维 SDE 的 rejection 方法，Beskos 和 Roberts (2005, [arXiv:math/0503453](https://arxiv.org/abs/math/0503453)) 又发展出有代表性的 exact algorithm；这条线通常利用 Brownian bridge、Poisson thinning，以及一维 drift 经 Itô calculus 后可化成时间积分的特殊结构。它们解决的核心问题是“怎样不留 discretization bias 地画一条 diffusion path”，但没有形成高维 optimization-style query complexity。维数上升后，path likelihood 的波动、接受率和所需轨迹坐标都会一起恶化，简单照搬一维 construction 并不会自动给出 polynomial bound，更不用说次线性的 $d$ 依赖。本文的新定位正是把旧的 change-of-measure 视角接到 FORS 与 ULD acceleration 上：不要求显式知道整条 ratio，只要求能构造一个少量查询、exponential moments 可控的无偏 estimator。

:::aside[“exact” 与最终误差]
标题中的 exact simulation 指 path-space change of measure 给出的无偏纠偏原理：若能直接使用完整的 Girsanov ratio，接受后的路径 law 就是 $P$，不是某个离散 SDE 的 stationary approximation。有限查询算法会对单点 estimator 做 clipping，第一套 proposal 还会离散化 stochastic integral，因此最终 theorem 陈述的是可任意压低的 Rényi 误差，而不是声称有限精度机器输出与 $\pi$ 完全相等。
:::

论文的关键入口是把“整条路径上的指数权重”变成常数次 oracle 查询。作者采用 Chen et al. (2026, [arXiv:2602.01338](https://arxiv.org/abs/2602.01338)) 的 first-order rejection sampling（FORS）。假设 log-density tilt 可写成
$$
w(Z)=\mathbb E_{\xi\sim\Xi}[W(\xi;Z)],
$$
其中每次随机抽一个辅助变量 $\xi$ 后，$W$ 只读取路径上 $O(1)$ 个时刻。FORS 先把 $W$ clip 到 $[-B,B]$，再用 Poisson 个独立估计量的乘积构造接受概率；Poisson generating function 恰好把这个乘积的期望还原成 $e^{\mathbb E W}$。当 $B=O(1)$ 且 $W$ 超出截断区间的 exponential tail 足够小时，一次被校正的 transition 只需常数期望查询，并在 Rényi divergence 下逼近真正 ULD transition。最反直觉的一点是：路径时间网格可以很细，但查询数不必与格点数成正比，因为一次 estimator 只抽一个随机时刻及其相邻端点；算法只需按时间顺序联合生成实际被点到的少数 Gaussian transition，而不必先画出整条离散轨迹。

全局误差也不是把单步 total variation 粗暴相加。作者先证明 corrected kernel $\widehat P_T(z,\cdot)$ 与 exact ULD kernel $P_T(z,\cdot)$ 的双向 Rényi-type error 足够小，再用 Rényi weak triangle inequality 跨 $K$ 步 composition；与此同时，exact semigroup 每经过一段时间都按 accelerated rate 把已有误差向平稳分布压回去。为目标误差 $\varepsilon$，每一步只需把 clipping 与 estimator error 压到约 $\varepsilon/K$ 的尺度，代价进入 $\log(K/\varepsilon)$。这就是“constant expected queries per corrected segment”最终能转成 $K\,\mathrm{polylog}(1/\varepsilon)$，而不会在 composition 时重新掉回 $1/\varepsilon$。

在只假设二阶光滑时，proposal 把一小段 $[0,T]$ 内的 force 冻结在起点：
$$
dX_t=P_tdt,\qquad
dP_t=-\bigl(\nabla V(X_0)+\gamma P_t\bigr)dt+\sqrt{2\gamma}\,dB_t.
$$
这是可以精确采 endpoint 的线性 Gaussian SDE。它与真实 ULD 的 drift 差为
$$
\mu(X_t)=\frac{\nabla V(X_t)-\nabla V(X_0)}{\sqrt{2\gamma}}.
$$
Girsanov ratio 中的 $\int\lVert\mu(X_t)\rVert^2dt$ 可以在均匀随机时刻评价 integrand 得到无偏估计。更麻烦的 Itô integral $\int\langle\mu(X_t),dB_t\rangle$ 经过离散 integration by parts 后，可由 $B_T-B_{jh}$ 与相邻两个位置上的 gradient difference 估计。于是一次 $W$ 仍只需要常数个 gradients。

为什么这会冒出 $\kappa^{2/3}d^{1/3}$，论文的步长约束把来源暴露得很清楚。对典型 phase-space 状态，动量、梯度与噪声的总尺度 $R(z)$ 是 $\widetilde O(d)$；为了让 Girsanov estimator 的 exponential moment 保持常数，需要大致满足
$$
T^3\lesssim \frac{\gamma}{\beta^2d}.
$$
而 accelerated ULD 取 $\gamma\asymp\sqrt\alpha$，总 transition 数约为 $1/(T\gamma)$ 乘对数 mixing factor。把允许的最大 $T$ 代入，恰好得到
$$
\frac1{T\gamma}
\asymp \left(\frac{\beta^2d}{\alpha^2}\right)^{1/3}
=\kappa^{2/3}d^{1/3}.
$$
这条三次方 balance 是主界的解释，不是分析末尾碰巧化简出的指数。直接 discretization 会让更细的 $h$ 逐步兑现成更多 gradient calls；这里细网格只控制单个随机 estimator 的 bias，真正计费的是长度为 $T$ 的 path proposals 数，所以 $\varepsilon$ 只进入 clipping、composition 和 mixing 的对数因子。

有 Lipschitz Hessian 时，简单地冻结 gradient 已经浪费了局部二阶结构。一个自然想法是直接模拟 drift $\nabla V(X_0)+\nabla^2V(X_0)(X_t-X_0)$，但这会要求对 Hessian 做 matrix exponential，单次代价不再像 oracle query 那样轻。作者改用 Picard iteration：先生成第 $\ell-1$ 层近似路径，再令第 $\ell$ 层满足
$$
dP_t^{\ell}=-\left(\nabla V(X_0)
+\nabla^2V(X_0)(X_t^{\ell-1}-X_0)+\gamma P_t^{\ell}\right)dt
+\sqrt{2\gamma}\,dB_t.
$$
因为 Hessian 始终只乘一个已知向量，这个 proposal 可由 generalized first-order oracle 实现。它把 drift remainder 从一阶的 $O(\beta\lVert X_t-X_0\rVert)$ 降到二阶的 $O(\beta_H\lVert X_t-X_0\rVert^2)$。同时，stochastic integration by parts 给出的 estimator 使用
$$
\partial_t\mu_t
=\frac{\nabla^2V(X_t)P_t-\nabla^2V(X_0)P_t^{L-1}}{\sqrt{2\gamma}},
$$
也仍然只需随机时刻的 Hessian-vector products，而不需显式构造 Hessian 矩阵。

因此两个 headline bounds 不能脱离 oracle 模型直接比较。$d^{1/3}$ 结果只把一次 $\nabla V(x)$ 当作一次查询；$d^{1/5}$ 结果把一次 $(\nabla V(x),\nabla^2V(x)v)$ 当作 generalized first-order query。论文指出 Hessian-vector product 可用 gradient finite differences 逼近，但 theorem 本身没有把有限精度与数值稳定性的额外成本展开计入。它的三阶条件也相当有力：
$$
\lVert\nabla^2V(x)-\nabla^2V(y)\rVert_F
\leq \beta_H\lVert x-y\rVert
$$
控制的是所有曲率方向合在一起的 Frobenius variation，而非只控制最大 singular direction。不过这正是此前 $d^{1/4}$ MHMC bound 使用的同类假设，所以 $d^{1/5}$ 的比较是同一 smoothness regime 内的推进；不能把它读成在普通 gradient-oracle、二阶光滑设定下已经无条件得到 $d^{1/5}$。

这里最巧的一步不是 Taylor expansion 本身，而是 Picard proposal 与 sparse path queries 的配合：若显式线性化，二阶信息会把每一步变成昂贵的 dense linear algebra；若仍用 Euler，三阶假设又换不来更长的 path segment。Picard iteration 把“更准确的局部动力学”拆成若干次 matrix-vector oracle 调用，FORS 再确保只生成 estimator 实际触及的时刻。余项的 exponential-moment 分析产生五次方尺度平衡，从而给出 $\kappa_H^{3/5}d^{1/5}$；mixed smoothness、change-of-measure 与有限层 Picard 误差则留下 theorem 中的 $d^{2/11}$ 项。

高阶分析还有一个不能略去的初始化细节。最锋利的 tail bound 先要求 $R_2(\nu\Vert\Pi)=O(\sqrt d)$ 的 crude warm start，但一个容易构造的 Gaussian initialization 通常只有 $O(d\log\kappa)$。作者因此跑两阶段：先用较稳健的参数把 cold start 推到 $O(\sqrt d)$ warmness，再打开高阶 proposal 的较长步长，最终得到完整的 Theorem 4.2。Gaussian 情形尤其说明这种 adaptivity 有实质内容：$\beta_H=0$ 使非线性余项真正消失，算法自动退化到 $\widetilde O_q(\sqrt\kappa)$，而不是机械保留一个 $d^{1/5}$ 账单。

同一个框架还被用于 mirror Langevin。Mirror map 是用位置相关的局部曲率重新标度空间的凸函数，self-concordance 保证这种局部几何沿路径变化得足够平缓；在相应非欧几里得几何里，若能精确模拟经过这种重标度的 mirror Brownian motion，path-space correction 可把此前的 low-accuracy 保证提升为 high-accuracy。对非凸 $\beta$-smooth target，作者又把改进后的 log-concave 子程序接入 proximal reduction：它把原采样任务分解成一系列带二次正则、因而更接近 log-concave 的辅助采样问题。最终，生成 $\mathrm{FI}(\nu\Vert\pi)\leq\varepsilon^2$ 样本的维数依赖从 $d^{1/2}$ 降到 $d^{1/3}$，复杂度为 $\widetilde O(\beta d^{1/3}K_0/\varepsilon^2)$，其中 $K_0$ 是初始 KL divergence；这里 $\mathrm{FI}$ 是 relative Fisher information，衡量输出分布与目标分布的 log-density gradients 平均相差多大，适合表达“样本已接近一阶平稳”的保证。对我来说，更值得留下的是方法上的尺度转换：过去为了 high accuracy，人们通常在“离散一步之后如何 accept/reject”上做文章；这篇把随机化放进 Radon--Nikodym derivative（也就是两种 path laws 的 density ratio）的估计本身，让一条连续路径可以只被稀疏地查看，却仍接受整条路径的统计责任。此后再问更高阶导数能否继续改善维数指数，核心将不是写出更长的 Taylor formula，而是能否找到同样只需少数 path coordinates、同时有可控 exponential tails 的 density-ratio estimator。
