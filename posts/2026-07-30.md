## 编辑按语

今天的三篇论文覆盖 average-case graph algorithms、原地排序和 quantum information 三个不同方向，并没有直接的技术联系。图着色工作在均匀 $k$-可着色图上给出 $\Theta(nk)$ 的匹配上下界，常数 $k$ 时只需线性平均时间；排序工作同时核算 comparisons 与 data moves，在严格 in-place 模型下实现高概率 $n\lg n+O(n)$ 次比较和始终 $O(n)$ 次搬移。

量子谱估计论文则否定了 Keyl--Werner estimator 的最优性，以 relative-error tomography 配合 local moment matching，把常数误差下的 copy complexity 降到 $o(d^2)$。三篇分别追问典型图实例需要读取多少信息、有限工作区中怎样保存顺序信息，以及不知道 eigenbasis 时如何只学习 spectrum。

## Graph k-Coloring in Average Sublinear Time [arXiv:2607.26592](https://arxiv.org/abs/2607.26592)

这篇论文研究的是 average-case graph $k$-coloring：输入是一张从所有 $n$ 顶点、可用至多 $k$ 种颜色着色的 labeled graphs 中均匀选出的图，算法通过 adjacency-matrix query 询问任意一对顶点是否相邻，目标是输出整张图的 proper $k$-coloring。Marcussen、Pyne、Rubinfeld、Shapira 和 Tauber 证明，当 $k\le n^{1/37}$ 时，存在对每一张 $k$-colorable graph 都正确的随机算法，其平均运行时间为 $O(nk)$；另一方面，任何具有这种 worst-case correctness 的随机或确定性算法，在 $k\le n^{1/3}$ 时平均都需要 $\Omega(nk)$ 时间。因此在两者重叠的参数范围内，

$$
\overline T_{n,k}=\Theta(nk).
$$

特别地，固定 $k\ge 3$ 时复杂度是 $\Theta(n)$。典型输入有 $\Theta(n^2)$ 条边，adjacency matrix 也有 $\Theta(n^2)$ 个位置，所以算法连输入的常数比例都不读取；这是 graph $k$-coloring 首个常数 $k$ 的 average subquadratic algorithm。

先把问题与通常的 worst-case coloring 分开。Proper $k$-coloring 是一个映射 $c:V\to[k]$，要求每条边 $\{u,v\}$ 都满足 $c(u)\ne c(v)$。$k=2$ 时只需沿每个连通分量做 BFS，交替染色即可；每个固定 $k\ge3$ 的判定问题则是 NP-complete。Worst-case 算法必须处理人为构造的困难图，昨天的 [2026-07-29 日报](#2026-07-29) 还讨论了一个很不同的进展：对每个固定 $k$，最坏情形时间终于从通用的 $O^*(2^n)$ 降到某个 $O^*((2-\varepsilon_k)^n)$。本文没有推翻这种 worst-case hardness；它承诺输入已经 $k$-colorable，并把时间对所有这样的图取平均，同时仍要求每个单独输入都得到正确答案。

Average-case 研究存在的理由，不是断言现实中的图一定服从某个方便分布，而是把两种成本分开：一种来自少数精心构造的困难配置，另一种来自问题在典型结构上仍必须读取的信息量。Uniform $k$-colorable ensemble 是这方面最早、也最干净的基准之一——它不额外植入算法可见的解，也不挑选某个启发式特别擅长的实例生成器。若一个 NP-hard 问题在这个集合上仍要二次时间，障碍可能只是输入太大；若能做到线性时间，就说明绝大多数边对恢复解并不提供不可替代的信息。本文给出的 matching lower bound 又使这种区分不只停留在“某个算法很快”：$\Theta(nk)$ 是该模型本身所需的信息成本。

这个正确性与平均时间的量词顺序很重要。它不是“算法能给大多数图着色，少数图可以答错”，而是“所有图都正确，只允许少数图跑得极慢”。如果快速过程失败，算法最终会调用 $O(2^n)$ 的精确算法，所以要把这部分对期望的贡献压到多项式，失败图的比例必须小到约 $2^{-n}$；$1-1/\mathrm{poly}(n)$ 的 high-probability guarantee 远远不够。

:::aside[本文的 average-case 模型]
令 $\mathcal G_{n,k}$ 为顶点集 $[n]$ 上所有 chromatic number 至多 $k$ 的 labeled graphs。对随机算法 $A$，本文研究
$$
\overline T_A(n,k)=
\frac{1}{|\mathcal G_{n,k}|}
\sum_{G\in\mathcal G_{n,k}}
\mathbb E_r[T_A(G;r)].
$$
算法以常数时间查询 adjacency matrix 的一个位置。随机性是 Las Vegas 式的：输出必须是可验证的 proper coloring，不能用小错误率换速度。若改成从所有 graphs 均匀抽样，几乎每张图都不是常数-$k$-colorable，“快速判定不可着色”反而会使问题失去这里关心的内容。
:::

这条研究线的起点是 Dyer 和 Frieze (1989) 的 [polynomial expected-time 工作](https://doi.org/10.1016/0196-6774(89)90001-1)。他们首次证明 uniform $k$-colorable model 上可以在多项式平均时间内找到着色，对常数 $k$ 得到 $O(n^2)$。Kučera (1995) 随后把界改进为 $O(n^2/k)$，适用于 $k=o(n/\log^2 n)$（[论文页面](https://doi.org/10.1016/0166-218X(94)00103-K)）。他的算法用两点的共同邻居数判断它们是否应属于同一颜色类；但当 $k=O(1)$ 时仍要二次时间。Turner (1988) 等更早的传播算法能够快速着色 $1-1/\mathrm{poly}(n)$ 比例的图，却不能与指数时间 fallback 组合成 polynomial average time，这正说明“almost all inputs are easy”不自动等于“平均运行时间小”。

把主线的定量变化放在一起看，本文解决的缺口很直接：

| 结果 | 输入范围 | 平均运行时间 |
| :-- | :-- | :-- |
| Dyer--Frieze (1989) | 常数 $k$ | $O(n^2)$ |
| Kučera (1995) | $k=o(n/\log^2 n)$ | $O(n^2/k)$ |
| 本文，随机 | $k\le n^{1/37}$ | $O(nk)$ |
| 本文，确定性 | $k\le n^{1/37}$ | $\widetilde O(nk)$ |
| 本文下界 | $k\le n^{1/3}$ | $\Omega(nk)$ |

这里的“随机 $O(nk)$”与“确定性 $\widetilde O(nk)$”都保证所有 promised inputs 正确。随机上界与下界精确匹配；确定性版本还多 polylogarithmic factors，去掉它们仍是论文明确留下的问题。$k$ 的适用范围也尚未与下界的 $n^{1/3}$ 接上。

为什么一张均匀随机的 $k$-colorable graph 会容易？最方便分析的 planted model 先把顶点近似均分成 $A_1,\ldots,A_k$，同一类内禁止边，不同类间的每条边独立地以概率 $1/2$ 出现。于是图很稠密，而且其 planted coloring 通常被跨类边强烈地“锁住”：一个属于 $A_i$ 的顶点对每个 $A_j$、$j\ne i$ 都有许多邻居，只有 $A_i$ 是系统性没有边的方向。若已经知道每个颜色类的一小批代表点，只要不断随机抽代表并查询邻接，就可以排除 $k-1$ 个错误颜色，而不必扫描该顶点的整个邻域。

Planted model 只是分析中间站，不是主定理悄悄更换后的输入分布。固定 partition $A$ 后，它确实等于 uniform graph conditioned on $A$ 是一套合法 coloring；但同一张图可能有多套 colorings，因此“先均匀选 coloring、再均匀选与它相容的图”会按 coloring 数重复计权。颜色类也可能高度不平衡。论文最后必须证明典型图的 coloring 数不会造成大的 size bias，并证明不平衡 partition 支持的图指数更少，才能把 planted 结论转回真正的 graph-uniform 结论。

难点恰好在“已经知道代表点”这句话。Sublinear 算法不能先读完整图再求一个可靠 coloring；若从一个有多种着色方式的小子图出发，局部传播可能选择了无法扩展到全图的那一种，而且算法看得太少，未必能发现错误。这里 uniquely $k$-colorable 的意思是：忽略颜色名称的整体置换后，顶点只有一种划分成 $k$ 个 independent sets 的方式。只有这样的 core 才能充当全图的颜色坐标，保证从 core 推出的每个局部颜色都与任意全局解一致。

作者此前在 hypergraph 2-coloring 中已经发展过“小 core 加两轮传播”的路线，并得到每次查询平均 $O(1)$ 的 coloring oracle（Marcussen et al. (2025)，[arXiv:2507.10691](https://arxiv.org/abs/2507.10691)）。但直接把那里容易验证的 complete core 搬到 $k$ 色图，会因为这种 core 的密度随 $k$ 指数下降而先付出 $2^{\Omega(k)}$ 次采样。本文的新入口不是寻找更明显的 core，而是给典型的随机小图设计一个只需 $\mathrm{poly}(k)$ 时间检查的 **unique-colorability certificate**。

算法抽取

$$
\nu=\Theta(k^9\log k)
$$

个顶点作为候选 core $H$，限时运行 Kučera 的旧算法得到颜色类 $H_1,\ldots,H_k$，再检查三类条件。令 $s=|H|$、$\varepsilon=1/(10k)$：各 $H_i$ 的大小应为 $(1\pm 1/(100k))s/k$；每个 $u\in H_i$ 到另一类 $H_j$ 的 degree 应为

$$
(1\pm\varepsilon^4)\frac{s}{2k};
$$

同一 $H_i$ 中任意两点 $u,v$ 到 $H_j$ 的共同邻居数，即 codegree，应为

$$
(1\pm\varepsilon^3)\frac{s}{4k}.
$$

后两个中心值正是两个独立概率：一条跨类边出现的概率为 $1/2$，两条同时出现的概率为 $1/4$。这些统计都只发生在 $\mathrm{poly}(k)$ 大小的 core 内，因此可以完整检查而不碰 $n^2$ 级输入。

Degree 与 codegree 条件为什么足以证明着色唯一，是整篇最关键的结构论证。Alon et al. (1994) 的 degree--codegree criterion 蕴含每一对颜色类之间都具有 $\varepsilon$-regularity：不只全局边密度接近 $1/2$，任取占各自颜色类至少 $\varepsilon$ 比例的两个子集，它们之间的边密度仍接近 $1/2$。若还有另一套 coloring $D_1,\ldots,D_k$，某个新颜色类必然同时穿过旧颜色类 $H_a,H_b$。这两个交集同属 $D_i$，所以它们之间必须完全没有边；但只要两个交集都不太小，regularity 又强迫其间存在大量边，立即矛盾。若其中一个交集极小，另一边几乎吞下整个旧颜色类，则那个少数顶点到大类的 degree 会显著低于 $s/(2k)$，同样违反证书。于是局部可查的二阶统计排除了所有全局替代 coloring。

我认为这里比“使用 regularity”更值得注意的是 regularity 的用法：作者并没有运行代价巨大的 regularity partition algorithm，而是让随机 core 天然满足 degree/codegree 集中，再用一个 implication 把这些统计变成 uniqueness certificate。Regularity 在这里是一张证明证书正确的桥，不是算法要显式构造的分解；这正好保住了对 $k$ 的多项式依赖。

一旦得到 uniquely colored core，后面的传播就很直观。若顶点 $v$ 对除 $H_i$ 外的每个 core color class 都有邻居，那么 $v$ 不可能使用那些颜色，只能取 $i$。作者加强为 strongly inferred：$v$ 对除一个颜色类外的每类至少连接其中 $1\%$ 的顶点。算法对每个 $v$ 随机选择尚未排除的颜色类，再随机查询该类中的 core vertex；看到一条边就排除一个颜色。典型图上每个排除动作只需常数次尝试，总计 $O(k)$ probes。第一轮由 core 给每个真实颜色类中的至少 $99\%$ 顶点定色，得到大集合 $S_1,\ldots,S_k$；第二轮再从这些 $S_i$ 中抽样，给剩余顶点排除错误颜色。两轮总预算是 $O(nk)$。

支撑这段算法的不只是“对一个固定 core 集中”，而是一个对所有可用 core 同时成立的 structural theorem。论文称图为 $(\sigma,B)$-linked，如果存在一套近似均衡的 coloring，使得任取每类大小在 $[\sigma,O(k\log k)]$ 的代表集，第一轮都能 strongly infer 每类至少 $99\%$ 的顶点；任取每类覆盖至少 $90\%$ 的已着色集合，第二轮又能 strongly infer 除至多 $B$ 个顶点外的所有顶点。Theorem 8 证明，对 $k\le n^{1/36-\delta}$、$\sigma\ge c_\sigma\log k$，

$$
\Pr[\text{图有许多 good cores 且为 }(\sigma,B)\text{-linked}]
\ge
1-\exp\!\left(-\Omega\!\left(\frac{n\sigma}{k}\right)\right)
-\exp\!\left(-\Omega\!\left(\frac{n(B+1)}{k}\right)\right)
-2k^{-2n}.
$$

“许多”在这里是至少 $2/3$ 的 $\nu$-vertex induced subgraphs 都是 good cores，所以随机抽常数次便能找到一个。证明先在 planted partition model 中用 Chernoff bounds 控制传播性质；这类界说明大量独立随机边的计数偏离期望值很多的概率会指数衰减。随后用 McDiarmid inequality 控制 good cores 的总数。后者是一条 bounded-differences concentration inequality：若一个由许多独立随机边决定的计数，在翻转任意一条边时最多改变有限量，那么该计数偏离期望很多的概率也会指数衰减。最后还要回到 uniform $k$-colorable model：Dyer--Frieze 的计数结果表明随机图的 colorings 数期望至多为常数，而显著不平衡的 colorings 所支持的图数指数更少；因此按 planted coloring 计权与按 graph 均匀计权之间的偏差可以压住。

$1/37$ 这个看似奇怪的指数也能从证明中追出来。Core 大小是 $\nu=\Theta(k^9\log k)$，改变一条边至多影响 $\binom{n-2}{\nu-2}$ 个候选 cores；McDiarmid 给出的坏事件大致是 $\exp(-\Omega(n^2/\nu^4))$。为了把它压到 $k^{-2n}$，需要 $k^{36}$ 明显小于 $n$，正式分析先得到 $k\le n^{1/36-\delta}$，主定理再取整洁的 $n^{1/37}$。也就是说，目前限制 $k$ 的环节是“以足够强的尾界同时认证许多 $\Theta(k^9\log k)$ cores”，而不是每个顶点只花 $O(k)$ 次查询的传播阶段。

平均时间分析还需要一层不太常见的保险结构。对概率 $1-\exp(-\Omega(n/k))$ 的 “awesome” graphs，取 $\sigma=\Theta(\log k)$、$B=0$，一次 $O(nk)$ 迭代以至少常数概率完成两轮传播。若图不 awesome，不能立即调用 $O(2^n)$ fallback，因为 $\exp(-\Omega(n/k))$ 还不够小；算法先进入一个极慢但有限的第二阶段，枚举所有 $\nu$-vertex cores，改用完整邻接检查，并允许最后留下 $B=\Theta(k\log k)$ 个点再穷举颜色。这个阶段覆盖除 $3k^{-2n}$ 比例之外的 “okay” graphs。于是三部分的期望成本呈现为

$$
O(nk)
+\exp(-\Omega(n/k))\cdot n^{O(\nu)}
+3k^{-2n}\cdot O(2^n)
=O(nk).
$$

这里最容易被一句“失败就 brute force”掩盖掉的，其实是中间那层 okay graphs；没有它，指数 fallback 会毁掉平均界。确定性版本则利用 uniform distribution 的 vertex symmetry，把随机 core 换成固定的若干互不相交候选集，把邻接采样换成逐渐增大的固定 sample sets，得到 $\widetilde O(nk)$。同一结构还能实现 Local Computation Algorithm：当用户只问某个顶点的颜色时，算法不生成全部 $n$ 个答案，而以 $\mathrm{poly}(k)$ 的平均 probe complexity 返回一个与同一全局 coloring 一致的答案。这延续了 Rubinfeld et al. (2011) 提出的 LCA 目标（[arXiv:1104.1377](https://arxiv.org/abs/1104.1377)），也说明全局算法中的线性 $n$ 因子主要来自必须输出 $n$ 个颜色。

最后的 $\Omega(nk)$ 下界与上面的随机图结构完全无关，反而是一个适用于每张输入的 query adversary。把算法已经询问过的 vertex pairs 看成一张 query graph。若总查询数是 $o(nk)$，则有常数比例的顶点 query degree 小于 $k-2$；按算法输出的 $k$ 个颜色类做 pigeonhole，在同一颜色类中可找到两个这样的顶点 $u,v$，且 $\{u,v\}$ 从未被询问。这里 $k\le n^{1/3}$ 保证该颜色类大到不能让所有点对都已查询。

关键不是直接向原输入加边——那可能破坏 $k$-colorability——而是保持整个 query transcript 不变，重新补全未查询的位置。保留所有已查询到的边，加入未查询边 $\{u,v\}$，其余未查询位置都设成 non-edge。由于 $v$ 的已知邻居涉及至多 $k-2$ 种颜色，可以给 $v$ 换成一种既不同于 $u$、又未被这些邻居使用的颜色；所以补全后的图仍然 $k$-colorable。算法看到的每个答案都没变，必然输出原 coloring，却把 $u,v$ 染成同色而违反新边。对随机算法固定 coins 后同一论证成立，因此 worst-case correctness 强迫每条执行路径都做 $\Omega(nk)$ 次查询。

这个 lower bound 也给出了理解 $nk$ 的最好方式：算法并不是因为典型图有 $\Theta(n^2)$ 条边才花时间，而是必须为 $n$ 个顶点各取得足够信息，在 $k$ 个颜色中排除错误选项。上界最巧的一步，是先用一个 $\mathrm{poly}(k)$ 大小、可认证唯一性的 core 给这些颜色建立全局坐标系；坐标系一旦可靠，稠密输入中绝大多数边就从“需要读取的数据”变成了“随手抽几次就能命中的冗余证据”。

## Upper Bounds for In-Place Sorting with Minimal Moves [arXiv:2607.27040](https://arxiv.org/abs/2607.27040)

这篇论文研究的是 comparison-based sorting 的三重资源优化：输入是一个含 $n$ 个可比较元素的数组，算法只能通过两两比较获知 key 的顺序，既要原地重排数组，又要同时压低 comparisons 和 data moves。这里的 in-place 是严格意义的：除输入数组外，只允许一个临时元素位置，以及 $O(1)$ 个能存索引、计数器和指针的 $\Theta(\lg n)$-bit words；一次 move 指把整个数据元素写入另一个位置，交换两个元素因而计作三次 moves。Words 可以保存“第几个位置”或一个计数，却不能偷偷保存待排序的完整元素；搬动索引不计 data move，但相关的 word arithmetic 在定理中另行核算。这个区分使模型能刻画“大 record、小 key”的情形，也防止用指针数组绕过 move 限制。Xu 和 Chick 的随机算法对每个输入都保持正确，并且

$$
\Pr\!\left[C(n)\le n\lg n+O(n)\right]\ge 1-\left(\frac{27}{32}\right)^n,
\qquad
M(n)=O(n)
$$

后一个界对所有随机选择都成立。算法还使用 $O(n\lg n)$ 次 word arithmetic operations。其确定性版本则对每个整数 $2\le t\le \lg^*n-1$ 给出 worst-case trade-off

$$
C(n)\le n\lg n+O\!\left(n\lg^{(t)}n\right),
\qquad
M(n)=O(tn).
$$

因此，随机版本首次在严格 in-place 模型中同时做到始终线性 moves 和以指数高概率成立的 $n\lg n+O(n)$ comparisons；确定性版本则把此前的加性 $O(n\lg\lg n)$ 项继续压低。

为什么要把 comparisons 和 moves 分开数？如果数组里放的是很大的 records，比较两个短 key 可能便宜，搬动整个 record 却会触发大量内存传输；反过来，一个昂贵 comparator 又会让 comparisons 成为瓶颈。经典算法通常只擅长其中一边：selection sort 每轮找最小值，只移动最终选中的元素，但要做 $\Theta(n^2)$ 次比较；mergesort 可以接近最优比较数，却通常需要线性额外空间并反复搬动数据；heapsort 是 in-place 的，但 moves 仍是 $\Theta(n\lg n)$。这不是偶然的实现差异。少做 comparisons 的算法需要保留已经获得的顺序信息，最自然的保存方式是建树、分桶或维持有序 runs；少做 moves 的算法又希望一个元素一旦放下便尽量不再碰它。在常数 workspace 下，保存信息的载体只能是输入元素自身的相对位置，改变“数据结构”往往恰好意味着搬动 records。本文要化解的就是这个循环：不能先取一个 comparison-optimal sort，再用普通 in-place 技巧压空间，因为 conversion 本身可能把 move 账重新抬高。

比较下界来自 decision tree：对互异元素的 $n!$ 种可能顺序，二叉比较树至少要有 $n!$ 个叶子，所以即使平均情形也需要

$$
\lg(n!)=n\lg n-(\lg e)n+O(\lg n)
=n\lg n-1.4427\ldots n+O(\lg n)
$$

次比较。这里“达到信息论下界的加性线性精度”指上、下界只差 $O(n)$，并不声称已经找到了线性项的最佳常数。Moves 也有独立障碍：worst-case permutation 可以由几乎全是二元环的 cycle structure 构成，而算法只有一个临时元素位置，每交换一对就要三次写入；Munro 和 Raman (1996) 由此得到至少 $\lfloor 3n/2\rfloor$ moves 的下界（[论文页面](https://doi.org/10.1016/0304-3975(95)00225-1)）。所以 $O(n)$ moves 是渐近最优，本文标题里的 “minimal” 应按这个意义理解。

这条研究线经历过两次目标升级。Munro 和 Raman (1992) 首先系统提出 minimum-data-movement sorting，并在平均情形给出同时使用 $O(n\lg n)$ comparisons、$O(n)$ moves 和常数额外空间的肯定答案（[论文页面](https://doi.org/10.1016/0196-6774(92)90045-E)）。Franceschini 和 Geffert (2005) 随后解决 worst-case 的量级问题：首个严格 in-place、$O(n\lg n)$ comparisons、$O(n)$ moves 的算法见 [arXiv:cs/0305005](https://arxiv.org/abs/cs/0305005)。但 $O(n\lg n)$ 隐藏了比较数的首项系数；若真正以信息论下界为基准，目标应是首项恰为 $n\lg n$，而不是 $2n\lg n$ 或别的常数倍。Geffert 和 Gajdoš (2011) 把界推进到

$$
n\lg n+O(n\lg\lg n)\ \text{ comparisons},
\qquad
(34+\varepsilon)n\ \text{ moves},
$$

且同时适用于 average case 和 worst case（[论文页面](https://doi.org/10.1007/978-3-642-18381-2_21)）；如何去掉那一层 $\lg\lg n$，此后一直没有答案。

| 算法 | comparisons | moves | 保证 |
| :-- | :-- | :-- | :-- |
| Geffert--Gajdoš (2011) | $n\lg n+O(n\lg\lg n)$ | $(34+\varepsilon)n$ | worst case |
| 本文 randomized | $n\lg n+O(n)$ | $O(n)$ | comparison bound 以 $1-2^{-\Omega(n)}$ 概率成立；move bound 始终成立 |
| 本文 deterministic | $n\lg n+O(n\lg^{(t)}n)$ | $O(tn)$ | worst case |

“以指数高概率”修饰的是资源上界，不是允许排序出错。随机执行中，所有结构 invariant 和最终次序都确定无误；坏事件是为了寻找空位而做了过多次无效 probes。这个保证也比单纯的 expected $n\lg n+O(n)$ 强：失败概率随 $n$ 指数下降，而不是只靠期望值容忍很长的尾部。另一方面，$O(n\lg n)$ arithmetic operations 提醒我们，论文优化的是 comparison/move model 的两项关键成本，并没有声称实际 wall-clock time 已被证明线性。

:::aside[迭代对数参数]
$\lg^{(1)}n=\lg n$，$\lg^{(t)}n=\lg(\lg^{(t-1)}n)$；$\lg^*n$ 是反复取对数直到结果不超过 $1$ 所需的最少次数。固定 $t=2$ 时，确定性界回到 $n\lg n+O(n\lg\lg n)$；任取固定 $t>2$，moves 仍是 $O(n)$ 而加性比较项更小。若令 $t$ 随 $n$ 增长到约 $\lg^*n$，可以把比较项降到 $O(n)$，代价变为 $O(n\lg^*n)$ moves，因而还没有同时达到 worst-case 的两个目标。
:::

因此，确定性结果不是一个孤立的新 upper bound，而是一条可调曲线。若研究者坚持渐近线性 moves，可先固定任意常数 $t>2$，把旧的双对数损失换成三重或更深的迭代对数；若 comparisons 更昂贵，则可以继续增大 $t$，让每个元素多经历几次批量搬运。这也精确标出了随机版本多做了什么：它跨过的不是整个 $O(n\lg\lg n)$ 技术体系，而是这条曲线上最后一个无法同时归零的局部 trade-off。

论文先允许自己拥有一块额外 buffer，再把这块 buffer 从输入内部“借”出来。这个分层很重要，因为比较数的精细核算都发生在前半段。设要排序的 active block 有 $m$ 个元素，暂时给算法至少 $3m-1$ 个可与 active elements 通过一次比较区分的 buffer elements，以及 $m/\lg^2m$ 个 bits。“Active”只是当前真正要排的元素，“buffer”则是从数组别处借来、最终必须原样归还为某种排列的元素；二者的 key 落在一个分隔值两侧，所以用一次比较就知道一个槽当前装的是数据还是空闲资源。

这块内存分成 frame、cache 和 segment 三部分。数据结构的 lower level 是若干无序 segments，每段容量

$$
s=\Theta(\lg^4m).
$$

每个 segment 始终至少半满，因此 segment 数量只有 $O(m/s)$；它们在物理内存中可以乱序摆放，由 bit vector 里的隐式指针定位。Frame 构成 upper level，保存按 key 排序的 representatives。若第 $i$ 个 representative 为 $f'_i$，对应 segment 为 $S_i$，核心 ordering invariant 是

$$
f'_i\le x\le f'_{i+1}
\qquad\text{对每个 }x\in S_i.
$$

也就是说，段内暂不排序，但所有元素已经被路由到正确的全局区间。插入元素 $x$ 时，先在 representatives 中找到它属于哪个 interval，再放进该段的 cache line；cache 攒够一批才一次性写入 segment。段满后用线性时间 selection 找中位数，只划分大小关系而不把整段排好，再把两半放入两个半满段，并将中位数提升为新的 representative。于是昂贵的全局有序结构只管理每 $\Theta(\lg^4m)$ 个元素中的一个，绝大多数数据一直留在无序小段里。

这种设计类似“稀疏上层索引加密集下层桶”：上层只保存少量分界代表，下层容纳尚未排序的大多数元素。但这里最难的不是渐近搜索时间 $O(\lg m)$，而是把每次搜索精确控制到 $\lg(\text{representative 数})+O(1)$ 次 comparisons。候选 interval 有 $s_\#+1$ 个，信息论上本来就要约 $\lg s_\#$ 次比较；真正允许的浪费只有常数。只要每个元素多付 $\Theta(\lg\lg m)$，总账就会重新出现 $\Theta(m\lg\lg m)$。作者的新 ordered set 把 representatives 放在常数大小为 $8$ 的 gaps 中，每个 gap 前端是排好序的 active representatives，后端留 buffer slots；gap 的数量保持为二的幂。搜索先对各 gap 的首元素做一次 binary search，再在目标 gap 的八个位置里做三次比较，于是 Lemma 2.1 给出精确代价

$$
\lfloor\lg s_\#\rfloor+3,
$$

其中 $s_\#$ 是 active representatives 的数量。插入 representative 本身可以昂贵得多：当 gap 填满，算法在一个只存在于逻辑上的二叉 segment tree 中向上寻找失衡节点，再把对应区间重新均匀铺开，得到摊还的 $O(\lg^3m)$ comparisons 和 moves；这里“摊还”是把偶尔发生的昂贵重建成本平均到许多次便宜操作上。作者没有要求 ordered-set update 本身也最优：representative 只在一个含 $\Theta(\lg^4m)$ 个元素的 segment 分裂时才插入，所以总共只有 $O(m/s)$ 次。把一个 polylogarithmic 的昂贵更新乘上这个稀疏频率，总成本仍是 $o(m)$。

这套结构使主比较账出现一个几乎没有余量的“对数拼接”。所有元素被分派到 segments 时，Lemma 2.4 的代价是

$$
m\lg\left\lfloor\frac{m}{s}\right\rfloor+O(m).
$$

抽取时按 representatives 的顺序依次处理 segments，并在每个 segment 内部排序。因为每段至多 $s$ 个元素，Lemma 2.5 把这部分压到

$$
m\lg s+o(m).
$$

两项相加正好恢复 $m\lg m+O(m)$。这个等式也说明为何 segment 大小必须两头兼顾：$s$ 太小会让 representatives 太多、更新成本失控，$s$ 太大又使段内子程序无法把控制信息塞进常数个 words。

这一步还要求 small sort 自己足够锋利。作者对 $m'=O(\lg^c m)$ 大小的段使用 $k$-way mergesort，把 run pointers 和 selection tree 打包进 $O(1)$ 个 machine words，并对最初的小 runs 使用 table sort。这里的 table sort 是 indirect sorting：先给 run 中每个元素建立一个短 pointer，只对 pointers 做 mergesort，知道最终位置后再把每个 record 搬一次；中间改写 pointers 只算 word operations，不算 data moves。Selection tree 则是一棵以 $k$ 个 runs 的当前首元素为叶子的锦标赛树，每输出一个最小值只需沿一条根叶路径更新，恰好花约 $\lg k$ 次 comparisons。普通多路归并若机械地让每一轮都按 $m'\lg k+O(m')$ 计费，轮数乘上的线性误差会太大；论文单独利用最后一轮实际剩余 runs 更少，把最后一层的 selection tree 缩短，才把总数收紧为

$$
m'\lg m'+o(m')\ \text{ comparisons}
\quad\text{和}\quad
O(m')\ \text{ moves}.
$$

如果这里只调用一个普通的 $O(m'\lg m')$ 子程序而不控制低阶项，所有 segments 累积起来仍可能多出 $O(m\lg\lg m)$。论文强调，optimal representative search、cache 和 small sort 分别消掉旧算法中一个独立的 $O(n\lg\lg n)$ 来源，少一个都不能得到主定理。

Cache 是随机与确定性版本唯一真正分叉的地方。一个 segment 的物理地址编码在隐式 bit vector 里，读取完整指针要 $\Theta(\lg m)$ 次 comparisons；算法因此用容量 $g=\Theta(\lg m)$ 的 cache line 攒批，满了才解引用一次指针，把单元素的地址开销摊成 $O(1)$。随机 cache line 用 $2g$ 个位置容纳至多 $g$ 个 active elements，load factor 永远不超过 $1/2$。插入时均匀随机 probe，直到碰到 buffer slot；每次失败只做一次比较，真正找到空位后才搬动元素。即使连续 probes 并不独立，每一步条件成功率仍至少是 $1/2$，所以总失败次数 $p$ 被“取得 $m$ 次成功、成功率 $1/2$”的 negative-binomial distribution 支配。Chernoff bound 给出

$$
\Pr[p>2m]\le \left(\frac{27}{32}\right)^m.
$$

这解释了主定理中两种看似不对称的保证：异常随机串只会让算法多做 probes，不会多搬元素，故 comparisons 是 exponentially high probability，moves 却始终为 $O(m)$。随机化没有参与 pivot、分段或正确性判断；它只负责在一个至少半空的小数组里找空位。

确定性 cache 无法免费找到这个空位，作者改用逐级增大的 cache blocks。Level $i$ 把前一级攒出的整批元素放入下一个尚空的 subblock；各层大小呈 tower-like 增长，使第二层以后每元素承担的 binary-search cost 构成收敛几何级数。真正不可消去的是第一层：Lemma C.2 将每个元素的额外代价界为至多

$$
\lg^{(t)}m+2\ \text{ comparisons}
\quad\text{和}\quad
3t\ \text{ moves}.
$$

这正是最终 $O(n\lg^{(t)}n)$ 与 $O(tn)$ trade-off 的来源。换句话说，论文不是把整个随机算法黑盒 derandomize；其余结构本来就是确定性的，唯一需要替换的是 cache occupancy 的处理方式。

最后还要偿还那块“额外内存”。作者沿用 in-place conversion 的经典思路，先取出约

$$
v=\left\lceil\frac{n}{\lg^2n}\right\rceil
$$

个最小元素和同样多的最大元素，分别放在数组两端。第 $i$ 对元素的左右次序编码一个 bit，交换这一对就能改写该 bit；读取和写入这种 bit 会分别转化为常数次 element comparisons 和 moves，但没有申请真实空间。若两端边界不能严格区分，夹在中间的元素都等于同一 key，当前布局已经有序，可以直接结束，这也处理了大量重复 key 的退化情形。

随后对大小为 $n_i$ 的当前未排序区间选择 rank 约为四分之一的 pivot $q$。小于 $q$ 的 block 大小 $m_i$ 至多为 $n_i/4$，大于等于 $q$ 的 block 至少有 $3n_i/4-1\ge 3m_i-1$ 个元素，恰好满足核心算法的 buffer 需求；二者又能靠与 $q$ 比较而区分。算法用大块作工作区排好小块，把小块和所有等于 $q$ 的元素固定到最终位置，再在剩余的大元素上重复。

这个 conversion 不只是空间上的收尾。未排序区间每轮缩到至多原来的 $3/4$，所以 selection 与 partition 的扫描总量是 $O(n)$；各轮被真正送入核心算法的小块总大小至多 $n$。又因为 $m\lg m$ 和 $m\lg m+m\lg^{(t)}m$ 都是 superadditive 的，即对主成本函数 $F$ 有 $F(a)+F(b)\le F(a+b)$，把总量至多 $n$ 的若干小实例分开排序不会超过一个 $n$ 元素实例的主项。于是“从输入借空间”的过程只增加 $O(n)$ comparisons 和 moves，精细的 $n\lg n$ 首项没有被 conversion 冲掉。

本文的算法不稳定：equal keys 的原始相对次序可能改变。Franceschini (2007) 已经做到 stable、in-place、$O(n\lg n)$ comparisons 与 $O(n)$ moves（[论文页面](https://doi.org/10.1007/s00224-006-1311-1)），但 stable 情形能否把比较数进一步收紧到 $n\lg n+o(n\lg n)$ 仍未解决。对本文自身更尖锐的未决点则已经被压缩成一个很局部的问题：能否在最坏情形下，以 $O(1)$ amortized comparisons 把元素放进这个半空、大小 $\Theta(\lg n)$ 的隐式 cache line，同时不让同一元素穿过越来越多层？只要这一步仍需在“随机探测”与“多搬几层”之间二选一，worst-case 的 $n\lg n+O(n)$ comparisons 和 $O(n)$ moves 就还不能同时出现。

## The Keyl-Werner algorithm is not optimal for spectrum estimation [arXiv:2607.27117](https://arxiv.org/abs/2607.27117)

这篇论文研究的是 quantum state spectrum estimation：给定未知 $d$ 维量子态 $\rho$ 的 $n$ 份独立拷贝 $\rho^{\otimes n}$，允许对这些拷贝做联合的、跨拷贝纠缠的测量，目标不是恢复整张密度矩阵，而只输出按降序排列的特征值向量 $\alpha=(\alpha_1,\ldots,\alpha_d)$。Pelecanos、Spilecki、Tang 和 Wright 证明存在算法输出概率向量 $\widehat\alpha$，使得
$$
\Pr\!\left[d_{\mathrm{TV}}(\alpha,\widehat\alpha)\leq \varepsilon\right]\geq 0.99,
\qquad
n=O\!\left(
\frac{d^2(\log\log d)^2}{\varepsilon^4(\log d)^2}
\right),
$$
其中 $d_{\mathrm{TV}}(\alpha,\widehat\alpha)=\frac12\sum_i|\alpha_i-\widehat\alpha_i|$。因此当 $\varepsilon=\omega(\log\log d/\log d)$，特别是 $\varepsilon$ 为常数时，copy complexity 首次降到 $o(d^2)$；此前最好的 Keyl--Werner 算法需要 $\Theta(d^2/\varepsilon^2)$ 份拷贝，而且这个界对该算法本身是 tight 的。

这里的 copy complexity 只数消耗了多少份同态拷贝，不直接核算实现联合测量的电路规模；它回答的是量子统计中的信息论问题：至少要接触多少次同一个未知态，才有足够信息估计其谱。Total variation distance 则把两组特征值当作经典概率分布比较，表示把一组分布改造成另一组所需搬移的总概率质量。因而主定理不是只估计 entropy 或 purity 这类单个函数值，而是一次恢复整个排序后的谱；恢复后，所有对谱连续的 unitary-invariant quantities 都可以继续计算。

先解释输入对象。量子态由一个半正定、迹为 $1$ 的复矩阵 $\rho\in\mathbb C^{d\times d}$ 表示；它可以写成
$$
\rho=\sum_{i=1}^d\alpha_i|v_i\rangle\langle v_i|,
\qquad
\alpha_i\geq 0,\quad \sum_i\alpha_i=1.
$$
特征向量 $|v_i\rangle$ 说明“在哪些方向上测量”，特征值 $\alpha_i$ 则像这些方向出现的概率。Full state tomography 要同时恢复两者，通常以 trace distance $\frac12\|\rho-\widehat\rho\|_1$ 衡量误差；一般态有 $\Theta(d^2)$ 个实参数，最优 copy complexity 也是 $\Theta(d^2/\varepsilon^2)$，上界来自 O'Donnell 和 Wright (2016) [arXiv:1508.01907](https://arxiv.org/abs/1508.01907)，相应下界由 Haah et al. (2016) [arXiv:1508.01797](https://arxiv.org/abs/1508.01797) 建立。Spectrum estimation 丢掉了 eigenbasis，只保留一个 $d$ 维概率向量；rank、purity $\mathrm{tr}(\rho^2)$、von Neumann/Rényi entropy，以及任何在 $\rho\mapsto U\rho U^\dagger$ 下不变的性质，都只依赖这个向量。这正是人们期待它比 tomography 便宜的原因。

半正定保证任意测量方向得到的概率非负，迹为 $1$ 保证总概率质量恰好为一；谱分解于是把密度矩阵拆成“方向加权重”。对 $\rho$ 做 unitary conjugation 只会旋转这些方向，不会改变权重，因此 spectrum estimation 可以忽略描述 eigenbasis 所需的约 $d^2$ 个自由度。问题的微妙之处正在于：输出虽然只有 $d-1$ 个独立实数，观测过程却仍发生在未知的 $d$ 维基底中，参数个数本身不能直接推出线性的样本上界。

困难在于，量子拷贝并不会附带“这次抽中了第 $i$ 个特征向量”的经典标签。如果 eigenbasis 已知，测量每份拷贝再数频率即可；但在 $n=o(d^2)$ 的范围内，描述整套 eigenbasis 所需的信息本身就学不出来。算法必须在不知道类别是什么的情况下估计各类别频率，而且单份拷贝上的测量通常还会改变状态。这也是为什么这里允许 collective measurement 很关键：它把 $\rho^{\otimes n}$ 当成一个整体测量，而不是逐份测完后只保留经典结果。近期 [2026-07-16 日报](#2026-07-16) 讨论的 process tomography 也展示了 quantum memory 对 copy complexity 的影响；本文固定在最强的 collective-measurement 模型里，问的是在 access model 不变时，“只学谱”能否严格便宜于“学整态”。

Keyl 和 Werner (2001) [arXiv:quant-ph/0102027](https://arxiv.org/abs/quant-ph/0102027) 给出的答案是 weak Schur sampling。直觉上，把 $n$ 份相同状态按“交换拷贝不改变什么”分解，会得到一个由 Young diagram $\lambda\vdash n$ 标记的测量结果；$\lambda$ 最多有 $d$ 行，归一化行长
$$
\left(\frac{\lambda_1}{n},\ldots,\frac{\lambda_d}{n}\right)
$$
就是谱的 empirical estimator。这个算法完全不需要知道 $|v_i\rangle$，也因此成为 representation-theoretic quantum learning 的基本组件。

Young diagram 可以看成把整数 $n$ 写成不增的行长 $\lambda_1\ge\lambda_2\ge\cdots$ 后画出的方格图。Weak Schur sampling 返回的不是某份拷贝“属于哪个特征向量”，而是 $n$ 份拷贝在置换对称性下共同落入的表示类型；行长因此扮演无标签频数的角色。这解释了它为何能绕过未知 eigenbasis，也解释了原 estimator 的限制：直接使用 $\lambda_i/n$，等于把表示类型中的原始经验频数当作最终概率估计，没有利用不同概率尺度可以采用不同去偏策略这一事实。

:::aside[Schur--Weyl measurement 的形式化图景]
Schur--Weyl duality 给出分解
$$
(\mathbb C^d)^{\otimes n}
\cong
\bigoplus_{\lambda\vdash n,\ \ell(\lambda)\leq d}
\mathcal Q_\lambda^d\otimes\mathcal P_\lambda,
$$
其中 $\lambda$ 是 $n$ 的 partition，$\mathcal Q_\lambda^d$ 与 $\mathcal P_\lambda$ 分别承载 unitary group 和 symmetric group 的不可约表示。Weak Schur sampling 只测量状态落入哪个 $\lambda$-block，不读取 block 内的 eigenbasis 信息。O'Donnell 和 Wright (2015) [arXiv:1501.05028](https://arxiv.org/abs/1501.05028) 证明 empirical Young diagram estimator 在 total variation 误差下确实需要 $\Omega(d^2/\varepsilon^2)$ 份拷贝。
:::

随后二十五年的进展主要是在把这个 estimator 的有限样本分析做紧，而不是找到更好的 estimator。经 O'Donnell 和 Wright (2015, 2017) 的工作，Keyl--Werner 的 $O(d^2/\varepsilon^2)$ upper bound 与针对它的 lower bound 已经匹配。问题本身却只知道
$$
\Omega(d/\varepsilon^2)
\ \leq\
n^\star_{\mathrm{spec}}(d,\varepsilon)
\ \leq\
O(d^2/\varepsilon^2);
$$
左端来自 maximally mixedness testing，也就是检验未知状态是否为所有方向权重相同的完全混合态 $I/d$，远不足以证明任何 $d^{2-o(1)}$ 下界。Wright (2016) 在博士论文中猜测可以省掉至多一个 $\log d$，即应有 $\Omega(d^2/\log d)$ 下界；Anshu 和 Arunachalam (2023) 的量子态学习综述 [arXiv:2305.20069](https://arxiv.org/abs/2305.20069) 又把最优 spectrum estimation 明列为 open problem。本文的常数误差上界
$$
O\!\left(d^2\left(\frac{\log\log d}{\log d}\right)^2\right)
=o(d^2/\log d)
$$
直接否定了 2016 年的猜想。这里要分清两件事：论文证明的是 **Keyl--Werner 不最优**，并没有确定 spectrum estimation 的最优复杂度；目前严谨 lower bound 仍只有 $\Omega(d/\varepsilon^2)$。

新算法的入口来自一个经典对应物。若 $\rho$ 在已知基下是对角矩阵，问题就退化为 sorted distribution estimation：从 $d$ 元分布采样，但只需恢复概率的 multiset，不必知道哪个概率属于哪个标签。直接 empirical histogram 需要 $\Theta(d/\varepsilon^2)$ 个样本；Paninski (2004)、Valiant 和 Valiant (2011) 等关于“estimating the unseen”的工作发现，标签被忘掉之后，未出现元素的总体频率仍可由 fingerprint 推断。这里的 fingerprint 不是保留元素标签，而是记录“恰好出现一次、两次、三次……的标签各有多少个”；它压缩了样本中与概率 multiset 有关、与标签名称无关的信息。Han et al. (2018) 把这条线整理成 local moment matching [arXiv:1802.08405](https://arxiv.org/abs/1802.08405)：在误差不太小时，只需 $O(d/(\varepsilon^2\log d))$ 个样本即可恢复排序后的分布，而且这是最优的。

Moment matching 为什么能看到“没出现的元素”？把概率向量看成在数轴上放置的 $d$ 个点，估计
$$
p_k(\alpha)=\sum_{i=1}^d\alpha_i^k
$$
就等于获知这组点的前若干个 power moments；低次多项式逼近再把 moment 误差转成排序概率向量的误差。麻烦是一个较大的 $\alpha_i$ 会主导高次矩并放大 estimator variance，淹没大量 $O(1/d)$ 的小概率。Local moment matching 因而先粗略地把概率按尺度分桶，再在每个桶内单独匹配矩：大概率项数量少，可以直接学；小概率项数目多，却因为单项都小而有可控的 moment variance。

从函数逼近的角度看，若一个统计量能在某个概率区间上由低次多项式逼近，那么它对整个谱的取值就能写成若干 power moments 的线性组合。只匹配有限阶矩当然不能逐点确定所有 $\alpha_i$，但排序谱的 total variation 误差并不要求辨认每个原始标签；许多彼此很近的小特征值可以作为一团质量处理。分桶的作用是让每一团里的动态范围受控，使同一组低阶矩既足以区分需要区分的形状，又不会被桶外的大特征值支配。

Pelecanos et al. (2025) 已把这套思路搬到 single-copy quantum measurement [arXiv:2504.02785](https://arxiv.org/abs/2504.02785)。量子矩仍然容易写：
$$
p_k(\alpha)=\mathrm{tr}(\rho^k).
$$
用 $k$-cycle permutations 构造作用于多份拷贝的 Hermitian observable，就能把一次测量结果的期望设计成这个量，从而得到无偏估计；把所有 $n$ 份拷贝上的估计对称化还能降低方差，而且这些 moment observables 可以通过一次 weak Schur sampling 同时读取。真正的障碍是 bucketing。经典算法可直接看每个标签的 empirical frequency；量子算法只能先做粗糙 tomography 得到 $\widetilde\rho$，再按 $\widetilde\rho$ 的大小特征空间构造投影 $\Pi$ 与 $I-\Pi$。这会产生两种误差：本应属于小特征值的方向可能被错分；执行投影还会删去 $\Pi\rho(I-\Pi)$ 的 off-diagonal block，从而改变待学习的谱。

2025 年算法使用 uniform operator-norm guarantee
$$
\|\widetilde\rho-\rho\|_\infty
=O\!\left(\sqrt{\frac dn}\right).
$$
这里的 operator norm $\|\cdot\|_\infty$ 是矩阵对单位向量造成的最大伸缩；对 Hermitian 误差矩阵，它等于绝对值最大的特征值，因此控制的是最坏方向上的估计偏差。若希望“估计值小于 $B$ 的方向，其真实权重也至多 $O(B)$”，就必须让右端小于 $B$，即 $n\gtrsim d/B^2$。常数误差下 local moment matching 所需的尺度是
$$
B\asymp \frac1d\left(\frac{\log d}{\log\log d}\right)^2,
$$
于是得到 $d^3(\log\log d/\log d)^4$ 的 single-copy 算法；它比 single-copy full tomography 的 $\Omega(d^3)$ 少 polylog 因子，却无法进入 $o(d^2)$。

本文的关键 technical lemma 是一种 heteroskedastic、同时对所有方向成立的 tomography bound；所谓 heteroskedastic，是说误差尺度不是各方向相同，而会随该方向承载的真实概率质量改变。算法输出矩阵 $\widetilde\rho$，使得以至少 $0.99$ 的概率，对每个单位向量 $|w\rangle$ 同时有
$$
\left|\langle w|(\widetilde\rho-\rho)|w\rangle\right|
\leq
C\left(
\sqrt{\frac dn\,\langle w|\rho|w\rangle}
+\frac dn
\right).
$$
最坏情况下它仍是 $O(\sqrt{d/n})$，没有违反已知 operator-norm lower bound；但在 $\langle w|\rho|w\rangle$ 很小的方向，误差也随之缩小，最低降到 $O(d/n)$。把 $x=\langle w|\rho|w\rangle$ 代入上式：若 $\langle w|\widetilde\rho|w\rangle\leq B$，则
$$
x\leq B+C\left(\sqrt{\frac{dx}{n}}+\frac dn\right),
$$
解这个自洽不等式可得，只要 $n\gtrsim d/B$，就有 $x=O(B)$。与旧条件 $n\gtrsim d/B^2$ 相比，恰好省下一个 $1/B$；代入上面的 $B$，便出现主定理中的 $d^2(\log\log d/\log d)^2$。

这条自洽推理正好满足 bucketing 真正需要的单向保证：算法不必在所有方向上都达到同一个加性精度，只需确保被估计器判入“小谱桶”的方向不可能暗藏很大的真实质量。Uniform operator-norm 分析按最坏方向付费，即使某个方向的真实权重接近零也容许 $\sqrt{d/n}$ 级误差；relative bound 则让误差随 $x$ 缩小。于是阈值从必须压过平方根噪声的 $n\gtrsim d/B^2$，变成只需压过线性噪声底的 $n\gtrsim d/B$。主结果节省的近一个 $d$ 因子，具体就发生在这里，而不是来自 Schur sampling 本身更省拷贝。

这个 relative-error bound 的证明是我认为全文最巧的一步。作者使用 Pelecanos et al. (2025) 的 Mix(AGPS) tomography [arXiv:2511.15806](https://arxiv.org/abs/2511.15806)：random purification channel 先把 mixed-state copies 转成某个随机 purification 的 copies。Purification 是把混合态嵌入更大系统得到的纯态，丢弃新增的辅助系统后会恢复原来的 $\rho$；这里“丢弃辅助系统”在矩阵语言中就是取 partial trace。算法再运行经过 debias 的 pure-state tomography，最后对辅助系统取 partial trace，由此得到无偏 estimator。对固定 $|w\rangle$，作者证明 $\langle w|\widetilde\rho|w\rangle$ 是 sub-gamma random variable；也就是说中等偏差有 Gaussian 型尾界，极端偏差仍有 exponential 型控制，其 variance proxy 正比于 $\langle w|\rho|w\rangle$。

但“对固定 $w$ 集中”还不等于“对所有 $w$ 同时相对集中”。直接在单位球上取 $\varepsilon$-net——用有限多个网格方向逼近所有单位向量——会失败，因为不同方向要求的误差半径不同，普通 net argument 只擅长证明统一的 operator norm。作者没有强行修补 union bound，而是按 $\rho$ 在各方向的尺度重新加权误差矩阵：令 $R$ 在第 $i$ 个 eigen-direction 上的权重大致为 $\sqrt{d\alpha_i/n}+d/n$，并考虑 Lyapunov map $\mathcal L_R(X)=(RX+XR)/2$。他们先对“白化”后的矩阵 $\mathcal L_R^{-1}(\widetilde\rho-\rho)$ 证明一个普通的 $O(1)$ operator-norm bound；白化的作用是把原来因方向而异的允许误差缩放到同一量级，这时才可以使用 net。再把缩放拉回去，恰好恢复上面的 direction-dependent inequality。这里不是获得了更强的全局范数，而是找到了正确的局部几何。

有了 bucketing，剩余部分才回到 local moment matching。小 bucket 中每个 eigenvalue 都是 $O(B)$，所以 entangled moment estimators 的 variance 不再被大特征值污染；大 bucket 的维数至多 $O(1/B)$，可以直接估计。投影造成的 alignment error 则由同一个 relative bound 控制：$\widetilde\rho$ 在两个 bucket 间没有 off-diagonal block，$\rho$ 的对应 block 正是 tomography error 的一部分。把大、小 bucket 的谱估计合并，再做 error-aware 参数选择，得到 $\varepsilon^{-4}$ 的主定理。这个依赖很可能不是终点：作者猜测在“足够大的” $\varepsilon$ 区间，正确答案应接近
$$
\Theta\!\left(\frac{d^2}{\varepsilon^2\log^2 d}\right)
$$
（可能仍差 $\log\log d$ 因子），但现有 bucketing/moment-matching 分析似乎无法把 $\varepsilon^{-4}$ 改成 $\varepsilon^{-2}$。相应地，本文只有在 $\varepsilon\gg\log\log d/\log d$ 时优于 Keyl--Werner；高精度区间可能像经典 sorted distribution estimation 一样重新撞上 tomography 的代价。

Relative-error lemma 还有两个能检验其分量是否“用对了”的推论。对已知 rank $r$ 的状态，Bures $\chi^2$ divergence tomography 的 copy complexity 从 Flammia 和 O'Donnell (2024) 隐藏 polylog 的 $\widetilde O(\sqrt{rd^3}/\varepsilon)$ [arXiv:2305.18519](https://arxiv.org/abs/2305.18519)，收紧为
$$
O\!\left(\frac{\sqrt{rd^3}}{\varepsilon}\right).
$$
这种 divergence 会重罚在真实概率很小方向上的相对误差，正适合由新 bound 控制。对 quantum PCA，若 $\rho_{\leq k}$ 表示保留前 $k$ 个主方向的近似，作者还以 $O(kd/\varepsilon^2)$ 份拷贝得到 rank-$k$ 输出 $\widehat\rho_{\leq k}$，满足论文采用的 Bures distance 保证
$$
D_B(\rho,\widehat\rho_{\leq k})
\leq \sum_{i>k}\alpha_i+\varepsilon.
$$
Bures distance 是由两态 fidelity 导出的几何距离；这里右端把不可避免的谱尾质量与算法额外误差分开。这一复杂度与 rank-$k$ Bures tomography 的最优复杂度相同，却允许输入 $\rho$ 本身有长尾噪声。

二十五年前 Keyl 和 Werner 问自己的 estimator 是否 optimal；本文给出的回答很有分寸：不 optimal 的是“把 Young diagram 的行长直接当谱”这一步，而不是 Schur--Weyl measurement 这套语言。新算法仍用 weak Schur sampling 同时读出谱矩，只是先由 relative-error tomography 划出不同尺度，再让 Young diagram 在局部桶内工作。一个曾经承担最终答案的对象，退到更复杂算法中的 moment-estimation 子程序——这比单纯省下两个对数更能说明这条研究线发生了什么变化。

## 未入选但值得关注

### Breaking the $2^n$ barrier for graph $k$-coloring [arXiv:2607.27159](https://arxiv.org/abs/2607.27159)

论文对所有 $k$ 统一给出突破 $2^n$ 的精确图着色算法。其主结论与 [2026-07-29 日报](#2026-07-29) 已收录的 Zamir 独立并行工作重合，本期不重复占用正文名额。

### Constructions of $k$-Min-Wise Hash from Bounded Independence [arXiv:2607.27157](https://arxiv.org/abs/2607.27157)

论文以 matching lower bound 和 affine-hash 反例补全了 $\Theta(k+\log(1/\delta))$ 的 tight characterization。核心 upper bound 与 [2026-07-14 日报](#2026-07-14) 已解读的 Wang 工作重合，因此只列作关注。

### Enumerating Small Cycles [arXiv:2607.27147](https://arxiv.org/abs/2607.27147)

论文把近二次预处理、近常数 delay 的 even-cycle listing 推进到长度 $16$，并给出更一般的区间枚举算法。结果扎实，但三篇正文优先留给封闭更长期缺口的工作。

### Explicit Separations for One-Query Unitary Synthesis [arXiv:2607.26478](https://arxiv.org/abs/2607.26478)

论文建立显式的 1-query/2-query unitary-synthesis separation，并提出新的 oracle-state cryptographic games。量子方向的正文名额留给首次突破二十五年谱估计样本界的工作。

### Sensitivity and Differential Privacy in Metric Voting with Distortion below Three [arXiv:2607.26388](https://arxiv.org/abs/2607.26388)

论文证明 distortion 严格低于 $3$ 可以同时兼容低 Wasserstein sensitivity 与 approximate differential privacy。它是很好的跨方向结果，但相较三篇入选论文，当前主线影响面稍窄。

### The Code Distortion Problem [arXiv:2607.26261](https://arxiv.org/abs/2607.26261)

论文从 code equivalence 推广出新的 distortion optimization 问题，并建立常数不可近似性。当前算法仍为 single-exponential，近似因子又随维数平方增长，研究版图尚在起步阶段。
