## 编辑按语

今天入选的五篇论文覆盖精确指数算法、受限内存优化、计算几何、连续优化与随机调度几个不同方向，没有共同技术主线。图着色工作证明任意固定 $k$ 都有 $O^*((2-\varepsilon_k)^n)$ 算法；凸优化工作给出 subquadratic memory 下更强的 query lower bounds。

其余三篇分别构造低交叉 Euclidean spanner，用联合值域 cover 统一一批固定次数多项式优化 QPTAS，以及刻画 machine reservation 给随机调度带来的适应性。后二者虽都属于近似算法，但技术路线并不相同。

## k-Coloring is Faster than Computing the Chromatic Number [arXiv:2607.25973](https://arxiv.org/abs/2607.25973)

给定一张 $n$ 个顶点的无向图 $G=(V,E)$ 和固定整数 $k$，精确 $k$-coloring 要判断是否存在映射 $c:V\to[k]$，使每条边的两个端点颜色不同。Or Zamir 证明，对每个固定的 $k$，都存在常数 $\varepsilon_k>0$，使这个问题可以用随机算法在 $O^*((2-\varepsilon_k)^n)$ 时间内解决，错误是可降至 $\exp(-\Omega(n))$ 的单侧错误。此前只有 $k\le 6$ 知道如何把指数底数严格降到 $2$ 以下；对每个 $k\ge 7$，最好上界仍是那个连 chromatic number 都能计算的 $O^*(2^n)$ 通用算法。

论文实际证明了更强的 fixed-palette List Coloring 定理。给定一个固定 palette $P=[K]$，每个顶点 $v$ 有一个非空的允许颜色表 $L(v)\subseteq P$，要求选出 $c(v)\in L(v)$ 并保持相邻顶点异色；若所有表的大小至多 $k$，就称为 $k$-list-coloring。这里必须区分“最大 list size” $k$ 与“整个 palette 的大小” $K$：证明会固定同一个 $K$，再把可处理的 list size 从 $2$ 一层层升到 $K$。主定理的精确形式是

$$
\textbf{Theorem 5.2.}\quad
\forall K\ge 1,\ \exists \varepsilon_K>0,\quad
\text{List Coloring over }[K]\text{ 可在 }
O^*((2-\varepsilon_K)^n)
\text{ 时间内随机求解。}
$$

其中 $O^*$ 隐去输入规模的多项式因子，算法使用 exponential space；单侧错误指的是返回的着色总能直接验证，所以 no-instance 不会被误判为 yes，随机性只可能让算法暂时漏掉一个确实存在的着色。普通 $K$-coloring 是令所有 $L(v)=[K]$ 的特例；反过来，fixed-palette list coloring 也能通过加入一个代表颜色的 $K$-clique 归约到普通 $K$-coloring，所以在 $K$ 固定时，这个更灵活的表述只多出常数个顶点。

$2$-list-coloring 之所以是整个递归的多项式时间起点，也值得说清楚。一个仍有两种颜色可选的顶点可以用一个 Boolean variable 表示；若一条边的两个端点在某组 Boolean 取值下会选到同一颜色，就加入一个 clause 排除这组取值。每个 clause 至多涉及两个变量，因此得到 2-SAT，在线性时间即可判定。Singleton list 则相当于固定变量，并把该颜色从邻居的 lists 中传播删除。

为什么要在一个已经 NP-complete 的问题上计较 $2^n$ 与 $(2-\varepsilon)^n$？Exact exponential algorithms 研究的不是把 NP-hard 问题变成多项式时间，而是问：若最坏情形确实需要指数时间，指数的底数能否下降。枚举每个顶点的颜色要 $k^n$ 种选择；底数从 $2$ 降到 $1.99$ 看似很小，却意味着规模增加时节省一个指数因子。这也是 fine-grained complexity 的视角：不只问“是否多项式”，还问一个基准算法的指数能否被严格改进。

着色问题很早就显示出“判定固定 $k$”与“计算最小 $k$”之间可能存在算法差异。Chromatic number 是 Karp (1972) 最初列出的 21 个 NP-complete 问题之一；$2$-coloring 等价于判断图是否 bipartite，可以在线性时间完成，而 Lovász 和 Stockmeyer (1973) 的结果意味着对每个 $k\ge 3$，$k$-coloring 都是 NP-complete。Chromatic number 要求输出

$$
\chi(G)=\min\{k:G\text{ 是 }k\text{-colorable}\}.
$$

Lawler (1976) 用独立集上的动态规划给出 $O^*(3^n)$ 算法。Björklund、Husfeldt 和 Koivisto (2006/2009) 随后把图着色看成 set partition：一个 proper coloring 就是把顶点覆盖为若干 independent sets，也就是内部没有边的顶点集合；再用 inclusion-exclusion 同时处理所有 $2^n$ 个顶点子集，得到计算 chromatic number 以及 List Coloring 的 $O^*(2^n)$ 算法（[论文页面](https://doi.org/10.1137/070683933)）。这个上界与颜色数无关，自此成为本文要跨过的基线。

:::aside[Inclusion-exclusion 为何给出 $2^n$]
若 $i(S)$ 表示诱导子图 $G[S]$ 的 independent sets 数量，则
$$
\sum_{S\subseteq V}(-1)^{|V\setminus S|}i(S)^k
$$
恰好计数并集覆盖 $V$ 的有序 $k$ 元 independent-set 组，因此非零当且仅当 $G$ 可 $k$-着色。算法为每个 $S\subseteq V$ 计算相应表项，总计 $2^n$ 个状态。List Coloring 版本把 $i(S)^k$ 换成各颜色允许的 independent-set 计数之积。
:::

固定小 $k$ 很早就有更快的专用算法，但这条进展在 $6$ 处停了很久。Beigel 和 Eppstein (2005) 曾把 $3$-coloring 做到 $O(1.3289^n)$；目前 Meijer (2023) 的上界是 $O(1.3217^n)$（[arXiv:2302.13644](https://arxiv.org/abs/2302.13644)）。$4$-coloring 经 Fomin、Gaspers 和 Saurabh (2007) 的 $O(1.7272^n)$，推进到 Wu et al. (2024) 的 deterministic $O(1.7159^n)$（[ESA 2024](https://doi.org/10.4230/LIPIcs.ESA.2024.103)）。Zamir (2021) 才首次证明 $5$- 与 $6$-coloring 都有某个 $O^*((2-\varepsilon)^n)$ 算法（[arXiv:2007.10790](https://arxiv.org/abs/2007.10790)）。于是本文之前的版图是：

| 颜色数 | 本文前的代表性最坏情形上界 | 状态 |
| :--: | :-- | :-- |
| $3$ | $O(1.3217^n)$ | 明确低于 $2^n$ |
| $4$ | $O(1.7159^n)$ | 明确低于 $2^n$ |
| $5,6$ | $O^*((2-\varepsilon)^n)$ | 已知存在常数 saving |
| 每个固定 $k\ge 7$ | $O^*(2^n)$ | 与计算 $\chi(G)$ 相同 |

这与 SAT 形成了明显反差：Monien 和 Speckenmeyer (1985) 已经证明每个固定 clause width 的 $k$-SAT 都可在 $(2-\varepsilon_k)^n$ 时间求解，而 Coloring 的对应命题直到这篇工作才成立。它也不同于 [2026-07-15 日报](#2026-07-15) 讨论的 balanced planar coloring：后者利用平面性保证某种均衡着色一定存在，本文面对任意图，付出指数时间来精确判断某个着色是否存在。

要理解突破为何困难，先看 Zamir (2021) 留下的 sampling reduction。假设我们已经会以底数 $a<2$ 解决 $(k-1)$-list-coloring，现在面对 $k$-list-coloring。把 $|L(v)|=k$ 的顶点叫 active。分析时暂时固定一个未知的正确着色 $c$：若 $v$ 的某个允许颜色在其邻居中出现很多次，就称 $v$ 为 good；否则称为 bad。算法当然看不到 $c$，所以也不能真的给顶点贴上 good/bad 标签，这个划分只用于证明随机过程有一条能保留正确解的路径。

Good 顶点适合用一个很小的随机 seed 处理。独立地抽取少量顶点并枚举 seed 的所有合法着色；若枚举到与 $c$ 一致的分支，一个 good active vertex 很可能在 seed 中碰到使用其允许颜色的邻居，于是这个颜色可从 $L(v)$ 删除。少量没被击中的顶点再显式枚举，剩余实例的最大 list size 就从 $k$ 降到 $k-1$，可以调用归纳假设。另一方面，Zamir (2021) 还证明：只要线性比例的顶点度数被某个常数 $\Delta$ 控制，List Coloring 本身已有 $O^*(C^n)$、$C<2$ 的算法。因此，“低度顶点很多”或“bad active vertices 很少”都是 easy case。

困难恰好是 easy case 的否定：存在很多既 bad、度数又高的 active vertices。2021 年的 reduction 能利用这种失败把 $(k+1)$-coloring、甚至 $(k+2)$-coloring 降到 $k$-list-coloring。粗略地说，若高阶邻域没有呈现许多不同颜色，它就集中在一个主导颜色上，可以猜中一批同色邻居并收缩。但再多跨一步时，邻居可能集中在两个颜色上；逐个猜二选一又会付回整整一个 $2^n$，saving 在这里耗尽。这正是旧方法只能做到 $5,6$ 色而到不了 $7$ 色的原因。

本文先把这个障碍单独提炼成一个很干净的 interpolation theorem。若 $n$ 个顶点里有 $b$ 个 list 大小至多为 $2$，palette 大小固定为 $K$，则

$$
\textbf{Theorem 4.4.}\quad
T(n,b)=O^*\!\left(2^{\,n-b/\binom K2}\right).
$$

证明先传播 singleton lists；其余短表都是二元组。总共只有 $\binom K2$ 个颜色对，所以至少 $b/\binom K2$ 个顶点共享同一个 list $Q=\{c_1,c_2\}$，把这组顶点记为 $S$，其余顶点为 $H=V\setminus S$。算法在 $2^{|H|}$ 总时间内同时算出：对每个 $X\subseteq H$，$G[X]$ 能否只用 $P\setminus Q$ 中的颜色着色。这里的“同时”很关键：subset convolution 是一种按所有顶点子集组织的动态规划代数，它把不同子集分拆的贡献一次性合并，而不是对 $2^{|H|}$ 个子图各跑一次指数算法。对每个可行的 $X$，剩余 $V\setminus X$ 只允许 $Q$ 中的两个颜色，因而化成 2-SAT，在多项式时间内检查。两边使用不相交的 palette，跨过割 $(X,V\setminus X)$ 的边不需要额外兼容条件。于是总成本是 $2^{|H|}\le 2^{n-b/\binom K2}$。这已经把旧 reduction 多推一步，首次给出 $7$-coloring 的 sub-$2^n$ 算法。

但二元 list 只是暖身。若递归继续，算法会制造许多大小为 $3$ 或 $4$ 的 lists，而“所有 list 都至多为 $3$”本身仍是 NP-hard，不再有 2-SAT 这个多项式端点。本文最关键的改变，是不只记录 list 缩短了多少，而是记录它被限制在 palette 的哪一边。技术主定理写成

$$
\textbf{Theorem 5.1.}\quad
\begin{aligned}
&P=[K],\quad 3\le k\le K,\\
&(k-1)\text{-list-coloring over }P\in O^*(a^n),\ a<2\\
&\Longrightarrow\quad
k\text{-list-coloring over }P\in O^*((2-\varepsilon)^n)
\end{aligned}
$$

其中 $\varepsilon>0$ 只依赖于 $K,k,a$。对一个 active vertex $v$，令

$$
Q_v=P\setminus L(v),\qquad R_v=L(v).
$$

这条 implication 能迭代，关键是输入和递归调用始终使用同一个 palette $P$。如果归约过程中为了缩短 list 而不断引入新颜色，上一层算法的常数便无法作为下一层的固定参数；本文所有抽样、取交和 normalization 都只删除颜色，不扩大 $P$。因此，证明需要同时控制三个量：最大 list size 每层下降一、palette 从头到尾不变、每层留下的指数 saving 虽可能恶化却仍严格为正。

当 $k<K$ 时，$|Q_v|=K-k$。因为 $P$ 固定，$Q_v$ 只有 $\binom K{K-k}$ 种可能；在困难情形的线性多个 bad high-degree vertices 中，pigeonhole principle 保证有线性多个共享同一个 complement $Q$。记 $R=P\setminus Q$。这些顶点的 list 恰为 $R$，所以算法一开始便保有一个线性大的集合

$$
B_R=\{v:L(v)\subseteq R\}.
$$

现在从这样的顶点 $v$ 的邻域随机抽取 $r$ 个顶点。因为 $v$ 是 bad，正确着色 $c$ 在 $N(v)$ 中使用每个 $R$ 色都不超过常数 $\Delta_1$ 次；而 $v$ 的度数大于 $r(1+k\Delta_1)$。所以绝大多数邻居在 witness coloring 下使用的是 $Q$ 中的颜色，把抽到的 $r$ 个邻居的 lists 全部与 $Q$ 取交，仍保留 witness 的条件概率至少为

$$
\left(1-\frac1r\right)^r\ge \frac14.
$$

连同选中合格 $v$ 的概率，每个 hard step 以某个常数 $p_0>0$ 保留固定 witness。无论是否保留 witness，只要这一步没有产生空 list，它都会新造出 $r$ 个

$$
A_Q=\{u:L(u)\subseteq Q\}
$$

中的顶点。算法随后删除 list 已经不相交的边；因此 $A_Q$ 与 $B_R$ 之间的边会消失，新造的 $Q$-supported 顶点不可能在后续又从某个 $R$-supported 顶点的邻域中被抽到。每个 completed step 都在制造全新的 $A_Q$ 顶点，而原来的 $B_R$ 不会缩小。经过 $m=\Theta(n)$ 步，两个集合都达到线性大小。

接下来才用到 Zamir (2023) 的 hypergraph/partition-container 工作（[arXiv:2211.11737](https://arxiv.org/abs/2211.11737)）。Container method 的直觉是用一个较小的顶点域包住某个颜色可能占据的 independent set；其算法层的难题是，即使知道每个颜色只允许出现在哪些顶点上，普通 inclusion-exclusion 仍有 $2^n$ 项，怎样让“允许域变小”真正反映到运行时间里。为此引入的 Extensions-Sum machinery 可以把颜色分成 $Q,R$ 两组，并按两组允许域的并集大小分别付费。本文直接使用它推出：

$$
L(v)\subseteq Q\ (v\in A_Q),\quad
L(v)\subseteq R\ (v\in B_R)
\quad\Longrightarrow\quad
T=O^*\!\left(2^{n-|A_Q|}+2^{n-|B_R|}\right).
$$

这里 $A_Q$ 和 $B_R$ 甚至可以重叠；这正是 binary interpolation 里“选一个 $X$，另一边交给 2-SAT”的简单拼接无法处理的地方。更具体地说，最终着色中使用 $Q$ 的顶点必须避开 $B_R$，使用 $R$ 的顶点必须避开 $A_Q$，但两个允许域的交叠部分仍可被分给任意一边；逐一枚举这种分法会回到 $2^n$。Extensions-Sum 不是先猜分界，而是把两边的全部 extension 贡献各自压成一张表，再按求和恒等式合并，成本只取决于两张表的大小。技术上最让我意外的是，本文并没有重新调用 container theorem 去覆盖当前图，而是抽出了 2023 年工作的代数求和层，把 sampling reduction 产生的两块互补 palette 支持直接喂给 Extensions-Sum。旧 reduction 的“抽样失败”因此不再只是 list 少掉几个颜色，而变成了可以被 inclusion-exclusion 计价的 domain information。

当然，连续猜对 $\Theta(n)$ 次的概率本身也会指数变小。证明的定量平衡是这套算法真正站得住的地方。设 easy solver 的底数为 $C=2^\kappa<2$，一个 hard step 保留 witness 的概率下界为 $p_0$，并选 $r$ 使

$$
\lambda=\frac{\log_2(1/p_0)}{r}<1.
$$

再取 $m=dn/r$，其中

$$
d=\min\left\{\frac{\gamma}{2},\frac{1-\kappa}{2\lambda}\right\}>0,
$$

$\gamma n$ 是保留下来的 $B_R$ 规模。重复 trial 来补偿 $p_0^m$ 的成功概率，只会给指数增加 $\lambda d$。Easy calls 与 two-block terminal calls 的三个相关 base-two 指数分别受控于

$$
\kappa+\lambda d,\qquad
1-(1-\lambda)d,\qquad
1-\gamma+\lambda d,
$$

按上述参数选择三者都严格小于 $1$。令它们的最大值为 $\rho<1$，总时间就是 $O^*(2^{\rho n})=O^*((2-\varepsilon)^n)$。这段分析说明了为什么不能只说“随机抽样会产生很多短 list”：每次猜测带来的 terminal saving 必须严格压过把成功概率放大回来所付的指数成本。

最后一层 $k=K$ 看似会出问题，因为 active list 已经是整个 palette，complement $Q_v$ 为空，无法再制造 two-block 结构。这里反而有一个短的封口：若这样的 active vertex 是 bad，那么它的每种邻居颜色都只出现至多 $\Delta_1$ 次，所以 $\deg(v)\le K\Delta_1$。Bad vertices 多，就落入“线性多个低度顶点”的 easy case；bad vertices 少，就由 seed-shortening solver 处理。因此 $k=K$ 的每个可行实例总有一个 easy case。以多项式时间的 2-list-coloring 为起点，对 $k=3,4,\ldots,K$ 依次应用 Theorem 5.1，便得到 Theorem 5.2。

论文给出的 $\varepsilon_K$ 数值非常小：未经优化的 bookkeeping 大致是高度 $\Theta(K)$ 的指数塔的倒数，主要损失来自每一层都调用 2021 年的 low-degree/subset-removal 工具。因此这不是一个意在实际击败现有 solver 的底数记录，而是一个此前缺失的定性分离。Binary interpolation 还精确暴露了 fixed palette 的必要位置：把它写成 $O^*(2^{n-b}q_K^b)$ 时，本文得到

$$
q_K=2^{1-1/\binom K2}<2,
$$

但 $q_K\to2$ 随 $K$ 增大；论文并用 ETH 证明，若要求一个对所有 palette 都适用的常数 $q$，端点 $q=1$ 不可能。是否存在 palette-independent 的 $1<q<2$ 仍决定着相同思路能否处理“list size 固定、palette 任意大”的 List Coloring。

标题里的差别最终是量词顺序。本文证明的是 $\forall$ 固定 $k$，$\exists\varepsilon_k>0$；它没有证明存在一个统一的 $\varepsilon>0$ 对所有 $k$ 生效。当计算 chromatic number 时，候选 $k$ 可以随 $n$ 增长，逐层 bootstrap 的 saving 也可能随之消失，所以 Björklund–Husfeldt–Koivisto 的无条件 $2^n$ 屏障仍在。Björklund et al. (2025) 在 Strassen generalized asymptotic rank conjecture 下给过 deterministic $O^*(1.99982^n)$（[arXiv:2404.04987](https://arxiv.org/abs/2404.04987)），但那依赖一个极强且与 Set Cover conjecture 不相容的假设。固定 $k$ 之所以终于能更快，不是因为出现了一个统一替代 inclusion-exclusion 的公式，而是因为有限 palette 允许算法逐层积累越来越微弱、却始终为正的结构性 saving。

## Stronger Memory-Query Tradeoffs for Convex Optimization: The Limitations of Subquadratic Memory [arXiv:2607.24827](https://arxiv.org/abs/2607.24827)

受限内存的 first-order convex optimization 模型如下：输入是定义在 $d$ 维单位 Euclidean ball 上的未知 $1$-Lipschitz convex function；算法每次可以查询一点的函数值和一个 subgradient，但两次查询之间只能保留 $m$ bits 状态，目标是用尽量少的查询找到近似最小点。Menart、Nikolov 和 Shamir 证明，对多项式级精度，随机算法需要
$$
\widetilde{\Omega}\!\left(\frac{d^2}{\sqrt m}\right)
$$
次查询；确定性算法需要
$$
\widetilde{\Omega}\!\left(
\min\left\{d^{8/5},\frac{d^{8/3}}{m^{2/3}}\right\}
\right)
$$
次查询。后一条与已有 upper bound 合在一起，首次在 $m\approx d^2$ 附近给出 sharp phase transition：内存只减少 polylogarithmic factor，query complexity 就会增加 $d^{\Omega(1)}$。

先把问题本身说清楚。Convex function 的含义是两点之间的函数图像不会高于连接两点函数值的直线；$1$-Lipschitz 则保证输入移动距离 $\Delta$ 时，函数值至多变化 $\Delta$。函数不必可微，所以 oracle 返回的是 subgradient $g\in\partial F(w)$：它给出一个支撑超平面，满足
$$
F(v)\ge F(w)+\langle g,v-w\rangle\qquad\text{对所有 }v.
$$
一次查询因而不只告诉算法当前位置有多好，还给出一条“最优点应该在超平面的哪一侧”的信息。给定精度 $\alpha>0$，算法要输出 $w\in B_2^d(1)$，使
$$
F(w)-\min_{v\in B_2^d(1)}F(v)\le \alpha.
$$
这里衡量的是 oracle calls，而不是普通运行时间；算法在两次调用之间可以做任意计算，本文只限制它必须在某个中间时刻把所有需要跨查询保存的状态压回 $m$ bits。

这个模型之所以值得单独研究，是因为大量机器学习和数值计算问题最终都要反复做同一件事：选择一个参数向量，评估当前损失，再根据局部方向修正参数。把具体数据结构、线性代数实现和硬件常数暂时拿掉，只保留“局部信息问了多少次”，可以得到不依赖某一种算法实现的 information-theoretic barrier。Lower bound 允许算法在查询之间做无限复杂的计算，所以它排除的不是某个现有优化器，而是所有只能从 value/subgradient 逐步认识未知函数的方法。加入 memory constraint 后，问题进一步区分“oracle 已经告诉过算法多少信息”和“算法能把其中多少留到下一轮”；这正是处理超大维模型、无法保存完整二阶矩阵或全部历史梯度时会遇到的资源冲突。

:::aside[这里的“内存”与空间复杂度]
本文限制的是 oracle interaction 之间的持久状态，而不是每一步计算都只能占 $m$ bits。它和 [2026-07-20 日报](#2026-07-20)中的 logarithmic-space counting、[2026-04-28 日报](#2026-04-28)中的 catalytic logspace 都关心“有限工作区能保留什么信息”，但模型并不相同：后两者限制离散机器的整个计算空间，这里允许查询间的临时计算空间不受限，只在 oracle calls 之间设置 $m$-bit checkpoint。
:::

为什么要同时计算查询数和内存？没有内存限制时，这个黑盒问题的 minimax oracle complexity——最优算法面对最坏函数时需要的查询数——已经基本闭合：
$$
\Theta\!\left(\min\left\{\frac{1}{\alpha^2},\,d\log\frac1\alpha\right\}\right).
$$
Nemirovski (1992) 奠定了这条界的经典部分，Braun、Guzmán 和 Pokutta (2017) 又补齐了 randomized lower bound 中的缺口 [arXiv:1407.5144](https://arxiv.org/abs/1407.5144)。当 $\alpha\ge d^{-1/2}$ 时，普通 gradient descent 用 $O(\alpha^{-2})$ 次查询已经最优；它只需保留当前点、梯度和少量计数器，约用 $O(d\log(1/\alpha))$ bits。进入 $\alpha<d^{-1/2}$ 的 high-accuracy regime 后，cutting-plane methods 可以把查询数降到 $O(d\log(1/\alpha))$：每个 subgradient 都切掉一个不可能含有最优点的半空间，算法不断维护剩余可行区域，并在它的某种“中心”继续问 oracle。

这两个表达式来自两种不同的进度度量。Subgradient descent 每一步只能保证平均误差按 $1/\sqrt t$ 下降，因此达到误差 $\alpha$ 要约 $\alpha^{-2}$ 步；它几乎不利用有限维空间的全局几何。Cutting plane 则把每条 subgradient 当作永久约束，若 query point 选在 center-of-gravity 或合适的 volumetric center，每次切割都能让候选区域的体积缩小一个常数比例。把单位尺度压到 $\alpha$ 尺度需要体积缩小约 $\alpha^d$，所以只需 $O(d\log(1/\alpha))$ 轮。两者在 $\alpha\approx d^{-1/2}$ 相交：精度较低时积累全局几何没有查询优势，精度更高时，记住旧 cuts 才能避免沿已经排除的方向反复试探。

代价在于，cutting-plane algorithm 必须记住足够多的 cuts，或维护一个描述区域形状的 $d\times d$ 矩阵，因此需要约 $\widetilde{\Theta}(d^2)$ bits；计算下一个 query point 通常还要至少三次方量级的线性代数时间。于是 gradient descent 和 cutting plane 各占一端：前者省内存但在高精度时要很多查询，后者省查询却要 quadratic memory。Woodworth 和 Srebro (2019) 把“中间是否存在更好的 memory-query curve”正式列为 COLT open problem [arXiv:1907.00762](https://arxiv.org/abs/1907.00762)。

此后的 lower bounds 一直在逼近 quadratic-memory 门槛。Marsden et al. (2022) 首先对 randomized algorithms 证明
$$
\widetilde{\Omega}\!\left(\frac{d^{8/3}}{m^{4/3}}\right)
$$
查询下界，适用于 $\alpha=1/\mathrm{poly}(d)$ [arXiv:2203.15260](https://arxiv.org/abs/2203.15260)。Blanchard、Zhang 和 Jaillet (2023) 对 deterministic algorithms 加强为
$$
\widetilde{\Omega}\!\left(\frac{d^{5/3}}{m^{1/3}}\right)
$$
[arXiv:2302.04963](https://arxiv.org/abs/2302.04963)。Chen 和 Peng (2023) 又得到 randomized bound
$$
\widetilde{\Omega}\!\left(\frac{d^{4/3}}{m^{1/6}}\right),
$$
从而证明近最优查询数需要近 quadratic memory，但其精度要求是 $\alpha\le 2^{-\log^5 d}$，比 $1/\mathrm{poly}(d)$ 小得多 [arXiv:2306.12534](https://arxiv.org/abs/2306.12534)。算法一侧，Blanchard et al. (2023) 的 recursive cutting-plane framework 给出一族显式 tradeoff；特别地，Vaidya 型方法用 $O(d^2\log(1/\alpha))$ bits 即可做到 $O(d\log(1/\alpha))$ 次查询 [arXiv:2306.10096](https://arxiv.org/abs/2306.10096)。

把本文与 prior best 放在同一张表里，增益最容易看清（每一行都限于相应论文适用的内存与精度区间）：

| 算法 | 此前最好 lower bound | 本文 |
| :-- | :-- | :-- |
| randomized | $\widetilde{\Omega}\!\left(\max\left\{\frac{d^{8/3}}{m^{4/3}},\frac{d^{4/3}}{m^{1/6}}\right\}\right)$ | $\widetilde{\Omega}(d^2/\sqrt m)$ |
| deterministic | $\widetilde{\Omega}(d^{5/3}/m^{1/3})$ | $\widetilde{\Omega}\!\left(\min\{d^{8/5},d^{8/3}/m^{2/3}\}\right)$ |

例如写 $m=d^{2-\delta}$，新的 randomized exponent 是 $1+\delta/2$，Chen--Peng 是 $1+\delta/6$；新的 deterministic exponent 是
$$
\min\left\{\frac85,\frac43+\frac{2\delta}{3}\right\},
$$
此前则只有 $1+\delta/3$。更关键的是令 $m=d^2/\log d$：本文确定性下界仍为 $\widetilde{\Omega}(d^{4/3})$，而 $O(d^2\log d)$ bits 已足以在多项式精度下做到 $\widetilde O(d)$ 次查询。上下两个内存预算只差 polylog factor，查询数却差一个 polynomial factor；此前所有下界都要把内存降到 $d^{2-\Omega(1)}$ 才能产生这样的 polynomial loss。

论文中的显式定理比 $\widetilde{\Omega}$ 记号更具体。记 $\mathcal M_{\mathrm{det}}(m,n)$ 和 $\mathcal M_{\mathrm{rand}}(m,n)$ 为用 $m$ bits 状态、至多问 $n$ 次 first-order oracle 的确定性与随机算法。对充分大的 $d$ 和某个 universal constant $C_3$，若
$$
d\log d\le m\le \frac{d^2}{128\log d},
\qquad
n\le
\frac{1}{C_3\log d}
\min\left\{d^{8/5},\frac{d^{8/3}}{m^{2/3}}\right\},
$$
则每个 $\mathrm{OPT}\in\mathcal M_{\mathrm{det}}(m,n)$ 都会在某个 $1$-Lipschitz convex $F$ 上无法达到 $\alpha=1/(4d^{13/2})$。随机版本则说，对某个 universal constant $C_4$，若
$$
d\log d\le m\le \frac{d^2}{256\log d},
\qquad
n\le\frac{d^2}{C_4\sqrt m\log d},
$$
则存在 $1$-Lipschitz convex $F$，使任意 $\mathrm{OPT}\in\mathcal M_{\mathrm{rand}}(m,n)$ 以至少 $1-O(1/d)$ 的概率达不到 $\alpha=d^{-7}$。这些是标题中“polynomially small suboptimality”的两个具体实例；标准缩放把它们写成开头的 $\widetilde{\Omega}$ 形式。

过去几篇 lower bound 的 hard function 都有同一个骨架：
$$
F(w)=\max\left\{
\underbrace{\max_j\{\langle x_j,w\rangle-j\gamma\}}_{\text{Nemirovski function}},
\underbrace{c\|Aw\|_\infty-\rho}_{\text{barrier}}
\right\}.
$$
Nemirovski function 是许多线性函数的最大值，因此仍然 convex；每个随机方向 $x_j$ 是一块尚未暴露的目标信息，offset $j\gamma$ 控制它要到什么时候才可能成为最大项。Barrier 中的 $A$ 是约有 $d/2$ 个随机行的矩阵，含有 $\Theta(d^2)$ 规模的信息。若某次查询 $w$ 不接近 $\ker A$，$\|Aw\|_\infty$ 就会让 barrier 主导，oracle 只返回 $A$ 的某一行；算法只有在近似正交于所有行时，才有机会从 Nemirovski 部分得到下一个 $x_j$。Hardness 的核心于是变成：只有 $m$ bits 时，一个算法能在多大范围内探索随机矩阵的近似 nullspace？

以往的 Orthogonal Vector Game 大致证明“找到若干彼此分散、又近乎正交于 $A$ 的向量很难”，但所得参数没有反映一个很自然的上界策略：把 $m$ bits 当成约 $m/d$ 个 $d$ 维向量的存储空间，直接记住一个 $k\approx m/d$ 维的 nullspace 子空间，之后只在其中查询。本文引入的 **Marked Subspace Game with Hint (MSGH)** 证明，任意编码策略在几何上都不会比这强很多。

游戏先让 player 把随机矩阵 $A$ 压成 $m_1$ bits 消息。Adversary 看到这条消息后标记一个至多 $k$ 维子空间 $L$；player 随后还能收到一条至多 $m_2$ bits、允许依赖 $A$ 和 $L$ 的 hint，并进行 $T$ 次 row query。一次 row query 只返回使 $\langle u,a_i\rangle-\eta_i$ 最大的那一行 $a_i$，这恰好模拟 barrier oracle 暴露 active row 的方式。Player 只有找到一个既近似满足 $Au=0$、又离 $L$ 有明显距离的 $u$ 才算赢。Proposition 1 证明，当
$$
\begin{aligned}
T&<\frac{d}{C_1\log d},&
m_1&\le\frac{d^2}{64\log d},\\
m_2&\le\frac{d}{C_2},&
k&\ge32\max\left\{\frac{m_1}{d},\log d\right\},
\end{aligned}
$$
adversary 可以选取 $L$，使任意、甚至随机的 player 以 $1-O(d^{-3})$ 概率输掉。换句话说，在约 $d/\log d$ 次新反馈到来之前，所有避开 barrier 的查询都被困在某个 $O(m/d)$ 维 subspace 的极小邻域中。

这个命题的证明是全文最有辨识度的一步。固定压缩消息 $B=b$ 后，作者考虑 **strong posterior set**：在看到消息后形成的 $A$ 的条件分布（posterior）下，那些仍以不可忽略概率近似正交于尚未暴露矩阵行的单位向量。然后用 slice dimension 衡量一个集合需要多少维子空间才能近似覆盖。若 strong posterior set 中真正满足 $Au\approx0$ 的部分有很大的 slice dimension，就能从中选出一组张成大体积 parallelepiped 的 well-spread vectors；它们不仅各自近似正交于 $A$，整个 span 都会近似正交。这样，一条短消息就等于从有限候选中指出了一个高维子空间，而随机 $A$ 同时近似正交于某个固定 $k$ 维空间的概率只有 $2^{-\Omega(dk)}$，与消息长度矛盾。因此 strong posterior set 必须贴近某个低维 $L$，adversary 就标记这个 $L$。

剩下还要排除 player 借 hint 或连续 row responses 逃出 $L$。论文分别证明：一条 $O(d)$-bit hint 只能把小概率事件的 posterior 放大有限倍；而每次 row response 对尚未返回的矩阵行所泄漏的信息也受控，$T<d/(C\log d)$ 轮后，weak posterior 中某个新方向突然近似落进 $\ker A$ 的概率仍然指数小。这里最让我意外的不是 packing estimate 本身，而是 MSGH 得到的结论形状：它没有假设算法真的“存了一组 basis vectors”，却证明任意非线性压缩、任意后续查询行为都等价地受困于一个低维几何切片。这正是过去 bound 与 $m/d$ 维朴素存储策略之间缺失的桥。

确定性下界把这条 confinement statement 直接用于 adaptive hard instance。作者取 $k=\Theta(m/d)$，把 Nemirovski directions 写成双指标 $x_{j,\ell}$。每个 round 开始时，MSGH 根据算法此刻的 memory state 产生 marked subspace $L'_{j,\ell}$；新的 $x_{j,\ell}$ 被采样为与此前所有 marked subspaces 正交。为了防止这些已公开方向反过来泄漏太多关于 $A$ 的信息，作者不是直接保存连续随机向量，而是在随机低维子空间的精细 cover 上取最近点；cover 是一个有限代表点集，保证空间里的每个候选向量都靠近其中某一点。这样每个 $x_{j,\ell}$ 只需 $\widetilde O(k\ell)$ 个依赖 $A$ 的 bits 描述。这一 discretization 是参数能继续推进的关键。

随后 resisting oracle 只按“目前已揭示的 $x_{j,\ell}$ 加 barrier”回答。要证明它真的是某个最终固定函数的合法 oracle，需要检查未来方向不会在过去查询处成为 active term：若查询远离 marked subspace，MSGH 保证 barrier 主导；若查询靠近 marked subspace，未来 $x_{j,\ell}$ 与该空间正交，内积小到不足以越过 offset。由此每约 $d/\log d$ 次查询只能推进一个 round。取
$$
N\asymp k^{1/3},\qquad
L\asymp \frac{d}{k\log d},\qquad
T\asymp\frac{d}{\log d},
$$
总查询数给出
$$
TNL=\widetilde{\Omega}\!\left(\frac{d^2}{k^{2/3}}\right)
=\widetilde{\Omega}\!\left(\frac{d^{8/3}}{m^{2/3}}\right).
$$
构造在 $m\ge d^{8/5}$ 时使用这组参数；对更小内存把边界值代回，便得到 $d^{8/5}$ 的 cap。若算法提前停下，它的输出仍与最后一批随机方向独立，而由全部近正交方向组合出的 $w^\star$ 已有明显更低的目标值，所以输出必然保持 polynomial-sized suboptimality。

随机算法不能让 hard function 依赖自己的 random coins，因此作者改用 Yao's minimax principle：要证随机算法的最坏情形下界，只需选定一个输入分布，再证明每个确定性算法在该分布上的平均表现都差。这里作者固定任意确定性算法，证明它在一个预先采样的 loss distribution 上失败。MSGH 首先导出更紧的 Orthogonal Correlated Vector Game (OCVG)：额外给 player 一个随机目标方向 $x$ 后，低内存策略不可能在少于 $\widetilde\Omega(d)$ 次查询内同时做到
$$
\|Au\|_\infty\ \text{很小}
\qquad\text{且}\qquad
|\langle u,x\rangle|\gtrsim \|u\|\frac{k}{d}.
$$
Chen--Peng 的分析只能排除相关度约 $(k/d)^{1/4}$ 的查询；本文把阈值降到近乎 tight 的 $k/d$，因为把 $x$ 投影到一个已保存的 $k$ 维 nullspace 本身就能达到这个量级。

仅有更紧的 OCVG 还不足以得到最终指数。随机 hard instance 因而加入第三项 wall function：
$$
F(w)=\max\{N(w),R(w),W(w)\},
\qquad
W(w)=\max_{z\in Z}\langle w,z\rangle-4\alpha.
$$
集合 $Z$ 排除围绕 $\widetilde x_j=\mathrm{Proj}_{\ker A}x_j$ 的小 correlation caps；一个 cap 就是单位球面上与某个指定方向内积超过阈值的区域。直观上，查询若想避开这堵 wall，其未被已知 directions 解释的分量就必须和某个 $\widetilde x_j$ 明显对齐；OCVG 又说，在避开 barrier 的同时建立这种对齐需要 $\widetilde\Omega(d)$ 次查询。Wall 因此允许作者把相邻 Nemirovski pieces 的 offset 缩小到 $\gamma=\Theta(\alpha k/d)$，并嵌入
$$
N\asymp\sqrt{\frac{d}{k}}
$$
个隐藏方向。每个方向花 $\widetilde\Omega(d)$ 次查询，而 $k=\Theta(m/d)$，于是
$$
\widetilde{\Omega}(dN)
=\widetilde{\Omega}\!\left(d\sqrt{\frac d k}\right)
=\widetilde{\Omega}\!\left(\frac{d^2}{\sqrt m}\right).
$$

Wall 带来的麻烦是它本身依赖 $\mathrm{Proj}_{\ker A}x_j$，所以 oracle 返回它的 subgradient 时可能泄漏 $A$。作者为此显式分析“给定已经发现的 projected directions 后，$A$ 的条件分布”：剩余随机性仍可写成较低维空间里、行范数略有缩小的一组均匀随机向量。MSGH 从一开始就允许各行有不同 norm，并允许 row query 带 offsets $\eta_i$，正好可以把已知分量扣掉，再对剩余随机矩阵调用 OCVG。这种接口设计并非装饰；没有它，wall function 与 game lower bound 无法严密拼接。

随机下界立即说明：若希望在 $\alpha=1/\mathrm{poly}(d)$ 时接近无内存限制的 $\widetilde O(d)$ 查询数，就必须有 $m=\widetilde\Omega(d^2)$。而确定性结果揭示了更陡的现象：$d^2$ 不只是“足够存很多 cuts”的经验预算，它还是算法能否在随机 nullspace 中自由改变方向的几何门槛。本文已经在 deterministic curve 上证明了门槛两侧的 polynomial jump；randomized curve 在同一位置是否也必然从 $\widetilde O(d)$ 跳到 $d^{1+\Omega(1)}$，则仍没有由现有下界决定。

::::issue[geometric-algorithms]
## Geometric $(1+\varepsilon)$-Spanners with Few Crossings [arXiv:2607.25040](https://arxiv.org/abs/2607.25040)

输入是平面中的 $n$ 个点 $S\subset\mathbb R^2$；Euclidean spanner 只能以这些点为顶点、以点对间的直线段为边，既要用稀疏图近似任意两点的 Euclidean 距离，又要控制边与边的相交。Luu 和 Tóth 构造了一张有 $O(n/\varepsilon)$ 条边的 $(1+\varepsilon)$-spanner，其中每条边至多与
$$
O\!\left(\varepsilon^{-3}\log\frac1\varepsilon\right)
$$
条边相交，因而总交叉数为 $O(n\varepsilon^{-4}\log(1/\varepsilon))$；任意两条相交边的长度之比还至多为 $O(\varepsilon^{-2})$。对固定 $\varepsilon$，这是第一张同时具有线性边数和每边 $O(1)$ 个 crossings 的近等距 spanner。

先把对象说清楚。完整 Euclidean 图为每对点都连边，当然精确保留距离，但要付出 $\Theta(n^2)$ 条边。Spanner 的任务是删掉绝大多数边、用短路径代替直连：若 $\delta_G(u,v)$ 是图中从 $u$ 到 $v$ 的最短路径长度，并且
$$
\delta_G(u,v)\leq (1+\varepsilon)\lVert u-v\rVert_2
\qquad\text{对所有 }u,v\in S
$$
都成立，就称 $G$ 为 $(1+\varepsilon)$-spanner。$\varepsilon$ 越小，图中距离越接近真实距离，也就越难保持稀疏。在通信网络、近似距离查询和几何 network design 中，这让我们不必存储和处理完整图，同时仍可把图上最短路当作真实距离的可靠替代。

本文数的 crossing 是两条直线边在各自内部的相交，共端点不算。在抽象图里，相交处并不是可以转向的顶点；但在图绘制、分层分治与把几何图平面化的算法中，每个 crossing 都会增加结构复杂度。除了总数，本文还关心单条边承受的最大交叉数，以及交叉边之间能否跨越悬殊的长度尺度。后两项不是总交叉数的装饰：即使总量是线性的，也可能全部集中到一条“主干”边上；若一条很长的边能被任意短的局部边反复穿过，按尺度分层的算法与 separator 分析也很难利用这张图。

这条研究线的第一层背景是“近等距”和“少边”已经可以兼得。Clarkson (1987) 与 Keil (1988) 独立证明，固定 stretch $t>1$ 时，平面点集总有 $O(n)$ 边的 $t$-spanner；把 $t$ 写成 $1+\varepsilon$ 并追踪参数，可做到 $O(n/\varepsilon)$ 条边，而且这一量级在最坏情形下最优。经典构造有两类代表：$\Theta$-graph 与 Yao graph 把每个点周围按方向切成窄扇区、每区只选少量邻居；well-separated pair decomposition 则把二次多个点对压缩成线性多个彼此远离的簇对，再为每个簇对保留代表边。Greedy spanner 走的是第三条路线，按边长顺序只保留当前没有短替代路径的边。

第二层背景是 planarity 与 stretch 之间存在真正冲突。Delaunay triangulation 用“存在一只经过两端点且内部没有其他输入点的圆”决定邻接，得到一张不交叉的三角剖分；Xia (2013) 证明其 stretch 小于 $1.998$。点处于凸位置时，Biniaz et al. (2016) 把 plane spanner 做到 stretch $1.88$。但 Dumitrescu 和 Ghosh (2016) 证明，对某些点集——甚至凸位置的点集——stretch 小于约 $1.43$ 时 crossing 已不可避免。因此，当 $\varepsilon$ 趋近于零，问题不可能是“把所有 crossing 消掉”，而是要问：为接近直线距离，最少必须容忍多少 crossing，又能否把它们均匀摊开？如果允许添加输入之外的 Steiner points，情形会改变：Bhore et al. (2026) 构造了完全不交叉的 Steiner $(1+\varepsilon)$-spanner，但需要 $O(n/\varepsilon^{3/2})$ 条边，并证明了几乎匹配的下界 [arXiv:2602.17801](https://arxiv.org/abs/2602.17801)。本文坚持顶点集恰为 $S$，保住最优的 $O(n/\varepsilon)$ sparsity，代价是允许但严格控制 crossings。

此前最直接的结果来自 Eppstein 和 Khodabandeh (2021) 对 greedy spanner 的分析 [arXiv:2002.05854](https://arxiv.org/abs/2002.05854)。Greedy 算法按长度从短到长考虑点对，只有在当前图中尚无足够短的替代路径时才加边；它在最大度、相对 minimum spanning tree 的总边长以及实验中的 crossing 数上都表现很好。他们证明 greedy $(1+\varepsilon)$-spanner 的每条边只会被 $O(\varepsilon^{-8})$ 条更长边穿过，总 crossings 为 $O(n/\varepsilon^9)$。问题出在“更短边”一侧：存在点集使一条 greedy edge 被 $\Omega(n)$ 条边穿过。也就是说，先前的线性总量并没有给出与 $n$ 无关的局部保证。本文把总量中的 $\varepsilon$ 指数从 $9$ 降到 $4$（外加一个对数），更重要的是首次消除了单边 crossing 对 $n$ 的依赖。

论文的 upper bounds 与互补 lower bounds 可以合在一个定理图景里。对 $0<\varepsilon<1$，任意 $n$ 点集都有一张 $G$ 满足
$$
\begin{aligned}
\mathrm{stretch}(G)&\leq 1+\varepsilon, &
|E(G)|&=O(n/\varepsilon),\\
\max_{e\in E(G)}\mathrm{cr}(e)
&=O\!\left(\varepsilon^{-3}\log\frac1\varepsilon\right),&
\mathrm{cr}(G)
&=O\!\left(n\varepsilon^{-4}\log\frac1\varepsilon\right),\\
e\cap f\neq\varnothing
&\Longrightarrow
\frac{\max\{|e|,|f|\}}{\min\{|e|,|f|\}}
=O(\varepsilon^{-2}).
\end{aligned}
$$
反方向，存在点集迫使每张 $(1+\varepsilon)$-spanner 分别满足

| 衡量量 | 本文 upper bound | 本文 lower bound |
| :-- | :-- | :-- |
| 总 crossings | $O(n\varepsilon^{-4}\log(1/\varepsilon))$ | $\Omega(n\varepsilon^{-3})$ |
| 单边最大 crossings | $O(\varepsilon^{-3}\log(1/\varepsilon))$ | $\Omega(\varepsilon^{-5/2})$ |
| 相交边最大长度比 | $O(\varepsilon^{-2})$ | $\Omega(\varepsilon^{-1})$ |

总量下界适用于所有 $n\geq\Omega(1/\varepsilon)$，单边下界适用于 $n\geq\Omega(\varepsilon^{-3/2})$，长度比下界只需 $4$ 个点（论文取 $\varepsilon\leq 1/16$）。后两条 lower bound 已经排除了“每边 $O(1/\varepsilon^2)$”以及“相交边总在常数倍尺度内”这两种过于乐观的目标。

:::aside[Crossings 与 separator]
把每个 crossing 处切成一个新顶点，几何图就被 planarize 了；结合 planar separator machinery，本文的总 crossing bound 导出大小
$$
O\!\left(\varepsilon^{-2}\sqrt{n\log\frac1\varepsilon}\right)
$$
的 balanced separator。这里 separator 是删掉一小批顶点，使剩余各连通块都不超过原图的固定比例。Eppstein–Khodabandeh 的旧 crossing bound 给出的 $\varepsilon$ 依赖为 $\varepsilon^{-9/2}$；在更高维，Le 和 Than 对 greedy spanner 证明了 $O(n^{1-1/d})$ separator [arXiv:2107.06490](https://arxiv.org/abs/2107.06490)，但那走的是另一套几何“lankiness”论证。
:::

Empty-region 思路本身有很长的历史。Chew (1986, 1989) 的 generalized Delaunay graphs 已经说明：若每条边都能由某个内部无点的凸形状见证，就可能得到常数 stretch 的 plane spanner。后来的 Gabriel graph、$\beta$-skeleton 与一般 empty-region graph 改用圆盘、透镜或固定锚点形状；但区域越薄，通常越容易失去有界 stretch。另一条 higher-order proximity graph 路线允许见证区域内含至多 $k$ 个点，能够证明 $O(k^2n)$ 或 $O(k^3n)$ 的 crossing bounds，却仍不能在小 $\varepsilon$ 时提供 $(1+\varepsilon)$ stretch。本文面对的难点因而不是单独发明一个空区域，而是让空区域、近等距与局部 crossing bound 三项同时成立。

构造从经典 $\Theta$-graph 出发。以每个点 $s$ 为 apex，把平面等分成 $k=\Theta(1/\varepsilon)$ 个窄 cones；在每个非空 cone 中，把投影到 cone bisector 后离 $s$ 最近的点 $p$ 连到 $s$。每个点每个方向只出一条边，所以总边数是 $O(kn)=O(n/\varepsilon)$。选择 $p$ 的规则还带来一个 empty canonical triangle $\Delta(sp)$：它由 cone 的两条边界射线和经过 $p$、垂直于 bisector 的直线围成，内部不含输入点。标准 stretch 证明正是利用这块空三角形，递归地把任意目标 $t$ 拉向更近的点。

但这个 empty region 对 crossings 不够强。三角形在 $s$ 处有一个角度 $\Theta(\varepsilon)$ 的尖角，大量短边可以从尖角附近穿过，而几乎不在三角形内部行进。Luu–Tóth 的第一个关键改动，是把“尖的空区”换成沿边方向铺开的“钝的空缓冲区”。令 cone aperture 为 $\alpha=2\pi/k\leq\varepsilon/16$，并取一个 regular $3k$-gon $D$。对每条 $\Theta$-edge $sp$，在 $\Delta(sp)$ 靠近 $s$ 与靠近 $p$ 的两端分别放置两个与 $D$ 相似、直径均为 $\alpha|sp|/5$ 的多边形 $D_s,D_p$。随后把二者沿中心连线向外平移，直到边界第一次碰到输入点 $s'$ 与 $p'$；新图不保留 $sp$，而是加入 $s'p'$。

令
$$
R_{s'p'}=\mathrm{conv}(D_s\cup D_p).
$$
初始时两个多边形都在 empty triangle 内，平移时又在碰到第一个输入点处立即停止，所以 $\mathrm{int}(R_{s'p'})\cap S=\varnothing$，而 $s',p'$ 位于边界。这个 region 像一根两端加粗的空管，横向宽度为 $\Theta(\varepsilon|s'p'|)$。Regular $3k$-gon 的选择也不是为了把圆离散化得好看：它的 interior angles 接近 $\pi$，消除了 $\Theta$-graph 空三角形的尖角；同时 polygon sides 与三套 cone boundaries 精确对齐，后面的 crossing case analysis 才能排除“从一个角上几乎零代价擦过”的情形。

仅有 empty buffers 还不够，因为同一方向、同一尺度仍可能堆着许多平行的候选边。作者把上述 modified $\Theta$-graph 旋转 $\alpha/3$ 与 $2\alpha/3$ 各做一遍，将三张图叠加；于是方向被细分成 $3k$ 类。再以 $\phi=5/4$ 做长度分桶，把原始边 $sp$ 按方向 $i$ 和尺度
$$
\phi^{j-1}\leq |sp|<\phi^j
$$
分到 $E_{i,j}$。对固定 $i,j$，每条边在 source $s$ 后方附带一个长约 $|sp|/10$、宽约 $\alpha|sp|/10$ 的 exclusion rectangle $A(sp)$。按沿 cone 方向的坐标从大到小扫描：保留当前边，并删掉 source 落入其 $A(sp)$ 的其他同类边。把每个保留边的 $A(sp)$ 以 $s$ 为中心缩小到 $1/3$，得到的 rectangles $B(sp)$ 两两不交。这是全文把组合 pruning 转成几何 packing 的接口。

Pruning 为什么没有破坏 stretch，是构造中容易被 crossing 分析遮住、但实际上同样关键的一步。对任意点对 $s,t$，取一只 aperture 为 $\alpha/3$、包含 $t$ 的细 cone。若 $s$ 对应的 $\Theta$-edge 被删，就有一条同方向、同尺度的保留边 $s_1p_1$，且 $s$ 落在 $A(s_1p_1)$ 中。三重旋转保证细 cone 即使把 apex 从 $s$ 挪到邻近的 $s_1$，目标 $t$ 仍处在 $s_1p_1$ 的 empty triangle 之后。于是可以用
$$
P(s,s'_1)\ \oplus\ s'_1p'_1\ \oplus\ P(p'_1,t)
$$
替代直接朝 $t$ 前进。作者按 $|st|$ 归纳，证明两端子问题 $|ss'_1|,|p'_1t|$ 都严格小于 $|st|$；再把三段路径投影到以 $st$ 为横轴的坐标系，用 $L_1$ 长度控制横向 backtracking 与纵向偏移。$\alpha\leq\varepsilon/16$ 恰好让这些额外代价被 $\varepsilon|st|$ 吸收。因此，pruning 删除的是局部冗余，而不是 stretch 所必需的方向信息。

接下来 empty buffer 与 disjoint rectangles 开始配合。先固定两条相交边 $ab,cd$，且 $|ab|\leq|cd|$。长边 $cd$ 的 region $R_{cd}$ 由两个直径 $\Theta(\varepsilon|cd|)$ 的 regular $3k$-gons 连接而成；单个 polygon side 的长度为
$$
\lambda=\Theta(\varepsilon|cd|)\cdot\Theta(1/k)
=\Theta(\varepsilon^2|cd|).
$$
由于 $R_{cd}$ 内部没有输入点，短边的两个端点都在 region 外；要穿过 $cd$，它必须穿越 $R_{cd}$ 的两段边界。若它穿过两端 polygons、两条 outer tangents，或 polygon 的非相邻 sides，立刻要走至少 $\Omega(\lambda)$。唯一危险的是擦过两个相邻 sides 的公共顶点；作者利用三套 cone 与 regular $3k$-gon 的平行关系，再结合构造中那根空 tube，证明这种穿法会把该顶点逼进短边自己的 empty region，产生矛盾。最终
$$
|ab|=\Omega(\varepsilon^2|cd|),
$$
这既给出 crossing-edge length ratio $O(\varepsilon^{-2})$，也把一条边可能遇到的长度 buckets 限制为 $O(\log(1/\varepsilon))$ 个。

最后固定方向 $i$、尺度 $j$ 和一条待分析边 $e$。作者给每条 $E_{i,j}$ 中的边配一个长 $\Theta(\phi^j)$、宽 $\Theta(\varepsilon\phi^j)$ 的矩形 $M_j$，同时包住该边及其小 rectangle $B(sp)$。若这条边穿过 $e$，那么 $B(sp)$ 必落在 Minkowski “sausage”
$$
e+(M_j-M_j)
$$
中；这里 $M_j-M_j$ 表示两点差的集合，直觉上就是把 $e$ 向各方向加粗一个 $M_j$ 的尺度。所有 $B(sp)$ 两两不交，而每个面积是 $\Theta(\varepsilon\phi^{2j})$，所以用 sausage 的面积除以单个 rectangle 的面积，就能控制同一 $i,j$ 中的 crossing 数。若 bucket 边不短于 $e$ 的 buffer 宽度，直接对整根 sausage packing；若更短，它只能在 $e$ 两端长度 $O(\varepsilon|e|)$ 的区域穿过，再用刚证出的长度比限制 packing。两种情况都得到每个 $(i,j)$ 至多 $O(\varepsilon^{-2})$ 条 crossing edges。乘上 $3k=O(1/\varepsilon)$ 个方向与 $O(\log(1/\varepsilon))$ 个相关尺度，就得到单边
$$
O\!\left(\varepsilon^{-2}\right)
\cdot O\!\left(\varepsilon^{-1}\right)
\cdot O\!\left(\log\frac1\varepsilon\right)
=O\!\left(\varepsilon^{-3}\log\frac1\varepsilon\right).
$$

下界的统一工具是一只 ellipse。对点对 $a,b$，令
$$
\mathcal E_{ab}
=\{x\in\mathbb R^2:|ax|+|xb|\leq(1+\varepsilon)|ab|\}.
$$
若 $\mathcal E_{ab}\cap S=\{a,b\}$，那么任何长度不超过 $(1+\varepsilon)|ab|$ 的替代路径都不可能经过第三个输入点，因此每张 $(1+\varepsilon)$-spanner 都被迫包含边 $ab$。这把 metric stretch 条件转成了“哪些直线边不可删除”的组合证书。

总 crossing 下界把 $\Theta(1/\varepsilon)$ 个点等距放在单位正方形的上、下边，每个上点到每个下点的 ellipse 都是空的，于是 spanner 被迫包含一个稠密 complete bipartite graph。这里调用的 Crossing Lemma 说，一张有 $N$ 个顶点、$M$ 条边且足够稠密的图，任何平面直线画法都有 $\Omega(M^3/N^2)$ 个 crossings；代入 $M=\Theta(\varepsilon^{-2})$、$N=\Theta(\varepsilon^{-1})$，每个 gadget 就产生 $\Omega(\varepsilon^{-4})$ 个 crossings。复制 $\Theta(\varepsilon n)$ 个相隔足够远的 gadgets，得到 $\Omega(n/\varepsilon^3)$。单边下界则把两排点放在一只长为常数、宽为 $\Theta(\sqrt\varepsilon)$ 的扁 ellipse 上下边，点距取 $\Theta(\varepsilon^{3/2})$。ellipse 的长轴边 $pq$ 被迫存在，而上下排之间有 $\Omega(\varepsilon^{-5/2})$ 条被迫边全部穿过 $pq$。长度比下界更凝练：四个点
$$
p=(0,0),\quad q=(1,0),\quad
a=(4\varepsilon^{3/2},2\varepsilon),\quad
b=(4\varepsilon^{3/2},-2\varepsilon)
$$
迫使 $pq$ 与 $ab$ 同时存在；二者相交，长度比恰为 $1/(4\varepsilon)$。

从优化问题看，这一方向甚至还没有走到“改善近似比”的阶段。已知给定 $S,K,t$，判断是否存在一张至多 $K$ 条边的 noncrossing $t$-spanner 是 NP-hard 的；但去掉边数预算 $K$ 后，仅判断给定 $S$ 是否存在某张 noncrossing $t$-spanner，其 NP-hardness 仍是开放的。直接最小化总 crossings 或最小化单边最大 crossings，也还没有非平凡的 approximation algorithm。

我觉得这篇最有辨识度的地方，是 empty-region argument 与 packing argument 没有被当成两项平行技巧：空管先禁止跨太多尺度的 crossing，pruning 再让同尺度边拥有互不重叠的面积证书，而三重旋转负责让 pruning 之后的 stretch 归纳仍然成立。三者少一个都得不到主定理。现在三组 upper/lower bounds 还分别差大约一个 $\varepsilon^{-1}$、一个 $\varepsilon^{-1/2}$ 和一个 $\varepsilon^{-1}$。尤其长度比中的 $\varepsilon^{-2}$ 来自两次尺度损失——buffer 直径先是 $\Theta(\varepsilon|e|)$，regular $3k$-gon 的 side 又短一个 $\Theta(\varepsilon)$；若未来能把“擦过 polygon corner”的禁区证明提升到 buffer 宽度而不是 side 长度，第三组 gap 会先闭合，并会同步减少 crossing 计数中允许出现的尺度范围。

::::issue[approximation-algorithms]
## A Unifying Framework for Quasi-Polynomial Optimization of Fixed-degree Polynomials [arXiv:2607.25693](https://arxiv.org/abs/2607.25693)

给定非负正交象限中的多面体 $H\subseteq\mathbb R_{\ge 0}^n$ 和 $m$ 个次数至多为 $d$ 的多项式 $\mathcal F=\{f_1,\ldots,f_m\}$，本文考察这些多项式在凸可行域上的**联合值域能否被少量可行点覆盖**。目标是构造有限集 $X\subseteq H$，使每个 $x\in H$ 都有某个 $x'\in X$ 同时满足
$$
\max_{j\in[m]}|f_j(x)-f_j(x')|\le \varepsilon.
$$
Bernasconi、Castiglioni、Celli 和 Farina 证明，只要 $d=O(1)$，且每个多项式在包含 $H$ 的最小非负 $\ell_1$-ball 上都有常数 range，这样的 $X$ 就能在 quasi-polynomial time 内构造，大小为 $n^{O(\log(nm)/\varepsilon^2)}$。这里 quasi-polynomial time 指 $n^{\mathrm{polylog}(n)}$ 量级；QPTAS 则是一族以精度 $\varepsilon$ 为参数、在 quasi-polynomial time 内达到所需近似保证的算法。枚举 $X$ 后取最优点，立即得到固定次数 polynomial optimization 的 QPTAS，并统一导出 dense CSP、Free Games、polynomial variational inequality、polynomial game 的 local Nash equilibrium，以及 normalized densest $k$-subhypergraph 的近似算法。

先澄清这个 cover 覆盖的不是 $H$ 的几何形状，而是映射
$$
\Phi_{\mathcal F}:x\longmapsto(f_1(x),\ldots,f_m(x))
$$
的像。两个在 $\mathbb R^n$ 中相距很远的点，只要所有 $f_j$ 的值接近，在本文的 pseudometric 下就是近邻；反过来，Euclidean distance 很小也未必有用。这个视角很重要：算法真正需要枚举的是优化目标与约束“看得见”的状态，而不是把高维可行域本身切成细小方格。

“同时”也不能由给每个 $f_j$ 单独造 cover 代替。单独的 cover 可能分别用不同代表点逼近不同坐标，无法拼成一个共同的 $x'\in H$；equilibrium 或 CSP 恰恰要求所有收益、所有约束在同一策略上成立。反过来，一旦联合 cover 已经构造出来，很多搜索问题就变成有限枚举：最小化单个 $f$ 时在 $X$ 中取最小值；检查一组近似不等式时筛掉违反某个坐标的点；对 variational inequality，则寻找所有 deviation polynomial 都不大于 $\varepsilon$ 的点。因此主定理并非只给一个存在性 net，而是把连续、多目标的可行性问题压成 quasi-polynomial 个候选状态；这比仅证明某个最优值能被网格近似强得多。

:::aside[Cover 的精确参数]
令 $r=\max_{x\in H}\|x\|_1$，并记
$$
B_1^+(H)=\{z\in\mathbb R_{\ge0}^n:\|z\|_1\le r\},\qquad
R=\max_{f\in\mathcal F}\left(\max_{z\in B_1^+(H)}f(z)-\min_{z\in B_1^+(H)}f(z)\right).
$$
若 $H$ 由 $K$ 个线性不等式描述，Theorem 5.1 构造 $\varepsilon$-cover $X\subseteq H$，满足
$$
|X|\le n^{O(R^2\rho(d)\log(nm)/\varepsilon^2)}
$$
且运行时间为
$$
\mathrm{poly}(K)\cdot n^{O(R^2\rho(d)\log(nm)/\varepsilon^2)}.
$$
$\rho(d)$ 只依赖次数；论文把 $d$ 视为常数，没有优化这一依赖。
:::

为什么会有人研究这种联合值域 cover？一个起点是 probability simplex
$$
\Delta_n=\{x\in\mathbb R_{\ge0}^n:\textstyle\sum_i x_i=1\}.
$$
它既是概率分布的空间，也是很多连续松弛的基本可行域。即使目标只是二次多项式，精确全局优化也已经 NP-hard：Motzkin 和 Straus (1965) 把图的 maximum clique 编码成 simplex 上的 quadratic optimization。另一方面，固定次数且 range 有界时，de Klerk、Laurent 和 Parrilo (2006) 证明可以枚举分母为 $N$ 的规则网格，以 $n^{O(1/\varepsilon)}$ 时间得到 additive PTAS；de Klerk、Laurent 和 Sun (2013) 后来用 Bernstein approximation 与 multinomial distribution 重新解释了这个现象 [arXiv:1311.0173](https://arxiv.org/abs/1311.0173)。这里的 range 是最大值减最小值，控制的是函数在关注区域内实际能变化多少，而不是输入表达式中系数有多大。

Additive approximation 要求输出值与最优值相差至多 $\varepsilon$，和要求相差一个 $1+\varepsilon$ 因子的 multiplicative approximation 不同；若目标本身能随 $n$ 任意放大，固定 additive error 没有统一意义，所以 bounded range 不是无关紧要的技术归一化。它也严格弱于“所有系数有界”：例如 $M(\sum_i x_i)^2$ 在 simplex 上恒等于 $M$，range 为零，展开后的系数却可随 $M$ 任意大。本文用 range 作参数，正是为了不让同一个函数因选择了糟糕的代数表示而看起来更难。

第二条脉络来自 game theory。Nash equilibrium 要求没有玩家能靠单独改变自己的策略提高收益；approximate equilibrium 把“不能提高”放宽为收益增量至多 $\varepsilon$。Lipton、Markakis 和 Mehta (2003) 证明，大型 normal-form game 总存在小 support 的 approximate equilibrium：从一个混合策略采样 $O(\log n/\varepsilon^2)$ 次形成经验分布，就能同时近似每个 pure action 的线性 payoff。枚举所有这种经验分布给出 $n^{O(\log n/\varepsilon^2)}$ 的 QPTAS。这里与单个多项式最小化有一个决定性的差别：后者只需照顾一个函数，Nash equilibrium 却要同时控制每个动作对应的 payoff，所以 union bound 带来 $\log n$，算法也从 PTAS 变成 QPTAS。Rubinstein (2016) 在 PPAD Exponential Time Hypothesis——一种排除 PPAD-complete 搜索问题次指数算法的复杂性假设——下证明，常数近似的 two-player Nash equilibrium 需要 $n^{\log^{1-o(1)}n}$ 时间，说明这个 quasi-polynomial 量级基本不可消除 [arXiv:1606.04550](https://arxiv.org/abs/1606.04550)。

第三条脉络把 simplex 换成带额外线性约束的区域，难度会发生质变。Dense CSP 把每个变量在字母表上的局部分布放进一个 simplex，所有变量合起来是 product of simplices；Free Game 则让多个互不通信的 prover 独立收到问题并给出随机回答，其 strategy profile 也是大量 simplex 的乘积。Arora、Karger 和 Karpinski (1995) 为 dense NP-hard problems 建立了经典 PTAS 框架；Aaronson、Impagliazzo 和 Moshkovitz (2014) 给出 Free Games 的 QPTAS，并通过 birthday repetition——批量抽取问题，用 birthday paradox 式的碰撞放大约束冲突——解释 dense CSP 的 quasi-polynomial hardness [arXiv:1401.6848](https://arxiv.org/abs/1401.6848)；Manurangsi 和 Raghavendra (2017) 又给出 dense CSP 运行时间与近似率的近紧 tradeoff [arXiv:1607.02986](https://arxiv.org/abs/1607.02986)。在 normalized densest $k$-subgraph 一侧，Barman (2015) 用 approximate Carathéodory theorem，即用少量极点的凸组合近似凸包中的任意点，得到 additive QPTAS [arXiv:1406.2296](https://arxiv.org/abs/1406.2296)；Braverman et al. (2017) 则在 ETH 下排除了 additive PTAS [arXiv:1504.08352](https://arxiv.org/abs/1504.08352)。

从离散问题到多项式的翻译并不神秘。CSP 的一个确定性 assignment 可以写成 $0/1$ indicator；把 indicator 放松成每个变量的概率分布后，一条涉及 $k$ 个变量的约束，其期望满足度就是 $k$ 次 multilinear polynomial。Free Game 中，各 prover 的随机回答相互独立，验证成功率同样是这些回答概率乘积的和。困难之处不在“能否写成多项式”，而在这种放松拥有很多彼此耦合的 simplex blocks，full-simplex 的稀疏经验分布不再自动满足每一组 normalization constraint。

这些结果过去看起来分别属于 nonlinear optimization、game theory、CSP 和 dense subgraph。本文给出的共同解释是：它们都把离散问题写成 bounded-range low-degree polynomial，然后寻找函数值意义下的稀疏代表点。此前最接近的一般结果是 Deligkas et al. (2022) 的 sampling theorem [arXiv:1810.01393](https://arxiv.org/abs/1810.01393)：对具有稀疏、系数有界描述的多项式族，它在 simplex 上得到指数含 $1/\varepsilon^5$ 的 cover，也处理常数个 simplices 的乘积。但当变量数对应的 simplex block 数是多项式量级时，其运行时间不再 quasi-polynomial。本文把误差依赖改善到 $1/\varepsilon^2$，更关键的是用函数在 ambient set 上的 range 取代稀疏性和逐系数界，并允许由多项式条不等式描述、可能有指数多个顶点的任意凸多面体。

证明先解决 full simplex。固定 $x\in\Delta_n$，把它看成 $[n]$ 上的 categorical distribution，独立采样 $N$ 次并令
$$
Z=\frac1N\sum_{t=1}^N X_t.
$$
$Z$ 是一个分母为 $N$ 的经验分布，support 至多 $N$。关键连接是 $f(Z)$ 的期望恰好等于 $f$ 的 $N$ 阶 Bernstein approximation 在 $x$ 处的值。Bernstein approximation 是用规则网格上的函数值作系数的多项式插值；经典误差界在这里变成一个 probabilistic statement：
$$
\big|\mathbb E[f(Z)]-f(x)\big|
\le \frac{\rho(d)\,\mathrm{rg}(f)}{N}.
$$
这只控制 bias，还不足以说明某个具体 $Z$ 好。作者进一步证明，若 $w$ 沿 simplex 的 tangent space 移动，也就是 $\sum_iw_i=0$，则
$$
|\nabla f(x)^\top w|
\le \rho(d)\,\mathrm{rg}(f)\|w\|_1.
$$
这个维数无关的导数界来自 Bernstein basis 系数的 range 受函数 range 控制。替换一份样本只让 $Z$ 沿 $(e_i-e_j)/N$ 移动，于是 $f(Z)$ 的变化至多 $O(\rho(d)\mathrm{rg}(f)/N)$；McDiarmid inequality——“每个独立样本影响都很小，则函数集中在期望附近”的 bounded-difference 不等式——给出
$$
\Pr\!\left[|f(Z)-f(x)|\ge\varepsilon\right]
\le 2\exp\!\left(
-\frac{N\varepsilon^2}{\rho(d)\,\mathrm{rg}(f)^2}
\right).
$$
对 $m$ 个多项式做 union bound，取
$$
N=\Theta\!\left(\frac{R^2\rho(d)\log m}{\varepsilon^2}\right)
$$
即可保证存在一个 $Z$ 同时近似全部函数。枚举所有 count vector $\beta\in\mathbb N^n$、$\sum_i\beta_i=N$，得到大小 $n^{O(N)}$ 的 simplex pre-cover。

这里 Bernstein basis 不只是换一种记号。次数 $d$ 的 basis element
$$
B_\alpha^d(x)=\frac{d!}{\alpha!}x^\alpha,\qquad |\alpha|=d
$$
在 simplex 上非负且总和为 $1$，所以 $f(x)=\sum_\alpha c_\alpha B_\alpha^d(x)$ 像是对系数 $c_\alpha$ 做加权平均。经典 Bernstein 理论说明 $\max_\alpha c_\alpha-\min_\alpha c_\alpha$ 至多是 $\rho(d)\mathrm{rg}(f)$。沿 tangent direction 求导时，正负坐标的总质量相等，任意共同的巨大常数部分会相消，只剩系数之间的差；这解释了为什么前面的导数界依赖 range 而不是 $\max_\alpha|c_\alpha|$，也解释了为何诸如 $M(\sum_i x_i)^2$ 的大系数不会破坏分析。

这一段不能简化成“多项式是 Lipschitz，所以给 simplex 做网格”。bounded-range polynomial 的确在 $\ell_1$ 下有维数无关的 Lipschitz constant，可是 $\Delta_n$ 的 $\ell_1$ 几何 cover 是指数大的；对 $\ell_p$、$p>1$，虽有 quasi-polynomial-size 的稀疏 cover，哪怕线性函数的 Lipschitz constant 也会随 $n^{(p-1)/p}$ 增长。论文附录用 $f(x)=\sum_{i\le n/2}x_i$ 直接展示了这个障碍。采样论证绕过了“先让点靠近、再让函数值靠近”的两步法，直接证明函数值集中；这也是为什么它能只依赖 range，而不依赖某个不合适范数下的全局光滑性。

full simplex 之后才出现本文最关键的障碍。若
$$
H=\{x\in\Delta_n:Ax\le b\},
$$
把 ambient cover 与 $H$ 相交通常什么也得不到：这个网格极稀，可能没有任何点落在一个低维或倾斜的可行域里。把每个网格点投影到 $H$ 也不能保证非线性函数值保留。在线性情形，若 $\mathcal F$ 写成矩阵 $B$ 的各行，作者对每个 pre-cover anchor $\widetilde x$ 解 LP
$$
x\in H,\qquad \|Bx-B\widetilde x\|_\infty\le\varepsilon/2.
$$
对于真正需要覆盖的 $x^\star\in H$，总有某个 $\widetilde x$ 近似 $Bx^\star$，所以该 LP 至少以 $x^\star$ 为可行解；LP 返回的另一个 $\widehat x\in H$ 也会近似相同函数值。于是 ambient 点无需真的“投影”为邻近点，只需作为一组 value constraints 的 anchor。

次数大于一时，直接写 $|f(x)-f(\widetilde x)|\le\varepsilon$ 会把 feasibility program 重新变成非凸 polynomial optimization。这里最巧的一步是递归 degree reduction。作者证明每个 $k$ 次多项式都可写成
$$
f(x)=\sum_{i=1}^n x_i g_i(x),
$$
其中 $g_i$ 是 $k-1$ 次多项式，而且
$$
\mathrm{rg}(g_i)\le \rho(k)\,\mathrm{rg}(f).
$$
对每个 $f\in\mathcal F$ 反复分解，得到深度 $d$、branching factor $n$ 的树：根是 $f$，叶子是线性函数，整棵树只有 $O(n^d)$ 个节点。然后不只为原来的 $\mathcal F$，而是为所有树节点组成的扩大族 $\widehat{\mathcal F}$ 构造 $\delta$-pre-cover。因为 $d$ 固定，$|\widehat{\mathcal F}|=O(mn^d)$，union bound 只额外付出 $\log n$，range 也只放大一个依赖 $d$ 的常数。

现在固定 anchor $\widetilde x$。若节点 $g$ 的孩子为 $c_1[g],\ldots,c_n[g]$，算法加入约束
$$
\left|
\sum_{i=1}^n x_i\,c_i[g](\widetilde x)-g(\widetilde x)
\right|\le 2\delta
\qquad\text{对所有 }g\in\widehat{\mathcal F}.
$$
孩子的值都已在 $\widetilde x$ 处求好，因此未知量只有 $x_i$，整套约束仍是 LP。若 $\widetilde x$ 同时近似某个 $x^\star\in H$ 上所有树节点的值，分解恒等式保证 $x^\star$ 满足这些约束，所以 LP 一定可行。设它返回 $\widehat x$：从线性叶子往根归纳，degree-$k$ 节点在 $x^\star$ 与 $\widehat x$ 之间的误差至多 $4k\delta$；取 $\delta=\varepsilon/(4d)$，根节点的误差就是 $\varepsilon$。

我认为这棵树的作用比“把高次多项式拆成低次多项式”更具体：它给非线性函数值相近性造出了一份**线性可验证的递归证书**。LP 从不强迫 $\widehat x$ 靠近 $x^\star$ 或 $\widetilde x$，只要求每层的局部重组关系在 anchor 上成立；下一层的近似再把误差逐级传回根。正因为压缩发生在函数分解树上，而不是 ambient geometry 上，同一个算法才可以面对顶点数指数大的多面体。

从 simplex subset 到一般 $H\subseteq\mathbb R_{\ge0}^n$ 只需一个干净的 embedding。令 $r=\max_{x\in H}\|x\|_1$，把
$$
x\longmapsto
\left(\frac{x_1}{r},\ldots,\frac{x_n}{r},
1-\frac{\|x\|_1}{r}\right)
$$
送进 $\Delta_{n+1}$。整个 $\Delta_{n+1}$ 在逆映射下恰好对应 $B_1^+(H)$，所以 simplex theorem 中出现的 range 正是主定理里的 ambient $\ell_1$-ball range。这个条件承担了真实的复杂性工作，不能随意改成“只在 $H$ 上 range 小”：论文指出，若仅凭 feasible-set range 就有同样结论，会与 sparse 3-SAT 等已知 hardness 相冲突。另一方面，许多应用天然有归一化，使 ambient range 恰好为常数；框架捕捉到的不是“系数温和”，而是目标经过概率或密度归一化后不可能在大球上爆炸。

应用中这一点看得很清楚。一个 $k$-CSP 有 $m$ 个变量、字母表 $[q]$；以 $x_{i,a}$ 表示变量 $i$ 取值 $a$ 的概率，每条约束成为一个 $k$ 次 multilinear polynomial。总目标在 ambient ball 上的 range 至多 $m^k$，把 additive accuracy 设为 $\varepsilon m^k$ 后，Corollary 6.1 的运行时间是
$$
(mq)^{O(\rho(k)\log(mq)/\varepsilon^2)}.
$$
当实例 dense、约束数为 $\Theta(m^k)$ 时，这个 additive error 就是常数相对误差。对于 $k$-player Free Game，问题与回答分别来自 $Y,B$，验证者对独立均匀问题取期望；$1/|Y|^k$ 的归一化把目标 range 压到常数，于是对固定 $k$，在 $n=k|Y||B|$ 个策略变量上恢复
$$
n^{O(\rho(k)\log n/\varepsilon^2)}
$$
时间的 QPTAS。两者的专用算法可能有更好的参数，但本文的同一 cover 允许额外加入任意凸耦合约束，这一点是 product-of-simplices sampling 所不具备的。

联合 cover 还处理不能写成单个标量目标的 variational inequality。它要求当前点相对于算子 $F$ 没有任何可行的一阶改进方向；形式化地，给定凸包 $V=\mathrm{co}(v_1,\ldots,v_n)$ 和 polynomial operator $F$，VI 要找 $v\in V$ 使
$$
F(v)^\top(v'-v)\le0\qquad\text{对所有 }v'\in V.
$$
由于左侧对 $v'$ 线性，只需同时覆盖对应 $n$ 个顶点的多项式 $F(v)^\top(v_i-v)$。把各玩家 utility 的一阶 unilateral-improvement condition 写成 VI，作者得到常数玩家、常数次数 polynomial game 的 $\varepsilon$-local Nash equilibrium QPTAS，运行时间为
$$
n^{O(m^2\rho(d)\log n/\varepsilon^2)}.
$$
这里 local 指每个玩家沿任意单边策略方向的一阶收益至多 $\varepsilon$，不是保证全局 best-response gap 小；这一限定也解释了为什么结果不与一般 polynomial game 中 Nash existence/computation 的 hardness 冲突。

最后一个应用把 normalized densest $k$-subgraph 推到 $d$-uniform hypergraph，也就是每条超边都恰含 $d$ 个顶点的超图。对 $|S|=k$ 定义密度 $\rho(S)=|E(S)|/k^d$，作者优化 generating polynomial
$$
A_{\mathcal H}(x)=\sum_{e\in E}\prod_{u\in e}x_u
$$
加上正则项 $\eta\|x\|_2^2$，可行域是 $\Delta_n\cap[0,1/k]^n$。Maclaurin inequality 比较不同阶的 elementary symmetric means，在这里把 $A_{\mathcal H}$ 在 simplex 上的 range 控制为常数；当 $\eta\ge1/2$ 时，一个 pairwise mass-shifting 过程还能把解舍入到恰有 $k$ 个坐标等于 $1/k$，且目标不降。由此得到 constant-uniformity 下 $n^{\widetilde O(\rho(d)\log n/\varepsilon^2)}$ 时间的 additive approximation。

这套统一框架的边界也从证明里直接显露出来：VI reduction 要为凸包的每个顶点建一个多项式，因此尚不能有效处理只由少量 inequalities 隐式描述、却有指数多个顶点的 VI；degree reduction 对 $d$ 的依赖是指数级，尚未利用 CSP 与 Free Game 的 multilinearity；而 $1/\varepsilon^2$ 来自 McDiarmid concentration，已知下界通常只有指数中的 $\widetilde\Omega(1/\varepsilon)$。在我看来，最值得追的不是把 LP compression 再换一种实现，而是问联合值域 cover 是否存在不经过 independent sampling 的构造：只要第一步仍是经验分布，$\varepsilon^{-2}$ 就会像方差一样牢牢留在指数里；这也是整篇论文留下的核心技术问题之一，并决定这个框架下一步能否真正提速。

## Stochastic Load Balancing with Machine Reservations [arXiv:2607.25183](https://arxiv.org/abs/2607.25183)

Machine reservations 把 stochastic load balancing 分成两个阶段：给定 $m$ 台机器和一批处理时间随机的 jobs，算法先在只知道分布时为每个 job 预留至多 $k$ 台候选机器；等所有处理时间实现后，再把每个 job 分配给它的某台候选机器。目标是最小化 expected makespan，也就是最忙机器的期望负载。Alemán Espinosa、Garg、Ibrahimpur、Olver 和 Swamy 证明，在 identical machines 上，给每个 job 随机预留两台机器，就能在常数因子内逼近看见全部实现后任意调度的 omniscient optimum；这个结论对 jobs 之间任意相关的联合分布也成立。

作者同时证明，这个 “two choices suffice” 现象到了 related machines 就会失效：若每台机器有不同速度 $s_i$，job $j$ 在机器 $i$ 上耗时 $P_j/s_i$，则对每个正整数 $k$ 及 $m=\exp(\Omega(k\log k))$，都有某个独立-jobs 实例满足

$$
\frac{\mathrm{OPT}_k}{\mathrm{OPT}_m}
=\Omega\!\left(\frac{m^{1/(2k)}}{k}\right).
$$

因此任何 $k=o(\log m/\log\log m)$ 都不能保证常数 price of reservation。不过，论文仍给出关于 $\mathrm{OPT}_k$ 的真正 $O(\log m/\log\log m)$-approximation、使用 $2k$ 个候选机器的 bicriteria $O(1)$-approximation（把候选数预算放宽一倍，同时把 makespan 控制在常数倍内），以及一个相对于最优 adaptive policy 为常数近似的 2-reservation。正负结果放在一起，才完整说明 $k$ 量化了哪一种灵活性。

### 在随机性揭晓前，究竟要承诺多少

Load balancing 的日常原型是把请求分给服务器：请求的实际耗时事先未知，但长期分布可以估计；如果只按平均耗时分配，少数同时变大的请求可能把一台服务器压垮。Makespan 是所有机器负载的最大值，最小化它是在控制最坏拥塞，而不是平均吞吐。随机版本之所以困难，正因为目标里先取最大值、再取期望；$\mathbb{E}[\max_i L_i]$ 不能仅由各台机器的平均负载决定，尾部事件会支配答案。

为什么不等任务大小确定后再随意分配？因为机器选择往往还代表事前承诺。数据可能只预取到少数服务器，某个客户可能只授权给固定的一小组服务人员，或者每台候选机器都要提前留出状态与缓存。论文用投资机构作例子：给每位客户固定一名 fund manager 最容易维持连续服务，却可能在客户实际到访时造成严重忙闲不均；提前指定两三名熟悉该客户的 managers，再在当天到访名单明确后选择其中一人，就保留了大部分个性化关系，同时多出负载调节空间。参数 $k$ 因而不是抽象的算法预算，而是“为一个 job 维护多少条可用路径”的成本。

文献里通常比较三种信息结构。Non-adaptive policy 在任何 job size 揭晓前固定完整分配，部署简单，也让每个 job 的负责机器确定；adaptive policy 逐个处理 jobs，分配当前 job 时可以利用此前已经揭晓的实现，但不能回头改动旧决策；omniscient optimum 则先看见整个 size vector，再一次性选择最优分配。后两者的差别是，adaptive policy 只拥有沿时间逐步到来的信息，而 omniscient optimum 拥有完整 hindsight。

Machine reservation 插在 non-adaptive 与 omniscient 之间，但不是把决策树截短。第一阶段只根据分布选择

$$
\sigma(j)\subseteq [m],\qquad 1\leq |\sigma(j)|\leq k;
$$

第二阶段观察全部实现 $p=(p_{ij})$，再选择满足 $\pi(j)\in\sigma(j)$ 的 consistent assignment。形式化地，

$$
\begin{aligned}
\mathrm{cost}(\sigma;p)
&=\min_{\pi:\,\pi(j)\in\sigma(j)}
  \max_{i\in[m]}\sum_{j:\pi(j)=i}p_{ij},\\
\mathrm{cost}(\sigma)
&=\mathbb{E}_{P}\!\left[\mathrm{cost}(\sigma;P)\right],\\
\mathrm{OPT}_k
&=\min_{\sigma:\,|\sigma(j)|\leq k}\mathrm{cost}(\sigma).
\end{aligned}
$$

定义里的第二阶段取了最优 consistent assignment，但算法并没有因此依赖一个不可实现的 oracle。对固定的 $\sigma$ 和 realization $p$，这就是 deterministic makespan minimization on unrelated machines：job 只能去 $\sigma(j)$ 中的机器。Lenstra、Shmoys 和 Tardos (1990) 的经典 rounding 可在多项式时间给出 2-approximation，所以本文把技术注意力放在真正新增的第一阶段 reservation；实际执行第二阶段至多再损失一个常数因子。

于是 $\mathrm{OPT}_1$ 正是最优 non-adaptive assignment；$\mathrm{OPT}_m$ 允许给每个 job 预留全部机器，等于 omniscient optimum；而 $\mathrm{OPT}_k$ 随 $k$ 单调下降。论文把最坏情形比值

$$
\sup_I\frac{\mathrm{OPT}_k(I)}{\mathrm{OPT}_m(I)}
$$

称为 price of $k$-reservation。这里随机性不可省：确定性 jobs 在第一阶段已经完全已知，直接把最优分配当作 1-reservation 即可，只有不确定性才让“先留候选、后做选择”有意义。

三类标准 machine environments 也需要分清。Identical machines 上，同一个 job 到哪里耗时都为 $P_j$；related machines 给机器一个速度 $s_i$，耗时为 $P_j/s_i$；unrelated machines 则允许同一 job 在各机器上的 processing-time vector 没有统一的速度分解。后者最一般，也通常最难。

这条研究线始于对 non-adaptive 端点的理解。Kleinberg、Rabani 和 Tardos (2000) 首次处理 arbitrary job-size distributions，并在 identical machines 上给出常数近似（[Allocating Bandwidth for Bursty Connections](https://doi.org/10.1137/S0097539797329142)）；此前结果主要针对 Bernoulli、Poisson 等特殊分布。Gupta et al. (2021) 把常数近似推进到 unrelated machines（[arXiv:1904.07271](https://arxiv.org/abs/1904.07271)）。但这些算法近似的是 $\mathrm{OPT}_1$，并不表示固定分配接近更有信息的策略：Gupta et al. 还证明，即使机器 identical、每个 job 只是一个 weighted Bernoulli 随机变量，也有

$$
\frac{\mathrm{OPT}_1}{\mathrm{OPT}_{\mathrm{AD}}}
=\Omega\!\left(\frac{\log m}{\log\log m}\right).
$$

这个 gap 可以由一个很朴素的实例看见。取 $m^2$ 个独立 jobs，每个以概率 $1/m$ 实现为单位大小，否则为 0。实现后总共大约只有 $m$ 个非零 jobs，omniscient scheduler 可以把它们均匀摊开，$\mathrm{OPT}_m$ 与 $\mathrm{OPT}_{\mathrm{AD}}$ 都是 $\Theta(1)$。可任何事前固定的平衡分配都会让每台机器负责约 $m$ 个 Bernoulli trials；各机器负载近似独立 Poisson variables，其中最大者达到 $\Theta(\log m/\log\log m)$。障碍不是不会把期望工作量平均分，而是不知道哪些 jobs 会同时出现。

Eberle et al. (2025) 随后给出 matching 的 $O(\log m/\log\log m)$ non-adaptive 上界，并首次在 related machines 上构造相对于 $\mathrm{OPT}_{\mathrm{AD}}$ 的常数近似 adaptive policy（[arXiv:2208.13702](https://arxiv.org/abs/2208.13702)）；在 unrelated machines 上，能否让 adaptive policy 严格优于上述 logarithmic guarantee 仍然开放。换句话说，在本文之前，non-adaptive 一端的可计算近似已经很好，真正没有量尺的是：允许每个 job 多几个预先指定的去处，能消掉多少 information gap？

这里也有一条经典的 “power of two choices” 支线。Azar、Broder、Karlin 和 Upfal (1999) 研究把 $m$ 个 unit balls 在线放进 $m$ 个 bins：每次只随机选一个 bin 时，最大负载是 $\Theta(\log m/\log\log m)$；每次看两个随机 bins 并放进较轻者，降到 $O(\log\log m)$（[Balanced Allocations](https://research.google/pubs/balanced-allocations/)）。他们还证明，若先为每个 ball 抽两个 bins、最后离线决定放哪一个，最优最大负载为 $O(1)$。本文的 identical-machines 定理正是这个离线结论的随机尺寸版本：job weights 可以不同、可以相关，性能基准也不再是 unit-ball 实例的常数，而是每个 realization 自己的 omniscient optimum。

### 为什么两个随机候选能覆盖全知调度

Identical machines 上的算法简单到几乎没有可调参数：对每个 job $j$ 独立地均匀抽取 $i_1(j),i_2(j)\in[m]$，令 $\sigma(j)=\{i_1(j),i_2(j)\}$；两次抽到同一机器时候选集大小为 1。这个 reservation 甚至不读取 job distributions。论文证明得更强：对任意固定、可能由 oblivious adversary 选择的 size vector $p$——它必须在看见本次 reservation random bits 之前选定输入——都有

$$
\mathbb{E}_{\sigma}\!\left[\mathrm{cost}(\sigma;p)\right]
\leq 15\max\!\left\{p_{\max},\frac{p_{\mathrm{total}}}{m}\right\},
\qquad
p_{\max}=\max_jp_j,\quad p_{\mathrm{total}}=\sum_jp_j.
$$

右边两项是任何 assignment 都躲不开的下界：最大 job 必须完整落在某台机器上，总工作量也必须由 $m$ 台机器分担。因此对 $P$ 再取期望并交换两层期望，就得到

$$
\mathbb{E}_{\sigma}[\mathrm{cost}(\sigma)]
\leq 15\,\mathrm{OPT}_m.
$$

这也解释了“任意相关”为什么不妨碍定理：证明先条件化在整个 realization $P=p$ 上，真正需要独立的是不同 jobs 的 reservation coin flips，而不是 job sizes。

这里的随机性仍有实质作用。结论是先抽取 $\sigma$，再对 reservation 与 job realizations 的双重随机性取期望；它并没有给出一个对所有 size vectors 同时成立的固定 graph。能否在多项式时间确定性地构造满足 $O(\mathrm{OPT}_m)$ 的 2-reservation，是论文明确留下的问题。换言之，分布无关不等于已经 derandomized：算法不读分布，但仍靠隐藏于 oblivious adversary 之外的随机 bits 选择候选机器。

证明中最关键的变换，是把一个 2-reservation 看成 weighted multigraph。机器是 vertices，每个 job 是连接其两台候选机器的一条 weight-$p_j$ edge；把 job 指派给某个候选机器，等价于把 edge 朝该 endpoint 定向，机器负载就是 weighted indegree。对任意非空机器集合 $R$，定义

$$
\rho_\sigma(R;p)
=\frac{\sum_{j:\,\sigma(j)\subseteq R}p_j}{|R|}.
$$

分子里的 jobs 两个出口都在 $R$ 内，无论怎样定向都逃不出去，所以 $\max_R\rho_\sigma(R;p)$ 是 makespan 的下界。反过来，把每条 edge 的 weight 分数地拆给两个 endpoints，最小化最大 fractional load；一个 flow/min-cut 对偶说明，这个 fractional optimum **恰好**等于最大密度。再把每条 edge 指向承接了至少一半 weight 的 endpoint，每台机器负载至多翻倍，故

$$
\mathrm{cost}(\sigma;p)
\leq 2\max_{\varnothing\neq R\subseteq[m]}\rho_\sigma(R;p).
$$

这个 density lemma 把“在所有 edge orientations 中优化”改写成“控制所有 vertex subsets”，是整篇论文最有用的接口；related-machines 的分母只需换成 $\sum_{i\in R}s_i$。

剩下的障碍看上去反而更大：机器子集有 $2^m$ 个，怎么同时控制它们？先把 $p$ 缩放到 $p_j\leq1$ 且 $\sum_jp_j\leq m$。固定 $|R|=r$ 时，

$$
X_R:=\sum_jp_j\mathbf{1}[\sigma(j)\subseteq R],
\qquad
\mathbb{E}[X_R]
=\sum_jp_j\left(\frac{r}{m}\right)^2
\leq\frac{r^2}{m}.
$$

若 $r$ 小，阈值 $O(r)$ 相比均值 $r^2/m$ 是巨大的 relative deviation；若 $r$ 大，集合数虽然多，越过同一线性阈值所需的 absolute deviation 也随 $r$ 增长。Chernoff bound 的衰减恰好压过 $\binom mr$ 个集合的组合数，再对 $r=1,\ldots,m$ 求和。这里最巧的不是使用 concentration inequality 本身，而是把阈值按 $|R|$ 线性设置，使“小集合靠相对偏差、大集合靠绝对偏差”在同一个式子里接上；直接对每台机器负载做 balls-and-bins 分析，看不到这种全局可定向性。

:::aside[常数 15 的计算]
论文取阈值 $e^2r$。对每个 $|R|=r$ 的集合，积分形式的 Chernoff bound 给出
$$
\mathbb{E}\!\left[(X_R-e^2r)_+\right]
\leq \left(\frac{em}{r}\right)^{-e^2r}.
$$
再用 $\binom mr\leq(em/r)^r$ 对同样大小的集合 union bound，尾项可由 $\sum_{r\geq1}e^{-6r}/r$ 控制。连同 density-to-orientation 的因子 2，证明得到至多 15 的显式上界；论文没有试图优化这个常数。
:::

### 速度层级为何破坏 two choices

Related machines 的反例准确指出 identical proof 缺少哪一维信息。作者构造 $k+1$ 个 speed classes $C_1,\ldots,C_{k+1}$：相邻类的速度缩小 $\Delta$ 倍，机器数增大 $\Delta^2$ 倍，所以每一类的 aggregate processing power 反而比前一类大 $\Delta$ 倍。所有 jobs 独立同分布；size 恰等于第 $\ell$ 类速度的 jobs，期望数量被校准成 $|C_\ell|$。Omniscient scheduler 看见 realization 后，把各尺度 jobs 送到同尺度的 class，Chernoff concentration 保证 expected makespan 为 $O(1)$。

但每个 job 只有 $k$ 个候选机器，而尺度有 $k+1$ 层。对任何固定 $k$-reservation，平均原则保证存在某一 class $C_\ell$，至少 $1/(k+1)$ 的 jobs 在该 class 没有候选机器。当这些 jobs 实现成恰适合 $C_\ell$ 的尺寸时，送到更慢 class 会让单个 job 造成 $\Delta$ 级负载；全部挤到更快 classes，则那些 classes 的总处理能力不够，也会产生 $\Omega(\Delta/k)$ makespan。取 $\Delta\asymp m^{1/(2k)}$，就得到

$$
\frac{\mathrm{OPT}_k}{\mathrm{OPT}_m}
=\Omega\!\left(\frac{m^{1/(2k)}}{k}\right).
$$

这个构造说明问题不是随机挑选机器的分析太松，而是候选集合必须覆盖 job size 可能落入的速度尺度。相应的上界也按尺度付费：先把任意 related-machine 实例以常数损失 smoothing 成 $L=O(\log m)$ 个 classes，使速度几何下降、每类总处理能力几何上升；再为每个 job 从每个 class 随机抽两台机器，总共 $O(\log m)$ 个候选。每个 class 内可复用 identical-machines 的 density analysis，于是 $\mathrm{OPT}_{O(\log m)}=O(\mathrm{OPT}_m)$。目前 lower threshold $o(\log m/\log\log m)$ 与 upper threshold $O(\log m)$ 之间还差一个 $\log\log m$ 因子。

### 从 speed-class LP 回到具体机器

Related machines 上的 algorithmic results 解决的是另一个问题：给定 $k$，怎样近似本身可能远大于 $\mathrm{OPT}_m$ 的 $\mathrm{OPT}_k$？作者先做同样的 smoothing，再暂时不让 job 预留具体机器，而是预留 speed classes。以 $k=2$ 为例，变量 $x_{j,\ell_1,\ell_2}$ 表示 job $j$ 选择 classes $C_{\ell_1},C_{\ell_2}$ 的分数；每个 job 的这些变量之和为 1。

若候选 classes 中 $C_{\ell_1}$ 较快、$C_{\ell_2}$ 较慢，job realization 被按两个速度阈值切成 small、medium、large 三段。Small 部分连慢 class 也能在目标 makespan 内处理，medium 部分只能交给快 class；这两者进入各 class 的 volume constraints。Large 部分无论去哪一类，单个 realization 都会越过目标阈值，所以不再当作普通体积，而由一条 aggregate exceptional-jobs constraint 控制尾部。经过 binary search 缩放后，LP infeasible 就证明猜测的目标值低于 $\mathrm{OPT}_k$；若 feasible，机器数随 class 变慢而几何增长，使每个变量对约束总量的影响受常数控制。利用这种 bounded column sums 结构，Linhares et al. (2020) 的 iterative rounding 会反复固定已经接近整数的变量，把 fractional class choices 变成 integral choices，同时只付常数级 volume 损失。

最后一步从 classes 落回 machines，恰好产生论文的两种 guarantee。每个选中 class 只随机抽一台具体机器，会出现标准 one-choice balls-and-bins 拥塞，损失 $O(\log m/\log\log m)$；候选数仍为 $k$，所以这是相对于 $\mathrm{OPT}_k$ 的 true approximation：

$$
\mathbb{E}[\mathrm{cost}(\sigma_k)]
\leq O\!\left(\frac{\log m}{\log\log m}\right)\mathrm{OPT}_k.
$$

若从每个选中 class 抽两台机器，候选数变为 $2k$，class 内重新获得 two-choice density bound，于是

$$
\mathbb{E}[\mathrm{cost}(\sigma_{2k})]
\leq O(1)\,\mathrm{OPT}_k.
$$

我最喜欢这里的地方是 logarithmic loss 被定位得很精确：它不来自 class-level stochastic LP，也不来自 iterative rounding，而只发生在“一个 class 代表很多具体机器、每个 job 却只能选其中一个”这最后一公里。允许每类多抽一次，损失便消失。

论文最后还把 2-reservation 与 adaptive policy 接起来。核心中间对象是 1-class reservation：第一阶段为每个 job 承诺一个 speed class，第二阶段仍可在该 class 的所有机器中选择。作者证明，最优 1-class reservation 的代价至多是 $\mathrm{OPT}_{\mathrm{AD}}$ 的常数倍；随后在每个被选 class 内独立抽两台机器，再用 identical density lemma 压缩候选集合，得到

$$
\mathbb{E}[\mathrm{cost}(\sigma_2)]
\leq O(1)\,\mathrm{OPT}_{\mathrm{AD}}.
$$

这并不与 related-machines 的 price lower bound 冲突：omniscient optimum 一次看见全部 sizes，adaptive policy 只看见过去；而 2-reservation 的第二阶段虽有完整信息，却受两个候选机器约束。论文甚至构造了 $\mathrm{OPT}_{\mathrm{AD}}/\mathrm{OPT}_2=\Omega(\sqrt m)$ 的实例。于是 $k$ 并不是一根从 non-adaptive 平滑滑向 adaptive 的旋钮：它连接的是 non-adaptive 与 omniscient 两个端点，adaptive 位于另一条信息轴上。Identical machines 上两个候选已足以跨过整条轴，related machines 上的速度层级则把这两种信息资源明确地区分开来。

## 未入选但值得关注

### Breaking the $4^k$ Barrier for the $k$-Distinct Language [arXiv:2607.25381](https://arxiv.org/abs/2607.25381)

论文用 design-based gadget amplification 与 compose-and-compress，把 $k$-Distinct language 的 NFA 大小底数首次降到 $3.918$。未入选是因为推进主要集中在较窄自动机模型中的常数底数改进。

### Length-Constrained Network Design in Planar Digraphs [arXiv:2607.25811](https://arxiv.org/abs/2607.25811)

论文研究 planar directed Steiner tree/forest 的 length-constrained bicriteria approximation。结果扎实，但仍需 $O(\log k)$ 的长度违约，突破性略弱于本期入选工作。

### Parallel Spectral Graph Sparsification via Low Diameter Decompositions [arXiv:2607.25059](https://arxiv.org/abs/2607.25059)

论文用 low-diameter decompositions 推进 solver-free parallel spectral sparsification，是这一方向自 2014 年以来的重要改进。知识库近两期已连续覆盖 spectral sparsification，本期为保持话题多样性暂缓。

### Extending Biconnected Straight-Line Planar Drawings [arXiv:2607.25756](https://arxiv.org/abs/2607.25756)

论文研究如何把给定子图的 straight-line planar drawing 扩展到整个 biconnected graph，同时给出 NP-hardness、$O(p^2n)$ 算法和以 vertex cover 为参数的 FPT 结果。Fixed-embedding 且已画子图 $H$ 连通时的核心复杂性边界仍未解决，因此未入选。
